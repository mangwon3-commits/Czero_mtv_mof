# 재평가 파이프라인 v2 — 초기 HTS의 공백을 v3 규약으로 메우는 계획

작성 08-19. 사용자 질문에서 출발: "초반 기획이라 많은 걸 빼먹은 파이프라인 같다 —
빼놓은 것까지 넣어 재평가할 수 있나?" 답은 "된다, 그리고 대부분 조립이다".
착수는 사용자 복귀(08-21 20:00) 후, 엑셀 원표를 확보한 다음이다.

## 초기 파이프라인(run_master_pipeline.py)이 잰 것

- Widom K_H (CO₂/N₂), 298 K 무한희석, **전하 OFF** (`UseChargesFromCIFFile no`)
- Zeo++ LCD/PLD/VF/PV
- 채점: FlueGas = 0.5·K_H_norm + 0.5·PV_norm / DAC = 0.8·K_H_norm + 0.2·PV_norm,
  OMS ×1.3, min-max 정규화
- 비교군: Mg-MOF-74, MFU-4l 계열, Co-MOF 계열, ZIF-8/67/69, MTV_ZIF8 nIm 계열
  (widom_* 디렉터리에는 simulation.input만 남고 출력은 삭제됨. K_H 수치는
  CSV 3종과 사용자 보관 엑셀에만 있음 — **엑셀 위치 확인이 선행 과제**)

## 핵심 설계 원칙

**기준 MOF들을 우리 재료와 같은 규약에 통과시킨다.** 지금 비교표는 우리
재료(v3 규약)와 기준 재료(구 규약)의 세대가 어긋나 있다. 채점식을 고치는 것보다
이게 먼저다.

## 단계 (비용 통제)

- **Tier 0**: 이완 → DDEC6 → Widom(전하 ON/OFF 두 벌) + Zeo++. 구조당 수 분
  (이완 제외). 전 기준군.
- **Tier 1**: 건조 GCMC 0.15 bar. 구조당 수 시간 × ~20종 = 랩탑 1~2일.
- **Tier 2**: WC(ads/tsa/vsa) + 습윤. 상위 후보만.
- 채점식 v2: min-max 대신 고정 앵커(문헌 기준점) 정규화, OMS 보너스 폐지하고
  습윤 유지율을 독립 축으로. 세부는 착수 시 결정.

## 함정 (미리 적어둠)

1. **OMS 재료의 고전 힘장 한계** — Mg-MOF-74의 열린 금속 자리는 UFF+점전하로
   과소평가된다. 표에 문헌 실험값 열을 병기하고 "시뮬레이션끼리의 공정 비교"임을
   명시할 것. OMS ×1.3을 없애는 근거이기도 하다(습윤 피독 미반영).
2. **기준 구조도 이완 필요** — v3에서 이완이 순위를 뒤집었다(a1d4309).
   그리고 xtb는 데스크탑에만 있다(relax_fixcell.py:63 하드코딩, 08-19 확인).
   Tier 0 이완은 데스크탑 몫.
3. **Widom 출력 삭제 전례** — 이번에는 K_H 원출력을 결과 JSON에 넣어 커밋할 것.
