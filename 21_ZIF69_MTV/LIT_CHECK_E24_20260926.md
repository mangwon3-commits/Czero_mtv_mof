## 1. 형판 Zn(bib)(bdtdc) 원 논문 — 확인됨
- Zhao, Y.; Xu, X.; Qiu, L.; Kang, X.; Wen, L.; Zhang, B. *"Metal–Organic Frameworks Constructed from a New Thiophene-Functionalized Dicarboxylate: Luminescence Sensing and Pesticide Removal"*, **ACS Appl. Mater. Interfaces 2017** (10.1021/acsami.6b11797, 2017-04-18 — Crossref 메타).
- 논문 주제는 **형광 감지 · 농약 제거** — 제목 · 서지상 **CO₂/N₂ 분리나 CO₂ 포집은 주제가 아님**(본문 미열람 — 부수 측정이 있었는지는 모름). 링커 bdtdc 는 2017 년 당시 "새 링커".
- 뜻: 형판 모체는 **기존 물질**이지만, **CO₂/N₂ 선택 흡착재로서의 평가(E-15 · E-22 · E-25)는 이 프로젝트의 계산 결과**(CoRE 전수 스크리닝이 다른 곳에서 이 행을 이미 짚었는지는 확인 안 함).

## 2. 설계 후보 링커의 합성 근거
- **4,8-디메틸 BDT 골격**: 합성 문헌 있음 — BDT-4,8-다이온 + MeMgBr(그리냐르) → SnCl₂/HCl 환원(유기전자 분야 · "One-Pot Synthesis of 4,8-Dialkylbenzo[1,2-b:4,5-b′]dithiophenes"). 2,6-자리 카복실화는 BDT 에서 흔한 리튬화-CO₂ 경로로 추정 — **이 기질에서 보고됐는지 확인 안 함**.
- **4,8-디시아노 BDT**: 검색에서 **못 찾음**. 관련: BDT-4,8-다이카복실산 제조 특허(4,8-자리 카복시) — 아마이드 경유 탈수로 니트릴 가능성(추정, 확인 안 함). 합성 난이도는 CH₃ 보다 높다고 적음.
- **두 치환 링커로 만든 MOF(특히 Zn(bib) 짝)**: 검색에서 **못 찾음**(약한 음성).

## 3. 최종 설계문에 쓸 문장
"형판 Zn(bib)(bdtdc)는 2017 년 형광 감지 · 농약 제거 물질로 보고된 기존 MOF 이며, 이 프로젝트는 이를 CO₂/N₂ 분리재로 처음 평가했다(계산; 확인 범위 = 웹 · Crossref). 설계 후보 4,8-(CH₃)₂ · 4,8-(CN)₂ 치환판은 확인 범위 안에서 보고를 찾지 못했다 — 전문 DB(SciFinder · CSD) 확인은 향후 과제. 4,8-디메틸 BDT 골격은 합성 선례가 있어 CH₃ 판이 합성 접근성이 더 높다."
