## 2. 설계 후보 링커의 합성 근거
- **4,8-디메틸 BDT 골격**: 합성 문헌 있음 — BDT-4,8-다이온 + MeMgBr(그리냐르) → SnCl₂/HCl 환원(유기전자 분야 · "One-Pot Synthesis of 4,8-Dialkylbenzo[1,2-b:4,5-b′]dithiophenes"). 2,6-자리 카복실화는 BDT 에서 흔한 리튬화-CO₂ 경로로 추정 — **이 기질에서 보고됐는지 확인 안 함**.
- **4,8-디시아노 BDT**: 검색에서 **못 찾음**. 관련: BDT-4,8-다이카복실산 제조 특허(4,8-자리 카복시) — 아마이드 경유 탈수로 니트릴 가능성(추정, 확인 안 함). 합성 난이도는 CH₃ 보다 높다고 적음.
- **두 치환 링커로 만든 MOF(특히 Zn(bib) 짝)**: 검색에서 **못 찾음**(약한 음성).

### 4-1. Zhao et al., ACS Appl. Mater. Interfaces 2017, 9, 15164–15175 (10.1021/acsami.6b11797) — 형판 원 논문
- 화합물 1 = **[Zn(L)(BBI)·(H₂O)₂]**(L = benzo-(1,2;4,5)-bis(thiophene-2′-carboxylate) = 우리 bdtdc, BBI = 1,1′-(1,4-butanediyl)bis(imidazole) = 우리 bib). C2/m · **CCDC 1498478** · Zn 사면체 N₂O₂(Zn–O 2.037~2.065 · Zn–N 1.961 Å) · 카복실레이트 **단자리**(→ 비배위 O 가 있음 — E-22a 의 "이웃 bdtdc 비배위 카복실레이트 O" 와 맞음) · **4중 상호침투 dia** · 용매 접근 빈 부피 **36.6 %**(1161.2/3175 Å³) · c 축 미세 통로 7.9 × 5.7 Å · 기공은 무질서 물이 채움.
- **CO₂ · N₂ · 기체 흡착 · BET 측정 없음**(본문 전체에서 CO₂ 언급 0; "gas adsorption" 은 다른 연구 인용 한 줄뿐). 논문 주제 = 형광 감지(Hg²⁺ · Cu²⁺ · Cr(VI) · 살리실알데하이드) · 농약(2,4-디클로로페놀) 제거(화합물 2).
  → **"이 물질을 CO₂/N₂ 흡착재로 평가한 것은 이 프로젝트가 처음"(원 논문 기준) — 확정.** (다른 곳에서 뒤따른 보고가 있는지는 여전히 전문 DB 밖.)
- 안정성 단서: 물 현탁액에서 감지 · 재생을 **4~5회 반복**(에탄올 세척) — 물 속 구조 유지를 시사. **⚠ [정정 → §6-4] SI PXRD(그림 S20)는 물 순환 4회 뒤 새 봉우리 · 주 봉우리 소실 — 구조 변화. "유지를 시사" 는 틀림.** PXRD · TGA 는 SI(없음 — 본문만). **활성화(물 제거) 뒤 구조 유지 · 기공률은 보고 없음** → 우리 모델(용매 제거 강체 골격)의 전제는 **검증 안 된 가정**으로 한계에 적음.
- **링커 합성 경로(설계에 직접 씀)**: 2,5-디브로모-1,4-벤젠디카복스알데하이드 + 에틸 2-머캅토아세테이트 / K₂CO₃ / DMF 환류 20 h → 비스(티오펜) 다이에스터(43 %) → NaOH 가수분해(95 %). 즉 BDT 고리를 **가운데 벤젠에서 닫는** 경로 — **BDT 4,8-자리 = 출발 벤젠의 3,6-자리 H**.
  → 4,8-(CH₃)₂ 판 링커 = 같은 경로에 **2,5-디브로모-3,6-디메틸테레프탈알데하이드**를 넣으면 됨(그 출발물의 입수성은 확인 안 함). 4,8-(CN)₂ 판은 3,6-디시아노 출발물이 필요하고, 염기 · 티올레이트 조건에서 니트릴이 버틸지 불확실(추정).

### 4-2. Pappenfus et al., Heterocycles 2012, 85, 355–364 (10.3987/COM-11-12390) — 4,8-디알킬 BDT 원팟 합성
- 시판 BDT-4,8-다이온 + 알킬리튬(3.2 당량) → SnCl₂/HCl 환원, 원팟 두 단계. **4,8-디메틸-BDT(DM-BDT) — MeLi, 방법 A, 수율 30 %** · **단결정 구조 결정**(π-적층 없음). 다른 알킬 21~45 %.
  → CH₃ 판 링커의 **핵심 골격은 합성 · 구조 보고가 있음**. 남는 단계 = 2,6-자리 카복실화(BDT 의 2,6-스탄닐화는 유기전자 분야 표준 — 카복실화 자체는 이 논문에 없음, 추정).
- 합성 경로가 둘 — (a) 원 논문식 고리 닫기(치환 테레프탈알데하이드 출발) · (b) DM-BDT → 2,6-다이리튬화 → CO₂. 최종 설계문에 두 경로와 각각의 미확인 단계를 적음.

### 4-3. 설계문 문장 갱신
"형판 Zn(bib)(bdtdc)(CCDC 1498478)는 2017 년 형광 감지 물질로 보고됐고 **기체 흡착은 측정되지 않았다**. 이 프로젝트는 이를 CO₂/N₂ 분리재로 처음 평가했다(계산). 설계 후보 중 **4,8-(CH₃)₂ 판은 핵심 골격(DM-BDT)의 합성 · 구조가 보고돼 있어 합성 접근성이 높고**, 4,8-(CN)₂ 판은 선례를 찾지 못했다. 원 논문은 활성화 뒤 기공률을 보고하지 않았으므로, 계산의 '용매 제거 강체 골격' 전제는 검증되지 않은 가정이다."
