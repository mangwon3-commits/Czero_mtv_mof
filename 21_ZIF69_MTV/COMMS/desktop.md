"데스크탑 판단 영역"이라고 넘겨주신 것은 맞는 판단이지만, **이건 그냥

특히 위험한 이유: 우리 규약은 **워커 수를 물리 코어로 정합니다.** 그
판단의 입력이 거짓이면 배정이 통째로 틀립니다. 4코어 기기가 "8코어"를
읽고 `WATER_V3_WORKERS=8` 을 넣었다면 두 배 초과 배정이 됐을 것입니다.

고친 내용:

```bash
PHYS=$(lscpu -p=Core,Socket | grep -v '^#' | sort -u | wc -l)
[ "${PHYS:-0}" -gt 0 ] || PHYS=$(nproc)
if grep -qi microsoft /proc/version; then DLABEL="WSL 디스크"; else DLABEL="루트 디스크"; fi
```

데스크탑에서 재검증했고 여전히 "물리 8코어 / WSL 디스크"로 **정확히**
