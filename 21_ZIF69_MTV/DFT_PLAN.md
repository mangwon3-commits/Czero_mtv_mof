# 3단계 구상 — 술폰산이 Zn–N 을 끊는가, DFT 로 묻는 법

2026-08-14 작성. **구상만입니다. 계산하지 않습니다.**
착수 여부는 2단계가 끝나고 사용자가 지시할 때 판단합니다.

---

## 0. 이 단계만 답할 수 있는 것

1·2단계가 남기는 구멍은 하나로 좁혀집니다.

| 단계 | 답한 것 | 못 답한 것 |
|---|---|---|
| 1 문헌 | gme 계열 액상 데이터는 충돌, 수증기 데이터 없음 | 술폰산 ZIF 직접 데이터가 세상에 없음 |
| 2 유연 MD | 물이 **기계적으로** 기공을 무너뜨리는가 | 결합형 힘장이라 Zn–N 이 **끊어질 수 없음** |
| **3 DFT** | — | **결합이 끊어지는가. 이게 원래 질문** |

고전 계산이 원리적으로 못 하는 두 가지가 남습니다.

```
① SO₃H + n H₂O  ->  SO₃⁻ + H₃O⁺        전하 재분배. 고정 전하로는 표현 불가
② H₃O⁺ + N(이미다졸레이트) -> Zn–N 절단   결합 생성/소멸. 결합형 FF 로는 표현 불가
```

**우리 GCMC 는 RH90 에서 λ = H₂O/SO₃H = 1.3~1.5 를 줬습니다**(`HYDROLYSIS.md` 2절).
Nafion 계열에서 λ 1~2 는 양성자가 풀리기 시작하는 구간입니다. 즉 우리 계산은
**표현할 능력이 없는 채로 정확히 그 문턱값을 내놓았습니다.** ①을 직접 계산해
이 문턱이 진짜인지 보는 것이 3단계의 출발점입니다.

---

## 1. 클러스터 모형

주기 DFT 는 이 계에 과합니다(단위셀 600~700 원자). 반응이 국소적이므로 클러스터로
자릅니다.

### 자르는 방법

```
        ImH                     반응 자리:  Zn–N(saIm)
         |                      saIm  = 5-술포벤즈이미다졸레이트 (음이온)
   ImH–Zn–N(saIm)               nIm   = 2-니트로이미다졸레이트 (음이온)
         |                      ImH   = 중성 이미다졸 (캡)
        nIm
```

- Zn 하나 + 배위 링커 4개. 반응에 관여하는 **saIm 은 통째로** 넣습니다 — 술폰산이
  붙은 벤조환과 배위 질소가 같은 분자여야 국소 양성자 효과가 잡힙니다.
- 반대편 두 자리는 **중성 이미다졸(ImH)** 로 캡합니다. 이유는 전하입니다:
  Zn²⁺ + 이미다졸레이트 4개 = **알짜 −2** 라 기체상에서 인공적으로 불안정해집니다.
  음이온 둘 + 중성 둘이면 **알짜 0** 이고, 각 Zn 이 실제로는 링커를 이웃 Zn 과
  나눠 갖는다는 사실의 가장 싼 근사입니다.
- 크기: 60~90 원자. def2-SVP 구조 최적화가 8코어에서 감당되는 상한대입니다.

> **이 선택은 진짜 방법론적 결정입니다.** 대안은 (a) Zn 2개를 넣어 링커 하나를
> 양쪽에서 잡는 이핵 클러스터(더 정확, 2~3배 비쌈), (b) 주기 DFT(가장 정확,
> 이 하드웨어로는 불가). **(a) 로 한 점을 재검산해 캡 선택이 결론을 바꾸지 않음을
> 보여야 합니다.** 안 하면 캡이 답을 정했다는 반론에 답할 수 없습니다.

## 2. 두 개의 반응 좌표

### (A) 술폰산 해리 — λ 를 스캔한다

물을 n = 0, 1, 2, 3, 4, 6 개 넣고 두 형태를 각각 최적화합니다.

```
중성형   Ar–SO₃H · (H₂O)ₙ
이온쌍   Ar–SO₃⁻ · H₃O⁺ · (H₂O)ₙ₋₁
```

구하는 것: **이온쌍이 극소점으로 존재하기 시작하는 n**, 그리고 ΔE(n).
우리 λ = 1.3~1.5 와 직접 비교됩니다. 이게 3단계의 절반입니다 —
여기서 "λ 2 이하에서는 해리 안 함" 이 나오면 ②를 볼 필요가 없습니다.

### (B) Zn–N 절단 — 양성자가 있을 때와 없을 때

(A) 에서 해리가 일어나는 조건에서만 진행합니다.

```
1) H₃O⁺ 를 배위 질소 쪽으로 옮긴 구조에서 NEB/스캔으로 양성자 전달 장벽
2) 이어서 Zn–N 거리를 좌표로 잡아 스캔. 빈 자리는 물 하나가 채우게 둔다
   (실제 가수분해는 해리와 물 배위가 협동한다)
3) 대조군: 양성자 없이 물만 있을 때 같은 스캔
```

구하는 것: **양성자 유무에 따른 Zn–N 절단 장벽 차이.** 산이 촉매라는 가설의
직접 시험입니다.

## 3. 계산 설정

| 항목 | 값 | 근거 |
|---|---|---|
| 범함수 | ωB97X-D (또는 B3LYP-D3(BJ)) | 장거리 보정 + 분산. 수소결합·양성자 전달에 표준 |
| 기저 | 구조 def2-SVP / 단일점 def2-TZVP | 이 크기에서 현실적인 타협 |
| 용매 | **연속체 물 쓰지 않음** | 기공 안은 벌크 물이 아님. 물은 **명시적으로** 넣는다(그게 λ) |
| | 필요하면 ε≈4 연속체로 골격 유전 환경만 흉내 | |
| 열보정 | 진동수 계산으로 298 K 자유에너지 | 양성자 전달은 엔트로피가 크게 작용 |
| 전하/스핀 | 0 / 단일항 | Zn(II) d¹⁰ |

**도구는 지금 없습니다.** 후보는 PySCF(pip, 순수 CPU), Psi4(conda), ORCA(무료
등록). 이 계 크기면 구조 최적화 한 건에 수 시간~하루입니다. LAMMPS 에 REAXFF 가
깔려 있지만 **대안이 아닙니다** — ZIF 의 Zn–N–C–H–O–S 를 신뢰할 수 있게 다루는
공개 파라미터가 없습니다. 있는 것처럼 쓰면 고전 MD 의 한계를 반응성 계산의
탈을 씌워 반복하는 것뿐입니다.

## 4. 답을 아는 경우로 먼저 검증 (프로젝트 규약)

계산 전에 아래 셋을 통과해야 본 계산에 들어갑니다.

1. **Zn–N 결합 길이** — 최적화한 클러스터가 결정 구조의 1.98 Å 대를 재현하는가.
   못 하면 캡이나 범함수가 틀린 것입니다.
2. **산세기 순서** — 아릴 술폰산이 아세트산보다 기체상 탈양성자화 엔탈피가 낮게
   나오는가. 범함수가 산 화학을 다루는지 보는 최소 시험입니다.
3. **ZIF-8 산 분해** — 2-메틸이미다졸레이트 클러스터에 H₃O⁺ 를 넣었을 때
   Zn–N 절단 장벽이 298 K 에서 넘을 만한 값으로 나오는가. 문헌이 "산성에서
   빠르게 분해"라고 말하므로 **답을 아는 경우**입니다. 여기서 터무니없는 장벽이
   나오면 설정이 틀린 것이지 결론이 아닙니다.

## 5. 사전 등록 판정 기준

계산 전에 적습니다.

| 판정 | 조건 | 뜻 |
|---|---|---|
| **위험 낮음** | λ ≤ 2 에서 이온쌍이 극소점이 아니거나 중성형보다 20 kJ/mol 이상 높음 | ① 이 시작 안 됨. −SO₃H 계속 가도 됨 |
| **탈락** | λ ≤ 2 에서 해리하고, **또한** 그 양성자로 Zn–N 절단 자유에너지 장벽이 80 kJ/mol 미만 | 298 K 에서 실제로 일어남. ZIF 골격에 −SO₃H 는 성립 안 함 → Zr/Cr 카복실레이트 숙주로 갈아타야 함 |
| **판정 유보** | 그 사이 | 이핵 클러스터·주기 DFT 로 올려야 함. 그 비용을 그때 판단 |

80 kJ/mol 은 298 K 에서 시간 규모가 초~시간대가 되는 대략의 경계라서 골랐습니다.
정밀한 값이 아니라 **의사결정용 선**이고, 계산 전에 정했다는 점이 중요합니다.

> **미리 적어 두는 예상** — λ 1~2 에서 이온쌍이 이미 극소점이고, Zn–N 장벽이
> 경계 근처(60~100)로 나올 것으로 봅니다. 즉 "탈락" 과 "유보" 사이가 가장
> 그럴듯합니다. 그렇게 적어 두어야 나중에 예측이 맞았는지 말할 수 있습니다.

## 6. 이 단계에 들어가기 전 조건

1. **구조 결함 복구** (`STRUCTURE_DEFECT.md`) — DFT 클러스터는 결정 구조에서
   잘라내므로, 관통한 구조에서 자르면 시작 형상부터 틀립니다. **이게 선행입니다.**
2. 2단계(무치환 모체 습윤 MD)가 끝나 기준선이 있을 것.
3. 양자화학 도구 설치와 4절 검증 3건 통과.

## 7. 이 단계를 건너뛰는 선택지

DFT 가 비싸다고 판단되면, 같은 질문에 훨씬 싸게 답하는 길이 하나 있습니다 —
**실험 한 번**입니다. 술폰화 ZIF-69 를 합성해 RH90 에 일주일 두고 PXRD 를 찍는
것이 위 전부보다 쌉니다. 계산이 답할 수 있는 것은 "왜" 이고, "그러느냐" 는
실험이 더 싸게 답합니다. 1단계에서 이 물질의 데이터가 세상에 없다는 것을
확인했으므로, **그 실험 자체가 발표할 가치가 있는 결과**이기도 합니다.
