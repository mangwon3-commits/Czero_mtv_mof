# T-4 판정 — 물 밀도 피크는 치환기 O/N 3 Å 밖이다 (2026-09-05, laptop2)

**판정: 세 구조 모두 "결함형 자리 아님". 등록 가설(report6 위치 가설) 지지.**

등록: `ASSIGN_20260905.md` §2. 문턱 3 Å, 통계 "물 밀도 최대 피크에서 치환기 O/N
까지 최단거리". 격자는 **질량중심(COM)**, 후보 집합은 **모든 O + Zn 비배위 N**
(둘 다 결과 전 확정, 커밋 `09241a9`).

---

## 1. 판정

| 구조 | 최대 피크 → 치환기 최단거리 | 문턱 3 Å | 판정 |
|---|---:|---|---|
| `base` | **3.860 Å** | 밖 | 결함형 자리 아님 |
| `nbIm025` | **3.255 Å** | 밖 | 결함형 자리 아님 |
| `saIm050` | **3.181 Å** | 밖 | 결함형 자리 아님 |

등록문은 음성을 **의미 있는 결과**로 적어 두었다 — *"nbIm025 에서 NO₂ 주변 피크
없음 → report6 위치 가설 지지"*. **그 결과가 나왔다.**

## 2. 판정 전에 두 봉쇄를 걷어냈다

**(a) 후보 집합 — 자동 통과** (결과 전, `09241a9`)
`elements=('O','N')` 으로 고르면 이미다졸레이트의 **Zn 배위 N 이 구조당 96개**
섞인다. 골격 전체에 깔려 있어 **어느 복셀이든 3 Å 안**에 들어오고 판정이 무조건
통과한다. → **모든 O + Zn 에 배위하지 않은 N** 으로 확정(base 72 / nbIm025 90 /
saIm050 108). 비배위 N 은 니트로 N 과 일치한다(세 구조 검증).

**(b) 문턱 도달성 — 자동 기각** (판정 직전 발견, 데스크탑 결정 `11cd13d`)
`overlap_density.accessible_mask` 가 **골격에서 3.0 Å 초과** 복셀만 남기는데
(`ACCESSIBLE_MIN = 3.0`), 치환기 O/N 은 골격의 부분집합이다. 그러면
**`d ≤ 3.0` 인 복셀이 존재할 수 없다** — 실측 최소거리가 3.0228 / 3.0009 /
3.0004 로 전부 3.00 바로 위에 붙었다.

`ACCESSIBLE_MIN` 은 **T-4 등록 사항이 아니다**(T-6 겹침용 구현값). 그래서 걷는
것은 시험을 고치는 게 아니라 **복원**이다. 데스크탑이 그렇게 결정했다.

> **(a)는 자동 통과, (b)는 자동 기각. 거울상이다.** 나는 아침에 (a)만 검사하고
> (b)는 검사하지 않았다 — **문턱이 무엇을 떨어뜨리는지만 보고 무엇을 통과시킬 수
> 있는지는 안 봤다.**

## 3. 도달 가능성 (데스크탑 등록 `11cd13d`, 수 보기 전)

마스크를 걷은 뒤 치환기 3 Å 이내 복셀에 대해:

| 구조 | 3Å내 복셀 | (가) 밀도 0 아님 | (나) 중앙값 이상 | 3Å내 밀도 몫 |
|---|---:|---:|---:|---:|
| `base` | 221,856 | **3,656** | 3,656 | 4.52% |
| `nbIm025` | 293,608 | **7,304** | 7,304 | 6.69% |
| `saIm050` | 374,976 | **18,288** | 16,360 | 22.94% |

**셋 다 (가)·(나) 예 → 도달 가능 → 등록 통계로 판정한다.**

## 4. 최대 피크가 결정된 위치인가 (데스크탑 등록, 수 보기 전)

| 구조 | N_max | √N_max | 문턱 계수 | n_tie | 거리 범위 |
|---|---:|---:|---:|---:|---|
| `base` | 3,041 | 55.1 | 2,986 | **8** | 3.860 ~ 3.860 |
| `nbIm025` | 5,118 | 71.5 | 5,046 | **8** | 3.255 ~ 3.255 |
| `saIm050` | 19,150 | 138.4 | 19,012 | **8** | 3.181 ~ 3.181 |

**n_tie = 8 이지만 거리 범위가 0 이다.** 여덟은 **2×2×2 슈퍼셀의 대칭 복제**이지
경쟁하는 서로 다른 자리가 아니다.

**[강화, 데스크탑 독립 검산 + laptop2 재확인]** 개수가 아니라 **구조**로 보인다 —
동률 복셀 8개의 분율좌표가 **각 축에서 정확히 두 값**이고 **간격이 0.500000** 이다:

    base      축0 {0.333, 0.833}   축1 {0.178, 0.678}   축2 {0.044, 0.544}
    nbIm025   축0 {0.078, 0.578}   축1 {0.400, 0.900}   축2 {0.367, 0.867}
    saIm050   축0 {0.411, 0.911}   축1 {0.089, 0.589}   축2 {0.111, 0.611}

**세 구조 아홉 축 전부 간격 0.500000 — 2×2×2 반셀 병진, 2³ = 8.**
그러면 **"경쟁 자리가 아니다" 가 개수가 아니라 구조에서 나오고, 거리 범위 0 은
그 따름정리**다. (`check_t4_halfcell.py`) 등록 규칙의 "n_tie > 1 이나 전부 3.0 밖 → 판정
유지, n_tie 병기" 에 해당하며, **거리 범위 0** 이 그보다 강한 진술이다 —
**피크 자리는 대칭을 빼면 유일하다.**

(별건의 정합성 확인이기도 하다. **간격이 세 축 모두 정확히 0.500000** 이면 육방 셀
좌표 환원이 분율 기반으로 옳게 접힌다는 뜻이며, 정방정계 가정이 남아 있었다면
이 값이 깨진다. **판정과 무관한 축에서 나온 확인**이라 값어치가 있다.)

## 5. 병기 — 판정과 함께 읽어야 하는 것 **다섯**

**(가) 실행 간 산포 미측정 — 세 구조 전부.**
씨앗이 넷 다 다르다(러너에 `RandomSeed` 가 없어 RASPA 가 폴더 생성 시각으로
만든다. `RASPA_SEED_20260828.md:26-37`):

    base 1차(격자 유실)  1788537972      nbIm025  1788537975
    saIm050             1788537979      base 재실행 1788559403

세 격자가 **전부 실현 1개**다. 따라서 **구조 간** 거리 차이(3.860 / 3.255 /
3.181)는 어느 쌍이든 실행 간 산포를 탄다. 구조 **내** 판정(자기 치환기까지의
거리)은 영향 없다.
⚠ 이전 판에 있던 *"씨앗 간 최댓값 변동 28%"* 는 **1차 출처가 없어 폐기**했다
(데스크탑 전수 감사 `7b799b8`). 실측 동종 산포는 원계수 기준 **9~16%** 다.

**(나) `nbIm025` 는 14,500/15,000 사이클 판** (96.7%).
완주 직후 `run_water.py:267` 이 VTK 를 지우는데 그 삭제가 최종 기록과 **1초 안**
이라 20초 폴링이 졌다. 통계 잡음 증가는 `√(15000/14500) = 1.017` 로 **1.7%**.
`base`·`saIm050` 은 온전한 최종판이다(하드링크로 확보).

**(다) `base` 도 니트로 24개를 가진 구조다.**
ZIF-69 = Zn(nIm)(cbIm) 이고 nIm 이 니트로이미다졸레이트다. 치환은 cbIm 의 −Cl
자리에서 일어난다.

    base 니트로 24 · nbIm025 니트로 30 · saIm050 니트로 24 (O 만 48→84)

**대비는 '니트로 유무' 가 아니라 '니트로 밀도 +25%'** 이며 등록 가설이 상정한
것보다 약하다. 그러므로 "피크 없음" 은 **니트로가 물을 안 끈다는 증거가 아니라
이 대비로는 구별되지 않는다**까지만 말한다.
데스크탑 §1-5 사다리가 같은 방향의 독립 증거다 — nbIm025 는 f = 0.429±0.134 로
**25% 치환에서 −NO₂ 효과가 아직 안 올라와 있다.**

**(라) 도달 가능성 (나)는 독립 확인이 아니다.**
`base`·`nbIm025` 에서 접근가능 중앙값이 **계수 1개**(1/3,041, 1/5,118)라
`≥ 중앙값` 이 `≥ 계수 1` 이고 **(가)와 동일한 조건**이 된다(수가 정확히 같다:
3,656 / 7,304). `saIm050` 만 중앙값이 계수 2 라 (나)가 조금 더 엄하다.
**사실상 (가) 하나로 판정한 것이다.**

**(마) ⚠ 물 힘장에 `Hw` LJ 가 잘못 들어가 수소결합이 억제돼 있다 — 이 시험의
부정 결과는 그 결함으로도 설명된다.**

랩탑 발견(`WATER_FF_DEFECT_20260905.md`), 데스크탑·laptop2 가 각자 실행에서 확인.
**이 판정에 쓴 격자에서 직접 확인했다**:

    내 출력 (rh90_base)   Hw - Hw   p_0/k_B **22.14170**   p_1 **2.57113**
    UFF_MOF 17행          H_        lennard-jones  22.1417  2.57113   <- **완전 일치**
    배포본 Dubbeldam2007  42-43행   **Lw none / Hw none**  <- 우리 파일엔 **없다**

`UFF_MOF/force_field_mixing_rules.def` 에 `Hw`·`Lw` 항이 없어 RASPA 가 **앞자리
일치**로 `Hw` → `H_`(UFF 수소)를 물려준다. `Lw` 가 멀쩡한 것은 `L` 로 시작하는
형이 없어서일 뿐 **운**이다.

**왜 이 판정에 직접 걸리는가**: T-4 는 *"물이 치환기 O/N 주변에 앉는가"* 를 묻고
**"앉지 않는다"** 로 나왔다. 그런데 물을 그 자리에 앉히는 힘이 **수소결합**이고,
치환기 −SO₃H·−NO₂ 는 수소결합 주개/받개다. **부정 결과를 만들어 낼 결함이 정확히
그 자리에 있다.**

    랩탑 실측: 이합체 우물 **-22.9 → -10.0 kJ/mol**, 최소 위치 **2.70 → 3.60 Å**
    (방위각 최적화판: 수정 -28.36 @ 2.68 Å / 현행 -12.76 @ 3.55 Å)

⚠ **에너지는 배치에 민감하다.** 데스크탑이 다른 배치로 -19.01 @ 2.72 를 얻었다 —
**거리는 0.05 Å 안에서 재현되는데 에너지는 배치에 1.56배 민감**하다.
**거리만 인용하고, 에너지를 쓸 때는 배치 조건을 붙일 것.**
               액체 O-O 첫 봉우리 3.32 Å(물 2.80), g(2.82)=0.18(물 ≈2.9) — 첫 껍질 없음

**T-4 의 3 Å 문턱은 수소결합 거리에서 나왔는데 이 힘장의 물은 3.6 Å 아래로 잘 안
간다.** 측정된 피크 거리 **3.181~3.860 Å** 이 그 3.60 Å 근처인 것도 정합적이다.

> **판정을 뒤집지 않는다. 다만 이 부정 결과에서 구조의 성질과 힘장의 결함이
> 분리되지 않는다.** 힘장을 고친 뒤 재실행해야 갈린다.

## 5b. 거리 세 개가 단조다 — **관찰이며 증거가 아니다** (데스크탑 지적)

    base 3.860  ->  nbIm025 3.255  ->  saIm050 3.181      0.68 Å 이동, 단조

판정은 "셋 다 3 Å 밖" 이다. **이 배열을 "치환이 물을 끌어당긴다" 로 읽으면 안 된다:**

- **실현 1개씩**이고 실행 간 산포가 미측정이다 (병기 (가))
- 세 구조의 3 Å 이내 **복셀 수가 다르다**(221,856 / 293,608 / 374,976) — 기하가 다르다
- **사후다.** 등록 통계는 문턱 통과 여부이지 **거리의 순서가 아니다**

**관찰로만 적는다.** 안 적으면 병기가 넷이어도 이 세 수만 인용된다.
§6 의 4.5/6.7/22.9% 를 탐색으로 격리한 것과 같은 처리다.

## 6. 탐색 기록 — 판정에 쓰지 않음

마스크를 걷고 **3 Å 이내 영역의 밀도 몫**을 보면 base 4.5% / nbIm025 6.7% /
**saIm050 22.9%** 로 saIm050 이 base 의 5배다. **이 통계는 봉쇄를 발견한 뒤에
고른 것이라 사후이며 T-4 의 답이 아니다.** 데스크탑도 같은 이유로 채택을
기각했다(*"판정자를 바꿔도 사후는 사후"*). 쓰려면 **아직 보지 않은 구조**에서
새로 등록해야 한다.
