## 6. 정의역 — **이 판정은 `D < 41` 에서 유효합니다** (랩탑 지적, 14:3x)

§3 에 *"어느 대조 결과가 나와도 ① 은 판별력이 없습니다"* 라고 적었는데
**정의역이 빠졌습니다.** 경계는 3 이 아니라 **41** 입니다.

수정판 `K_H = 현행 / D` 이므로 조성 i 는 **`D < (그 조성의 배수)`** 동안 문턱 위입니다:

    `mbIm025` (최소)  **41배**   ->  D < 41
    `base`             114배     ->  D < 114
    `saIm0583` (최대)  628배     ->  D < 628

    **D < 41**        32/32 전량 문턱 위 유지  ->  **① 판별력 0. 이 판정 유효**
    **41 ≤ D < 628**  일부가 문턱 아래로       ->  **① 이 판별력을 *얻습니다*. 재판정 대상**
    **D ≥ 628**       전량 문턱 아래           ->  반대편에서 다시 판별력 0

> **판별력 없다고 판정한 시험이 결함을 고치면 살아날 수 있습니다.**
> *"어느 결과가 나와도 안 바뀐다"* 가 아니라 ***"이 구간에서 안 바뀐다"*** 입니다.
> **주장에는 정의역을 함께 적습니다.**

### 6-1. ⚠ `D ≥ 41` 에는 **부호 전제**가 숨어 있습니다

Widom 에서 `K_H ∝ ⟨exp(−βU)⟩` 이므로:

    `Hw` 항이 **반발**(ΔU > 0)  ->  현행이 **작다**  ->  **D < 1**
    `Hw` 항이 **인력**(ΔU < 0)  ->  현행이 **크다**  ->  **D > 1**

    |ΔU|  1 kJ/mol -> 1.50배   3 -> 3.36   5 -> 7.52   **9.2 -> 41.0**   (RT = 2.478)

**`D ≥ 41` 은 `Hw`–골격이 순 인력 9.2 kJ/mol 일 때만 나옵니다.**
크기 감각으로 든 액체의 **+18.06 kJ/mol 은 반발**이라 **방향이 반대**이고
(그리고 물–물이라 물–골격에 옮길 수 없습니다), 그 값이 그대로 통하면
**`D < 1` 쪽입니다 — 그러면 모든 조성이 문턱에서 더 멀어지고 ① 은 더 확실히 판별력 0** 입니다.

    Lorentz-Berthelot 쌍당 우물   Hw–C_ 0.284 · Hw–O_ 0.215 · Hw–N_ 0.231 · Hw–S_ 0.459 kJ/mol
    -> 9.2 kJ/mol 을 순 인력으로 모으려면 **우물 깊이 기준 30~50쌍**

**불가능하지는 않지만 작지 않은 요구입니다.**

#### 6-1-1. ⚠ 위 부호 논거는 **1차항만** 본 것입니다 (랩탑 정정, 14:4x)

`D` 는 **평균의 지수가 아니라 지수의 평균**입니다:

    D = **⟨exp(−βΔU)⟩_w**  ≠  exp(−β⟨ΔU⟩)      가중 w = exp(−βU_수정)

    ln D  ≈  −β⟨ΔU⟩_w  +  **(β²/2)·Var_w(ΔU)**
                          ^^^^^^^^^^^^^^^^^^^ **항상 ≥ 0** (Jensen)

    ⟨ΔU⟩   σ      ln D      D
      0.0  3.0   +0.73   **2.08**
      1.0  3.0   +0.33   **1.39**
      2.0  3.0   −0.07     0.93
      3.0  5.0   +0.83   **2.28**   <- **반발 3 kJ/mol 인데도 D > 1**

**분산 3 kJ/mol 이면 반발 2 kJ/mol 까지 상쇄합니다.** 그러므로 *"반발이니까 D<1"*
은 **성립하지 않습니다.** 그리고 **Widom 가중이 유리한 자리를 지수적으로 골라내므로**
자리마다 H 방향이 달라 **`Var_w` 가 큽니다** — **아침의 검사 10(잔여값의 함정)이
구조가 아니라 가중에서 반복되는 것**입니다.

> **그래서 `+18.06 kJ/mol` 은 크기도 부호도 못 옮깁니다.**
> 크기는 회피로 줄고, **부호는 분산항으로 뒤집힐 수 있습니다.**

**단, 위 수치는 가우스 가정에서만 유효합니다.** `D=41` 에 필요한 분산을 역산하면
`σ ≈ 6.8~8.7 kJ/mol` 이고 그때 `βσ ≈ 2.7~3.5` 라 **2차 절단이 성립하지 않습니다.**
**가정 없이 남는 것은 Jensen 부등식 — 분산은 항상 `D` 를 올린다 — 뿐입니다.**

**결론은 등록을 안 바꿉니다.** 이 분석은 **부호를 정하는 것이 아니라, 정할 수 없는
이유를 하나 더 대는 것**입니다. `TB2_CONTROLS_20260905.md` (다)-2 가 **부호를
가정하지 않고 양측으로** 등록해 둔 판단이 맞았습니다. **(다)로 재야 합니다.**

### 6-2. `41 ≤ D` 가 나오면 **(다) 1건으로는 재판정 못 합니다**

골격 조성이 다르면 `Hw`–골격 항도 다릅니다. **단일 `D` 로 32개를 나누는 것은 근사**이고,
재판정하려면 **32종을 수정 힘장으로 다시 재야** 합니다. **(다)는 `base` n=1 입니다.**
