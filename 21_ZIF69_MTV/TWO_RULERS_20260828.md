## 1. 두 자

| | 분모 | 문턱 1.5 의 실제 엄격도 |
|---|---|---|
| **통계 자** | RASPA `±` (= 95% CI = 2.776 × SEM) | **4.16 진짜 σ** |
| **배치 자** | 실현 표본 SD (진짜 1σ) | **1.5 진짜 σ** |

**2.776배 차이입니다.** 같은 "1.5 단위" 라고 적혀 있어도 한쪽은 다른 쪽보다
2.776배 넘기 어렵습니다.

> `ERROR_BARS.md` 가 *"의도보다 훨씬 엄격한 자"* 라고 한 것을 뒤집으면 —
> **1.5σ 가 원래 의도한 자입니다.** 어긋난 쪽은 통계 자이고 그건 이미
> 그 문서에 전수 조사돼 있습니다. **배치 자를 쓴 판정들은 의도한 자

## 4. 그런데 머리기사 안에 실물이 하나 있습니다

`saIm0583 0.7306` 대 `base 0.4692` 한 비교가 **세 값으로 적혀 있습니다.**
전부 재현했습니다:

```
d = 0.2614

  분모 0.0237  ->  11.03 단위    앙상블 평균의 SE (n=6)
                                 VERDICT_REVISION 63행의 **11.0**
  분모 0.0580  ->   4.51 단위    앙상블 배치 SD (n=6)
                                 NEW_MACHINE_20260822 52행의 **4.51**
  분모 0.0591  ->   4.42 단위    배치 SD ⊕ base 의 RASPA ±(0.0112)
                                 VERDICT_REVISION 219행 머리기사의 **4.4**
```

**세 값 다 옳고, 서로 다른 물음의 답입니다:**

- **11.0** — *"이 앙상블의 평균이 base 와 다른가"*
- **4.51** — *"새 배치를 뽑아도 base 를 이기는가"*
- **4.42** — 위 물음에 base 자신의 통계오차까지 얹은 것

**머리기사에 맞는 물음은 두 번째**입니다. 우리가 주장하는 것은 "이 여섯
실현의 평균이" 가 아니라 "치환하면" 이므로, 새 배치가 뽑혀도 서야 합니다.

> **4.4 는 배치 SD(진짜 σ)와 RASPA `±`(95% CI)를 한 분모에 넣었습니다.
> 두 자를 섞은 값입니다.** 다만 `base` 의 `±` 가 배치 SD 에 비해 작아
> 효과가 4.51 → 4.42 (2%) 뿐이라 **판정은 안 바뀝니다.** 결함은 실재하고
> 결과는 무해합니다.
>
> `base` 의 `±` 0.0112 는 `v3_wc/working_capacity.json` 의 **건조** 조건
> 값입니다. 습윤 조건의 `±` 는 JSON 에 없어 실행 폴더를 봐야 합니다.
> 4.42 가 재현된다는 것이 습윤 `±` 도 비슷하다는 **정황**이지 확인은
> 아닙니다.

### ⚠️ 6-1. 여는 김에 나온 별건 — 유지율 사다리가 분모를 두 가지로 씁니다

**자 문제가 아닙니다.** 같은 표 안에서 `√2` 를 붙였다 뗐다 합니다:

```
5.25 · 6.53   분모 3.41 %p        = 배치SD **한 개**
2.65 · 3.22   분모 4.82 %p        = 배치SD × **√2**
```

**규칙은 있습니다** — 한쪽이 배치 자유도 0 이면 그쪽은 산포를 안 내므로
`√2` 를 빼야 합니다. `C(24,0) = 1` 인 **`base`** 에는 제대로 적용돼
있습니다(5.25 · 6.53).

**그런데 `saIm100` 도 `C(24,24) = 1` 로 배치 자유도가 0 입니다.**
그런데 `saIm100` 이 들어간 두 칸에는 `√2` 가 붙어 있습니다:

| | 지금 | `√2` 빼면 |
