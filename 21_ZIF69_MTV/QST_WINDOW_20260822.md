# Q_st 목표대 30~40 kJ/mol 의 정량 근거 (2026-08-22 재유도)

Part 0-C 3절의 ZIF-8 시대 유도를 v3 데이터로 다시 계산한 것. 노션 정본은
Part 0-C **3-A절**. 이 파일은 재현용 수치와 절차 기록.

## 무엇이 달라졌나

| | ZIF-8 시대 (Part 0-C 3절) | v3 (이 문서) |
|---|---|---|
| 회귀 점 수 | 9 | **38** |
| Q 측정 구간 | 14~23 | **22.4~34.0** |
| 목표 창과의 관계 | **바깥에서 외삽** | **창을 감쌈** |
| 현열 | **미반영**(3-6절이 한계로 명시) | **반영** |

## 모형

랑뮈어 + 반트호프. 전지수 인자는 임의값이 아니라 v3 실측 (Q_st, K_H) 38쌍의
회귀에서 얻는다.

```
ln K_H = -13.979 + 0.4511 * (Q_st / RT298)     R² = 0.945
n(T,p) = n_sat * b(T)p / (1 + b(T)p),  b = K_H / n_sat
b(T) = b(298) * exp[(Q_st/R)(1/T - 1/298)]
공정: 흡착 298 K / 탈착 373 K, 둘 다 p(CO2) = 0.15 bar
총 에너지 E = Q_st + 67.5/WC   (현열 = Cp·ΔT/WC, Cp 0.9 J/g/K, ΔT 75 K)
```

기울기 0.451 (≠1) 은 엔탈피–엔트로피 보상. ZIF-8 시대 추정 0.259 보다 약하다.

**모형 검증**: 무치환 모체 예측 로딩 0.580 mol/kg 대 실측 0.589.

**핵심 둘.**

1. **현열을 넣으면 최적이 39~46 에서 36~38 로 내려온다.** 현열이 작업 용량에
   반비례하므로, 결합을 세게 만드는 것보다 용량을 키워 난방비를 희석하는 쪽이
   이긴다. Part 0-C 3-6절이 예고했던 방향 그대로.
2. **그 값이 가정에 둔감하다.** n_sat 을 3배(2.0→6.0) 바꿔도 최적 Q 는
   2 kJ/mol 만 움직인다(36.0→38.0). 작업용량 기준(38.9→46.4, 7.5 움직임)과
   대조적이다. 현열 항이 최적점을 붙들어 맨다.

## 두 끝의 성격이 다르다

- **하한 30 — 에너지에서 유도된 값.** 어떤 n_sat 가정에서도 30~32 이고,
  그 아래는 총 에너지가 가파르게 오른다.
- **상한 40 — 에너지가 허용하는 값(약 45)보다 보수적.** 근거가 다른 데 있다:
  (i) 물리흡착/화학흡착 경계가 그 부근이고 아민계(80~100)를 넣으면 총
  에너지가 549 로 발산한다. (ii) 본 계열에서 Q_st 를 40 가까이 올리려면
  치환율을 크게 높여야 하는데 **구조 안정성 관문이 먼저 닫힌다**(Part 7 7-2절).

## 이 재유도가 바꾸지 않는 것

**목표대 30~40 은 그대로다.** 사전 등록된 관문이므로 결과를 보고 고치지
않는다. 이 계산은 그 창을 **정당화**한 것이지 이동시킨 것이 아니다.

남은 한계: 단일 성분이라 수분 경쟁이 안 들어간다(그래서 실제 판정 지표는
습윤 작업 용량이다). C_p 0.9 는 문헌 대표값이고 0.6~1.2 에서 총 에너지가
1.6~1.8배 움직인다. 열회수 0% 의 보수적 상한. 그리고 모든 흡착 자리가 같은
Q_st 를 갖는다고 가정하므로 **평균이 감추는 분포의 꼬리**는 이 모형도 못 본다
(Part 0-C 2-3절).
