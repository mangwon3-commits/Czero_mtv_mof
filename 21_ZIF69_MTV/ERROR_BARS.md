# RASPA 의 `±` 는 1σ 가 아닙니다 — 95% 신뢰구간입니다

> **[09-05 추가] `±` 두 개의 *비* 에는 환산이 필요 없습니다.**
> 분산 검정에 진짜 1σ = `±/2.776` 이 필요하다는 규칙이 **비에는 안 걸립니다** —
> `(±₁/2.776)/(±₂/2.776) = ±₁/±₂` 로 약분됩니다. **환산해도 같은 답이고,
> 한쪽만 환산하면 틀립니다.** 두 `±` 의 비는 F 검정으로 바로 봅니다
> (dof 4/4 양측 5% 임계 = √F(0.975,4,4) = **3.099**).
> `21_ZIF69_MTV/TB2_CONTROLS_20260905.md` (다)-7.

**작성 2026-08-23. 계기: 랩탑이 saIm0667 의 큰 오차를 확인하려고 블록
다섯 개를 보내온 것.**

## 무엇을 발견했나

RASPA 출력의 `Average loading absolute ... +/- X` 에서 X 는 **블록 평균
다섯 개의 95% 신뢰구간**입니다. 표준오차(1σ)가 아닙니다.

    X = t(0.975, dof=4) x s_block / sqrt(5) = 2.776 x SEM

`CLAUDE.md` 2절은 이 값을 **"1σ"** 라고 부르고 있습니다. 그 이름이 틀렸습니다.

## 무엇이 틀렸고 무엇이 안 틀렸나

**틀린 것은 이름 하나뿐입니다.**

| | 상태 |
|---|---|
| 문서·장표의 "오차막대 1σ" 표기 | ❌ **틀렸습니다.** 95% 신뢰구간입니다 |
| "2.10σ", "6.50σ" 같은 비 | ⚠️ 숫자는 맞지만 **단위 이름이 σ 가 아닙니다** |
| 모든 순위·관문 판정 | ✅ **그대로 유효합니다** |
| 과대 주장 | ✅ **없습니다** — 전부 보수적이었습니다 |

비교의 양쪽에 **같은 자**를 썼기 때문에 모든 비교는 내부적으로 일관됩니다.
그리고 95% 신뢰구간은 1σ 보다 2.776배 넓으므로, 지금까지 적은 모든
유의도는 **진짜 σ 로 환산하면 2.776배 커집니다.** 즉 우리는 계속
**실제보다 덜 유의하다고 적어 왔습니다.** 철회할 결론이 없습니다.

`1.5σ` 문턱은 실제로는 `1.5 x 95%CI ≈ 4.16 진짜 σ` 를 요구해 왔습니다.
의도보다 훨씬 엄격한 자였습니다.

### 어느 쪽이 옳은가 — ~~아직 정하지 않습니다~~ **2026-09-06 (다) 로 결정 (아래 끝 절)**

    4.16σ  CLAUDE.md 문언에 충실. 그러나 배치 비교에서는 아무것도 검출 못 함
    1.5σ   배치 비교에 실용적. 그러나 §2 문언보다 훨씬 느슨

**두 자가 재는 대상이 다릅니다** — `±` 는 *한 구조를 다시 돌렸을 때*의 요동,

### 이름 규칙(영구) — 2026-09-06 사용자 결정 (다), `RULER_DECISION_20260828.md` §7

**문턱 1.5 는 어느 쪽도 옮기지 않았습니다. 이름만 갈랐습니다.**

    분모가 RASPA `±`(95% CI)        ->  **단위**        통계 비교(같은 구조 재실행, 단일 실현끼리, 씨앗 반복)의 판정 자
    분모가 실현 표본 SD(진짜 1σ)     ->  **배치 단위**   배치 비교(앙상블끼리, 앙상블 대 base, 관문 n실현)의 판정 자
    두 자를 섞은 분모                ->  `단위(혼합 95%)` + 비중. **새로 만들지 않음**
    표기                             ->  **항상 둘을 나란히**: `0.40 배치 단위 · 0.14 단위(±)`. 한쪽만 인용 금지

위 Junseok 물 비교는 이 규칙으로 **판정 0.40 배치 단위(미검출) · 병기 0.14 단위(±)** 로 읽습니다 — 결론 불변.
"당장의 규칙" 은 이 절로 영구 규칙이 됐습니다.
