# RASPA 의 `±` 는 1σ 가 아닙니다 — 95% 신뢰구간입니다

**작성 2026-08-23. 계기: 랩탑이 saIm0667 의 큰 오차를 확인하려고 블록
다섯 개를 보내온 것.**

## 무엇을 발견했나

RASPA 출력의 `Average loading absolute ... +/- X` 에서 X 는 **블록 평균
다섯 개의 95% 신뢰구간**입니다. 표준오차(1σ)가 아닙니다.

    X = t(0.975, dof=4) x s_block / sqrt(5) = 2.776 x SEM

`CLAUDE.md` 2절은 이 값을 **"1σ"** 라고 부르고 있습니다. 그 이름이 틀렸습니다.

## 검산 — 서로 다른 네 건, 전부 2.776

| 출처 | 블록 1σ | SEM | 파일의 `±` | 비 |
|---|---|---|---|---|
| 우리 rh90_saIm0583 (분자수) | 0.93748 | 0.41925 | 1.16384 | **2.7760** |
| 랩탑 0625/RH0 | 0.01087 | 0.00486 | 0.0135 | **2.777** |
| 랩탑 0667/RH0 | 0.02428 | 0.01086 | 0.0301 | **2.773** |
| 랩탑 0667/RH90 | 0.03118 | 0.01394 | 0.0387 | **2.775** |

`t(0.975, 4) = 2.7764`. 우리 자신의 `.data` 에서 블록값을 직접 읽어
재현했습니다 — 랩탑 수치에만 기댄 결론이 아닙니다.

```
Block[ 0] 68.58233   Block[ 1] 69.31100   Block[ 2] 66.99633
Block[ 3] 69.02967   Block[ 4] 67.85633
Average loading absolute  68.3551333333 +/- 1.1638419351
```

## 무엇이 틀렸고 무엇이 안 틀렸나

**틀린 것은 이름 하나뿐입니다.**

| | 상태 |
|---|---|
| 문서·장표의 "오차막대 1σ" 표기 | ❌ **틀렸습니다.** 95% 신뢰구간입니다 |
| "2.10σ", "6.50σ" 같은 비 | ⚠️ 숫자는 맞지만 **단위 이름이 σ 가 아닙니다** |
| 모든 순위·관문 판정 | ✅ **그대로 유효합니다** |
| 과대 주장 | ✅ **없습니다** — 전부 보수적이었습니다 |

비교의 양쪽에 **같은 자**를 썼기 때문에 모든 비교는 내부적으로 일관됩니다.
그리고 95% 신뢰구간은 1σ 보다 2.776배 넓으므로, 지금까지 적은 모든
유의도는 **진짜 σ 로 환산하면 2.776배 커집니다.** 즉 우리는 계속
**실제보다 덜 유의하다고 적어 왔습니다.** 철회할 결론이 없습니다.

`1.5σ` 문턱은 실제로는 `1.5 x 95%CI ≈ 4.16 진짜 σ` 를 요구해 왔습니다.
의도보다 훨씬 엄격한 자였습니다.

## 덤 — 앙상블 프로토콜의 단위도 섞여 있습니다

`ENSEMBLE_0583_PROTOCOL.md` 의 `s_ens / σ_stat = 7.15배` 에서 `s_ens` 는
6실현의 진짜 표본 표준편차(1σ)이고 `σ_stat` 은 95% 신뢰구간입니다.
**두 다른 자를 나눈 값입니다.** 같은 자로 맞추면 약 19.9배입니다.

방향은 안전합니다 — 배치 분산을 실제보다 작게 보이게 하는 쪽이므로
"배치 분산 실재" 라는 판정은 오히려 더 강해집니다. `σ_total =
√(σ_stat² + s_ens²)` 도 넓은 쪽 값을 넣고 있어 보수적입니다.

여기도 같은 권고입니다: **이름을 고치고 숫자는 두십시오.**

**긍정 주장은 전부 강해지기만 합니다.** 문턱 대비·조성 대비 모두 2.776배로

### 뒤집히면 문장이 달라지는 곳은 한 군데입니다

보고서 §8 의 **"유지율은 단조 감소가 아니라 25~75% 구간에서 76~80%의
고원을 이룬다"** — 이 고원은 025 vs 050 이 구별 불가라는 데 기대고 있습니다.
환산하면 025(80.45) 가 050(76.07) 보다 유의하게 높아지고, 모양이

    base 98.35 -> 025 80.45 -> 050·075 ~76.5 (평평) -> 100 60.56

즉 **한 단 내려가고, 평평하고, 절벽** 이 됩니다. 이것은 08-20 에 외부
기기와 합의해 기각했던 "단조 감소" 문구에 오히려 가까워집니다.

**포스터 그림 3 의 결론(문턱 현상)은 그대로입니다** — 100% 의 절벽이
15.4σ 로 남기 때문입니다. 바뀌는 것은 고원의 시작점 서술뿐입니다.

    평균 비교   두 점추정을 견주는 **관습 단위**

### 왜 예외인가 — 관습이 아니라 정의입니다

`χ² = Σ(x − x̄)² / σ²` 의 `σ` 는 **모집단 표준편차**입니다. 2.776배 넓은
구간을 넣으면 다른 단위가 아니라 **그냥 틀린 계산**입니다.

> **평균 비교는 문턱을 같이 스케일하면 결과가 안 바뀝니다.
> 분산 검정은 안 바뀌는 게 아니라 틀립니다.**

그리고 **자를 바꾼 것이 아닙니다** — 카이제곱은 08-27 이 처음이라 흔들
과거가 없습니다. 위 문단의 "환산 금지" 는 그대로 유효합니다.
