## 1. §7-3 비교 A — **러너 축 확인**

    F = s²(통짜, dof 3) / s²(분할, dof 3) = 0.006733² / 0.001678² = **16.093**
    양측 5% 임계   F(0.975,3,3) = 15.44     F(0.025,3,3) = 0.0648

    F = 16.093 ≥ 15.44   ->   **러너 축 확인**

**분할 러너가 실행 간 산포를 줄입니다.** 등록문 그대로 **기제는 주장하지
않습니다**(RandomSeed 없음 · 마르코프 사슬 논지 미해결).

> ⚠️ **등록된 금지 문구를 유지합니다** — *"분할 러너가 더 재현성이 높다"* 는
> 이 판정으로도 **쓰지 않습니다.** §7-5 가 보인 것은 `±` 가 같은 추정량이라는
> 것뿐이고, **작은 s_rep 이 품질인지 시험 민감도 저하인지는 이 자료로 갈리지
> 않습니다.** 다음 라운드 등록 사항: 분할 러너의 `±` 가 무엇을 재는지.

임계를 0.65 넘긴 값입니다(16.09 대 15.44). 문턱 근처라는 사실을 병기합니다 —
n=4 대 n=4 의 F 검정은 검정력이 낮고, 이 결론은 **한 조건·한 조성**입니다.

## 2. §7-4 비교 B — **하지 않습니다**

등록문의 적용 조건이 *"A 가 `0.0648 < F < 15.44` 또는 `F ≤ 0.0648` 일 때만.
`F ≥ 15.44` 면 B 는 하지 않음"* 입니다. **A 가 16.09 이므로 B 는 발동하지
않습니다.**

`srep_machine_test.py` 가 참고로 찍은 세 p(0.8968 / 0.7984 / 0.6431, 전부
비유의)는 **판정이 아닙니다.** 조건부 재실행(p 0.045~0.055 → N=5M)도 발동하지
않았습니다. 랩탑이 09-03 에 등록한 비 `s_rep/σ_stat` 직접검정과 MC 근사 단서는
**이번에 쓰이지 않고 등록만 남습니다.**

## 3. §7-5 분할 프로토콜 `±` 동등성 — **주장 유지**

    분할 합동 σ **0.0055188**   통짜 합동 σ **0.0055240**   (각 dof 16)
    F = 0.9981     임계 0.362 / 2.761

    0.362 < F < 2.761   ->   `CHUNKED_PROTOCOL_20260826.md` 2절의
    **"같은 추정량이고 상관 구조도 같다" 주장 유지**

병기(등록문 요구): 이것은 **σ_stat 의 산포**를 본 것이지 평균이 아닙니다.
관문 넷의 평균 일치는 그대로 유효하며 이 검정이 뒤집지 않습니다. **dof 16 은
블록 독립 가정 위에 있습니다.** 분할 4회 중 `0.00227` 이 나머지에서 2.8배
떨어져 있으나 **등록대로 사전에 빼지 않고** 그대로 넣어 계산했습니다.

> 이것이 §7 에서 가장 넓게 걸린 결과입니다 — 주장이 깨졌다면 **분할 프로토콜을
> 쓴 결과 전부**의 오차 표기가 재검토 대상이었습니다. 깨지지 않았습니다.
