# 감사 — 같은 종류의 오류가 더 있는가

2026-08-14. `STRUCTURE_DEFECT.md` 의 빌더 결함을 겪은 뒤, **같은 성질의 미발견
오류**를 찾으려고 계산 설정 전체를 다시 훑었습니다.

## 0. 무엇을 찾았나 — 판정 기준

이번 결함의 성질은 "틀렸다" 가 아니라 이것이었습니다.

> **계산이 정상 완주하고, 경고 한 줄 나오지 않고, 모든 자동 검사를 통과한다.**

그래서 감사 대상을 "결과가 이상해 보이는 것" 이 아니라 **"틀려도 아무것도
울리지 않는 자리"** 로 잡았습니다. 세 개가 나왔고, 일곱 개는 통과했습니다.

## 1. 모체 ZIF-69 결정 구조가 기하 최적화되지 않았습니다 — **미수정**

### 증거는 파일이 스스로 적어 두었습니다

`01_CIF_Data/ZIF-69-crystal.cif` 머리말:

```
_citation_special_details  'ZIF-69 removed random disorder, not optimized'
```

**`not optimized`.** 무질서를 제거만 하고 기하는 손대지 않은 구조입니다.
무질서 제거는 겹쳐 있는 두 배향 중 하나를 고르는 작업이라, 고른 뒤 결합 길이가
물리적으로 말이 되는지는 **보장되지 않습니다.**

### 실측 — 방향족인데 결합 길이가 퍼져 있습니다

| 결합 | 개수 | 최소 | 중앙 | 최대 | **폭** | 이상값 |
|---|---|---|---|---|---|---|
| C–N | 216 | 1.288 | 1.364 | 1.443 | 0.156 | 1.34 |
| C–C | 168 | **1.273** | 1.400 | 1.465 | **0.192** | 1.39 |
| **C–H** | **144** | **0.949** | **0.949** | **0.951** | **0.003** | **1.083** |
| N–Zn | 96 | 1.970 | 1.980 | 2.002 | 0.032 | 1.99 ✅ |
| N–O | 48 | 1.179 | 1.193 | 1.207 | 0.028 | 1.22 ✅ |
| C–Cl | 24 | 1.673 | 1.827 | **1.982** | **0.309** | 1.74 |

**방향족 고리는 공명으로 결합 길이가 균일해야 합니다.** C–C 가 1.273에서
1.465까지 0.192 Å 퍼져 있다는 것 자체가 구조가 틀렸다는 신호입니다.
1.273 Å 은 방향족이 아니라 삼중결합대입니다.

금속 노드(Zn–N)와 나이트로기(N–O)는 정상입니다. **망가진 곳은 유기 링커,
그중에서도 치환이 일어나는 벤조 고리입니다.**

### C–H 는 성질이 다릅니다 — 계통 오차입니다

144개가 **전부** 0.949 Å, 폭 0.003. 잡음이면 이렇게 안 나옵니다.
이것은 알려진 X선 회절 현상입니다 — 수소의 전자밀도가 결합 상대 원자 쪽으로
끌려가 있어, X선이 보는 위치가 **핵 위치보다 10~20% 짧게** 나옵니다
(riding model). 중성자 회절 기준 방향족 C–H 는 **1.083 Å**.

**수소는 기공 벽면을 이루는 원자입니다.** CO₂ 가 실제로 닿는 자리가 0.134 Å
안쪽에 박혀 있으면 기공이 그만큼 넓게 보입니다.

### 왜 이것이 이번 결함과 같은 종류인가

* 빌더는 이 왜곡된 고리에 Kabsch 정합을 했습니다. **정합 오차가 그대로
  치환기 결합 길이가 됐습니다**(`STRUCTURE_DEFECT.md` 2절).
* `STRUCTURE_DEFECT.md` 2-1절이 이 왜곡을 **이미 관찰하고 기록했습니다.**
  그런데 "2판의 진단 — 증상이었습니다" 로 분류하고 **모체는 고치지 않았습니다.**
  빌더 쪽만 우회했습니다.
* 즉 **원인의 절반은 아직 그대로 있습니다.**

### 영향 범위 — v2 도 이것을 물려받았습니다

`structures_v2/ZIF69_saIm100.cif` 의 C–C·C–N·C–H 분포가 모체와 **완전히
동일**합니다(위 표와 같은 값). 재구축은 치환기만 다시 붙였고 모체 골격은
그대로 복사했기 때문입니다. **지금 돌고 있는 재계산도 이 왜곡 위에서 돌고 있습니다.**

무치환 모체(`base`)는 `STRUCTURE_DEFECT.md` 7절이 "영향 없음 / 대조군은
살아 있다" 로 분류했지만, **그 판정은 치환 결함에 한한 것입니다.** 모체 기하
왜곡에 대해서는 대조군도 예외가 아닙니다.

### 측정 중

`chtest/` 에서 A/B 를 돌리고 있습니다 — `base` 대 `baseHnorm`(C–H 만 1.083 으로
정규화, 전하는 그대로). Widom CO₂·N₂ 각 2건. 전하를 함께 바꾸지 않은 이유는
**기하 효과만 분리**하기 위해서입니다. 결과는 아래 6절에 채웁니다.

## 2. 손님 분자 힘장이 문서와 다릅니다 — **미수정**

### 우리가 적어 온 것

노션·보고서·`MIGRATION.md` 전부 **"TraPPE (CO₂, N₂)"**. 입력 파일에도
`MoleculeDefinition TraPPE` 라고 씁니다.

### 실제로 실린 값

`MoleculeDefinition TraPPE` 는 **분자의 기하만** 고릅니다. 전하와
Lennard-Jones 는 `Forcefield` 가 가리키는 폴더의 `pseudo_atoms.def` /
`force_field_mixing_rules.def` 에서 옵니다. 우리는 `Forcefield UFF_MOF`.

| | 우리가 실제로 쓴 값 | TraPPE | 출처 |
|---|---|---|---|
| CO₂ C | q **+0.6512**, ε 29.933 K, σ 2.745 Å | +0.70, 27.0, 2.80 | García-Sánchez 2009 |
| CO₂ O | q **−0.3256**, ε 85.671 K, σ 3.017 Å | −0.35, 79.0, 3.05 | 〃 |
| N₂ N | q **−0.405**, ε 38.298 K, σ 3.306 Å | −0.482, 36.0, 3.31 | 〃 계열 |
| N₂ COM | q **+0.810** | +0.964 | 〃 |

**둘 다 TraPPE 가 아닙니다.** CO₂ 는 García-Sánchez et al., *J. Phys. Chem. C*
**2009**, 113, 8814 (Transferable Force Field for CO₂ Adsorption in Zeolites)
의 값과 정확히 일치합니다.

### 게다가 기하와 파라미터가 서로 다른 모델에서 왔습니다

RASPA 배포본이 가진 CO₂ 정의:

```
EPM2       C–O = 1.149      <- García-Sánchez 계열이 맞춰 만든 기하
TraPPE     C–O = 1.16       <- 우리가 고른 것
```

**García-Sánchez 전하·LJ 를 TraPPE 기하 위에 얹었습니다.** 이 조합은
어느 논문에도 없습니다.

### 영향은 방향이 정해져 있습니다

선형 사중극자 Θ = Σqᵢzᵢ² 로 환산하면 (단위 e·Å²):

| | CO₂ | N₂ |
|---|---|---|
| **우리 것** | **−0.876** | **−0.245** |
| 의도한 모델 (d=1.149) | −0.860 | — |
| TraPPE | −0.942 | −0.292 |
| **실측** | **−0.895** | **−0.291** |

* **CO₂ 는 오히려 실측에 가깝습니다.** TraPPE(−0.942)보다 우리 값(−0.876)이
  실측(−0.895)에 근접합니다. 운이 좋았습니다.
* **N₂ 만 16% 약합니다.** TraPPE 는 실측을 정확히 재현하는데 우리 것은 못 합니다.

N₂ 를 실제보다 약하게 잡으면 **CO₂/N₂ 선택도가 계통적으로 부풀려집니다.**
거칠게: N₂ 결합에너지 ~2.4% 감소 → Henry 상수비 ~1.15배 → **선택도 약 15% 과대**.

**다만 이 편향은 모든 조성에 똑같이 걸립니다.** 조성 간 순위와 σ 판정은
영향받지 않고, **절대값만 이동**합니다.

### 무엇을 할 것인가

**성급히 바꾸면 안 됩니다.** 지금 원격 세션이 이 설정으로 v2 GCMC 를 돌리는
중이고, 중간에 힘장을 바꾸면 v1/v2 비교가 무의미해집니다. 선택지는 셋:

1. **문서를 실제에 맞춘다** — 가장 정직하고 가장 싸다. "García-Sánchez CO₂ /
   UFF_MOF 배포본 N₂" 로 표기. 재계산 불필요.
2. `MoleculeDefinition` 을 `EPM2` 로 바꿔 **기하-파라미터 정합**을 맞춘다.
   CO₂ 전부 재계산. 변화는 사중극자 1.9% 로 미미할 것.
3. TraPPE 전하를 쓰도록 `pseudo_atoms.def` 사본을 만든다. **전부 재계산.**

**권고는 1 + (재계산 끝난 뒤) 3의 검증 1회.** 지금 필요한 것은 결과를 바꾸는
것이 아니라 **결과가 무슨 모델인지 정확히 말하는 것**입니다.

## 3. v1 치환 **개수**가 이름과 달랐습니다 — v2 에서 해소

RASPA 출력의 골격 질량(brbIm075, 단위셀당 8652.84 g/mol)이 손으로 센 값
(8696.8, Br 18개 기준)과 **44 g/mol** 어긋났습니다. 44 는 Br−Cl 질량차(44.45)와
거의 같습니다 — 치환기가 하나 덜 붙었을 때 나오는 값입니다. 전수 확인했습니다.

| | 이름 | 실제 치환 | 실제 비율 |
|---|---|---|---|
| **v1** 모든 `050` | 50% | **14 / 24** | **58.3%** |
| **v1** 모든 `075` | 75% | **17 / 24** | **70.8%** |
| v1 `025`, `100` | | 6, 24 | 정확 |
| **v2 전 30종** | | **정확** | **정확** |

여덟 계열 × 2 = **16개 구조**. 즉 **조성-성능 곡선의 x축이 통째로 어긋나
있었습니다** — 25 / 50 / 75 / 100 이라고 그린 축이 실제로는
**25 / 58.3 / 70.8 / 100** 이었고, 간격도 균등하지 않았습니다.

### 원인

`choose_conflict_free_sites` / `forcing_pairs` — 치환기 충돌을 피하려고 자리를
고르는 코드가 **개수까지 말없이 조정했습니다.** 깨진 기하가 만든 가짜 충돌이
이 로직을 발동시킨 것입니다. 부착 원자를 고친 뒤로는 배타쌍·강제쌍이 0이라
발동하지 않고, 그래서 v2 가 정확합니다.

**그러나 이 코드 경로는 아직 무장돼 있습니다.** 다른 모체나 더 큰 치환기에서
충돌이 다시 생기면 같은 일이 조용히 반복됩니다.

### 검사기가 왜 못 잡았나 — 이번에도 같은 구조

`structures/ZIF69_saIm050.meta.json` 에 빌더가 남긴 것:

```
base_cif              = ZIF69_base.cif
seed                  = 0
min_pairwise_distance = 0.9456        <- 물리적으로 불가능한 값. 기록은 됐다
topology_drift_risks  = []
```

**치환 개수는 아예 기록조차 되지 않았습니다.** 그리고 0.9456 은 `STRUCTURE_DEFECT.md`
3절이 지적한 것과 같은 패턴입니다 — **숫자는 눈앞에 적혀 있었고 문턱이 그것을
정상으로 분류했습니다.**

v2 는 이 부분이 고쳐졌습니다:

```
n_sites = 24 · n_substituted = 12 · requested_fraction = 0.5 · achieved_fraction = 0.5
```

**요청과 달성을 둘 다 적습니다.** 이러면 불일치가 파일에 남습니다.

## 5. 이 감사 자체에도 버그가 있었습니다

첫 판에서 `nbIm` 네 구조를 전부 "불일치" 로 신고했습니다. **모체가 이미 갖고
있는 산소 48개**(nIm = 2-나이트로이미다졸레이트의 나이트로기 24×2)를 기댓값에서
빼먹었기 때문입니다. 구조는 멀쩡했고 **검사기가 틀렸습니다.**

적어 두는 이유는, 이번 사태의 교훈이 "검사기를 늘려라" 가 아니라
**"검사기도 틀린다"** 이기 때문입니다. `check_substituent_clash.py` 가
신뢰를 얻은 방식이 옳았습니다 — **답을 아는 경우(fbIm 의 F–H 0.561 Å)로
먼저 맞춰 보는 것**(`STRUCTURE_DEFECT.md` 4절).

## 6. C–H 정규화 A/B 결과 — **3~10% 구간. v3 재구축이 정답입니다**

판정 기준을 **계산 전에** 적어 두었습니다:

* 변화 **< 3%** → 계통 편향으로 문서에만 명시하고 재계산하지 않습니다.
* **3 ~ 10%** → 모체를 정규화하고 **v3** 로 재구축. 다만 지금 도는 v2 는 끝까지 돌립니다.
* **> 10%** → v2 를 중단하고 모체부터 다시 잡습니다.

### 결과 (`chtest/`, 298 K, Widom 무한희석, 15000 사이클)

`base` = 모체 그대로(C–H 0.949) / `baseHnorm` = C–H 144개만 1.083 으로, **전하는 그대로**.

| | K_H CO₂ [mol/kg/Pa] | K_H N₂ | Q_st CO₂ [kJ/mol] | Q_st N₂ |
|---|---|---|---|---|
| 원본 0.949 | 5.0696e−05 ± 2.9e−07 | 2.8635e−06 ± 3.0e−08 | 26.043 ± 0.047 | 15.007 ± 0.014 |
| 정규화 1.083 | 4.7242e−05 ± 5.6e−07 | 2.7279e−06 ± 2.0e−08 | 25.867 ± 0.068 | 14.875 ± 0.026 |
| **변화** | **−6.81 % (5.5σ)** | **−4.74 % (3.8σ)** | −0.176 (2.1σ) | −0.132 (4.5σ) |

| CO₂/N₂ 선택도 | |
|---|---|
| 원본 0.949 | 17.704 ± 0.210 |
| 정규화 1.083 | 17.318 ± 0.241 |
| 변화 | **−2.18 % (1.2σ — 구별 안 됨)** |

### 읽는 법

**수소를 제자리에 놓으면 흡착이 줄어듭니다.** 0.949 Å 는 수소를 고리 쪽으로
0.134 Å 당겨 놓은 것이고, 그만큼 **기공이 실제보다 넓게** 보였습니다.
K_H 가 5~7% 내려가는 방향이 이것과 맞습니다.

**중요한 것은 두 기체가 같은 방향으로 움직인다는 점입니다.**

| 무엇을 말하는가 | 안전한가 |
|---|---|
| **조성 간 순위, σ 판정** | **안전** — 편향이 모든 구조에 균일 |
| **CO₂/N₂ 선택도** | **안전** — 1.2σ, 비에서 상쇄됨 |
| **Q_st (목표대 30~40 진입 판단)** | 거의 안전 — 0.7% 이동 |
| **절대 흡수량 / K_H / 작업 용량** | **5~7% 과대평가** |

즉 &quot;어느 조성이 낫다&quot; 는 결론은 흔들리지 않고, **&quot;얼마나 잡는다&quot; 는
숫자가 5~7% 높게 나와 있습니다.**

### 판정 — **v3 재구축**

K_H 변화 4.7~6.8% 가 **3~10% 구간**에 들어갑니다. 사전 등록한 기준대로:

1. **지금 도는 v2 는 끝까지 돌립니다.** 중단할 근거가 아닙니다.
2. v2 가 끝나면 **모체를 이완시켜 v3** 를 만듭니다.
3. **v3 는 C–H 만 고쳐서는 안 됩니다.** 이 A/B 는 C–H 하나만 본 것이고,
   1절의 더 큰 왜곡은 고리 자체입니다 — C–C 가 0.192 Å 퍼져 있고 C–Cl 은
   0.309 Å 입니다. C–H 의 0.134 Å 균일 편차보다 큽니다. **고리 전체를 이완**해야
   합니다.
4. **이완 후 PACMAN 전하를 다시 뽑아야 합니다.** 이 A/B 는 전하를 고정해
   기하 효과만 분리한 것이라, 전하 변화분은 아직 측정되지 않았습니다.
   ML 전하 모형은 DFT 최적화 구조로 학습되므로 왜곡된 기하에서 뽑은 전하는
   별도의 오차원입니다.
