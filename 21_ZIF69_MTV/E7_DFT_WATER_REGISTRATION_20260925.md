# E-7 — DFT 물 결합으로 우리 자(UFF_MOF + DDEC6 + TIP5P-Ew)의 물 오차 재기 — 등록 2026-09-25 12:31 HKHOME (자료 0건)

**배경**: 맹점 ⑨ — 우리 자가 물–N 수소결합(MAF-66 예측 소수성, 실측 친수성; E-12)과 **물–열린 금속 배위**(E-16·E-17)를 못 본다. 그리고 E-14 의 설계 단서("mslm050 = G 천장 + 물 지수 절반")가 **힘장이 −SO₂CH₃ 의 물 결합을 과소평가한 결과인지** 가려야 한다. 사용자 결정 1번(pyscf, 데스크탑 `dft` 환경).
**자리(6)**: S1 −SO₃H(saIm) · **S2 −SO₂CH₃(mslm)** · S3 −NO₂(nbIm) · S4 기준(모체 cbIm 의 C–Cl/C–H 면, 비극성) · S5 MAF-66 −NH₂ 와 비배위 트리아졸 N · S6 **열린 Zn**(Zn(bib)(bdtdc), 10.1021/acsami.6b11797).
**양**: 물 1분자 결합에너지 ΔE_bind(자리 조각 + 물). **ΔE_err = ΔE_DFT − ΔE_FF**(음수 = 힘장이 과소 결합). 두 판 병기: **차(kJ/mol)** 와 **비(ΔE_DFT/ΔE_FF)** — 판정 문턱(5 kJ/mol 차 vs 2배)은 사용자 7번 결정 뒤 적용, 그 전에는 둘 다 적고 판정 보류.
**방법(고정)**: DFT = ωB97X-V/def2-TZVP(VV10 내장 — 추가 패키지 없음), Boys–Bernardi 균형보정. 물 자세 = 힘장 최소 자세 1 + 자리별 정형 수소결합 자세 4(주개·받개) → 각 자세 DFT 단일점, 최저값 사용(DFT 기하 최적화 없음 — pyscf 최적화기는 추가 패키지라 환경 변경). 조각 = 해당 전하 CIF 에서 잘라 배위 N 을 H 로 막은 중성 링커(S1~S5), S6 은 Zn 과 첫 배위권(카복실레이트·이미다졸 N)을 H 로 막은 클러스터. 힘장 ΔE_FF = 같은 조각·같은 자세에서 UFF_MOF LJ(혼합 규칙 파일 그대로, Hw/Lw none) + 조각 원자 DDEC6 전하·TIP5P-Ew 전하 쿨롱. **구현 세부(조각 자르기·H 위치·자세 생성)는 첫 DFT 수치 전에 이 문서 §2 에 고정.**
**예측(등록)**:
  (1) S5 MAF-66: ΔE_DFT 가 ΔE_FF 보다 **≥ 5 kJ/mol 더 강하고 비 ≥ 2** — 맹점 ⑨ 의 수치 확인. 기각: 둘 다 아님.
  (2) S6 열린 Zn: **ΔE_DFT ≤ −40 kJ/mol 이고 비 ≥ 2**(배위 누락). 기각: 비 < 1.5.
  (3) S1 −SO₃H · S3 −NO₂: |ΔE_err| < 5 kJ/mol(전하 받개·주개는 DDEC6 + TIP5P 가 잡음).
  (4) **S2 −SO₂CH₃: |ΔE_err| < 5 kJ/mol → mslm050 의 물 이점은 힘장 인공물이 아니다.** 기각: DFT 가 ≥ 5 kJ/mol 더 강함 → E-14/E-19 의 mslm050 물 이점 문장 보류.
  (5) S4 기준: |ΔE_err| < 3 kJ/mol(비극성 면 — 방법 자체의 기준선).
**비용**: 조각 20~60원자 × 자세 5 × 균형보정 3 계산 — 같은 계 실측 없음. **첫 단일점 시간을 재서 견적 갱신**(데스크탑 8코어, E-18 과 코어 나눔).
