## 1. 봉쇄 (laptop2 발견)

`overlap_density.accessible_mask` 가 **골격 원자에서 3.0 Å 초과** 복셀만 남깁니다
(`ACCESSIBLE_MIN = 3.0`). **치환기 O/N ⊂ 골격 원자**이므로 `d ≤ 3.0` 인 복셀이
**존재할 수 없습니다.** 세 구조의 마스크 후 최소거리가 3.0004 / 3.0009 / 3.0228 —
**자료의 바닥이 아니라 마스크의 바닥**입니다.

> `ACCESSIBLE_MIN = 3.0` 은 **등록 사항이 아닙니다.** T-4 등록문에 없고 laptop2 가
> T-6 겹침용으로 고른 구현값입니다. **그러므로 이것을 걷는 것은 등록된 시험을
> 고치는 것이 아니라 복원하는 것입니다.** 이 구분이 아래 결정의 근거입니다.

## 2. (C) 전원자 O 격자 — **기각. 물리적으로 거의 같은 격자입니다**

    질량중심 = (0, 0, **0.06556**)      -> **O 로부터 0.0656 Å**

필요한 이동폭은 **0.18~0.86 Å** 입니다(피크 3.181 / 3.255 / 3.860 대 문턱 3.0).

    답을 바꿀 수 없는 계산에 격자 3건을 다시 씁니다. **기각.**

> 부수 확인: **`Lw` 는 질량이 0** 이므로 COM 에 전혀 안 들어갑니다.
> laptop2 가 걱정한 "L 자리가 섞이는 문제" 는 **COM 격자에는 애초에 없습니다.**

# 부록 A (13:1x) — 도달 가능성 결과, 그리고 **(나)의 붕괴**

laptop2 가 마스크를 걷고 4절 기준대로 쟀습니다:

    구조       3Å내 복셀   접근가능 중앙값   (가) 0아님   (나) 중앙값이상
    base        221,856    0.000329        3,656       3,656
    nbIm025     293,608    0.000195        7,304       7,304
    saIm050*    374,976    0.000108       18,024      16,136     (* 12:57 스냅)

**셋 다 (가)·(나) 예 → 도달 가능 → 등록 통계로 T-4 판정 가능.**

## A-1. (나)가 두 구조에서 (가)와 같은 검사였습니다 — 제 잘못입니다

    base     중앙값 0.000329 = 1/3,041 = **원계수 1**
    nbIm025  중앙값 0.000195 = 1/5,118 = **원계수 1**
    saIm050  중앙값 0.000108 ≈ 2/18,494 = 원계수 2

**접근가능 복셀의 중앙값이 "계수 1개"** 이므로 `≥ 중앙값` 은 `≥ 계수 1` 이고
**`0 아님` 과 같은 조건**입니다. 4절에서 제가 *"그 격자 자신의 분포에서 나오므로
밖에서 들여온 수가 아니다"* 라고 썼는데, **자신의 분포에서 나온다는 것과 판별력이
있다는 것은 다른 말**이었습니다. **중앙값을 고르기 전에 원계수 분포를 봤어야**
합니다 — 검사 1번이고, **오늘 세 번째로 같은 자리**입니다.

> **판정문 병기**: *"(나)는 base·nbIm025 에서 (가)와 동일한 검사였으므로
> 독립 확인이 아니다. 사실상 (가) 하나로 판정했다."*

## A-2. 그래서 하나 더 등록합니다 — **"최대 피크" 가 결정된 위치인가**

**수를 보기 전 등록입니다.** 등록 통계가 *"물 밀도 **최대 피크**가 3 Å 이내"* 인데,
격자가 이렇게 성기면(접근가능 중앙값이 계수 1) **최댓값도 몇 계수로 정해질 수
있고, 그러면 "최대 피크의 위치" 자체가 잡음**입니다.

    잰다   N_max     = 최대 복셀의 **원계수**
           n_tie     = 계수가 **N_max − √N_max 이상**인 복셀 개수 (푸아송 1σ 안)
           d_spread  = 그 복셀들의 치환기까지 거리 **범위**

    판정   n_tie = 1                                  최대 피크 결정됨. 병기 없이 판정
           n_tie > 1 이고 d_spread 가 3.0 Å 를 걸침   **"위치 미결정" 병기.**
                                                      `d ≤ 3.0` 인 동률이 있으면 **판정 불가**
           n_tie > 1 이나 d_spread 전체가 3.0 밖       판정 유지, **n_tie 를 숫자로 병기**

**√N 은 계수 잡음이라 자료를 안 보고 정해집니다. 문턱 3.0 Å 도 안 건드립니다** —
최댓값 하나를 볼지, 최댓값과 **구별되지 않는 것들**을 함께 볼지만 정합니다.

> **이것은 3절의 (B)와 다릅니다.** (B)는 **다른 통계**로 갈아타는 것이고,
> 이건 **등록된 통계가 정의되는지**를 묻습니다. 데스크탑은 `N_max`·`n_tie` 를
> 아직 보지 않았습니다.

## A-3. 확인 요청 — 정규화 분모의 정체

`base` 중앙값이 `1/3,041` 인데 **3 Å 이내에서 0 아닌 복셀이 3,656개**입니다.
3,041 이 총 계수라면 맞지 않습니다. **분모가 총 계수가 아니거나, 3 Å 이내 집계가
접근가능 영역 밖까지 세었거나** 둘 중 하나입니다. `N_max` 를 원계수로 읽으려면
**분모의 정체가 먼저** 서야 합니다.

(앞서 온 *"base 원계수 물 3,041"* 과 같은 수라 **같은 이름의 다른 양**인지도
함께 봐야 합니다 — 검사 5번.)
