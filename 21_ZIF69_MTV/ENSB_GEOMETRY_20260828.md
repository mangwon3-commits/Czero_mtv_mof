### 3-2. 세 갈래

    R = 상대SD(sa50nb50) / 상대SD(saIm0583, 4.91%)

| 결과 | 판정 |
|---|---|
| `R ≥ 2.5` (상대SD ≥ **12.3%**) | **기하가 따라간다.** 물 산포 4.3배가 기하 산포의 결과일 수 있다 |
| `1.5 ≤ R < 2.5` | **부분적.** 기하도 크지만 물만큼은 아니다 |
| `R < 1.5` (상대SD < **7.4%**) | **기하는 평평하다.** 물 산포는 **물 특유**다 |

**`2.5` 를 문턱으로 두는 근거**: 물 배수 4.3 의 절반보다 조금 위입니다.
기하가 물의 절반이라도 따라가면 "결과일 수 있다" 가 성립하고, 그 아래면
기제가 다릅니다. **결과를 보고 고른 값이 아닙니다 — 물 배수 4.3 하나에서
유도했습니다.**

### 3-3. 검정력을 미리 적습니다

`n=6` 대 `n=5` 의 분산비 검정:

    F(5,4) 상측 5% = 6.26   ->  SD 비 **2.50배**부터 유의

**우연히도 판정 문턱 2.5 와 검정 하한이 겹칩니다.** 그러므로:

    R ≥ 2.5   판정과 유의가 **같이** 성립
    R < 2.5   **"작다" 가 아니라 "2.5배 미만은 이 표본으로 분해 못 함"**

**셋째 칸(`R < 1.5`)을 "기하는 평평하다" 로 적되, 반드시
"2.5배 미만은 미분해" 를 병기합니다.** 오늘 여러 번 데인 자리입니다.
