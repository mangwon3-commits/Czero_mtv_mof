## (다)-7. ⚠ **`±` 의 비에는 2.776 환산이 필요 없습니다**

두 `±` 가 얼마나 갈리는지 볼 때 CLAUDE.md §2 의 *"분산 검정에는 진짜 1σ = ±/2.776"*
을 적용하고 싶어집니다. **비에서는 2.776 이 약분됩니다:**

    (±₁/2.776) / (±₂/2.776) = ±₁ / ±₂

**환산해도 같은 답이고, 한쪽만 환산하면 틀립니다.** 08-27 에 이 구분을 놓쳐
배치 산포를 2.0배로 적었던(실제 8.7배) 것의 **반대 방향 실수**입니다.

    관측 SD 비  **2.700** (20.6% 대 7.6%),  dof 4/4
    양측 5% 임계 = √F(0.975,4,4) = √9.6045 = **3.099**
    2.700 < 3.099  ->  **같은 참 σ 와 모순 없음.  양측 p = 0.080**

**p = 0.080 은 경계입니다** — "흔한 일" 이 아니라 **"기각 못 한다"** 입니다.
dof 4 에서 SD 추정의 상대 불확실성은 **1/√(2·dof) = 35.4%** 입니다.
