# v4 설계 브리프 — δ-균형 비양성자성 혼합 MTV (사전 등록)

2026-08-20 등록. **아래 관문·예측은 v4 계산 시작 전에 고정되며, 결과를 보고
고치지 않습니다.** 설계는 Fable 주 에이전트, 문헌은 Opus 검색(전문 확인분만),
데이터는 v3 정본. 기존 규칙(DECISION_RULE_20260820.md)의 문턱은 불변입니다.

## 해석 로드맵 — v3 가 가르쳐 준 규칙 (요약)

R1. saIm 사다리의 LCD 는 58.3→62.5% 한 칸에서 +5.16%p 계단(민감도 ±0.06%p
    의 80배) 후 고원 — δ 원칙(Yang JACS 2017: 링커 δ 혼합비가 위상을 결정,
    비율만 바꿔도 GME→LTA)으로 읽으면 **"붕괴"가 아니라 "그 조성은 GME 로
    결정화하지 않는다"는 신호**. LCD<20% 관문은 위상-합성가능성 대리
    지표로서 유지. 62.5%+ 의 Q_st 는 도달 불가능한 가상 상의 숫자로 취급.
R2. 공여-H 의 값: Q_st +2.4 (saIm075 31.42 vs mslm075 29.01) 에
    RH90 유지율 -20%p 이상을 지불. 비양성자성 극성기 우선.
    (앵커: Pal 2020 설폰 -SO2- 는 수분 무손실)
R3. 물 친수화 문턱 = ΔH_ads(물) 44 kJ/mol (Ortiz/Coudert 2014).
    -NO2 52.5 는 국소 결함에 그침, -CHO 80 은 전면 친수화.
R4. 정전기는 극성이 아니라 **비대칭이 켠다**(Morris 2010). 자체 재현:
    fbIm 사다리(대칭 Cl→F)가 Q_st 22.4→23.0 으로 모체와 평평.
R5. 0.15 bar 에서 공동은 작을수록 유리(Morris 2012 위상 통제 실험).
    개구 3.5~5 ∩ 공동 6~9 Å 은 사실상 GME·sod 뿐(Yang 2017 지도).
R6. Q_st 선호 창은 30~35 (재생률 관문 생존자 전부 <35, Yang CCL 2020;
    우리 regen v3: 지배항은 현열 67.5/WC). 등록 목표대 30~40 은 불변,
    30~35 는 보고 시 병기.
R7. nbIm(-NO2)은 우리 실측에서 LCD 를 **확장**(-8.8~-18%) — δ-균형 파트너.

## 제안 (3건, 실행 등급 순)

P1 (오늘 밤): δ-균형 혼합 3종, GME 유지
    M1 sa50nb50 = saIm 12 + nbIm 12   (672원자: Zn24 C240 N132 O108 S12 H156)
    M2 sa25nb75 = saIm  6 + nbIm 18   (660원자: Zn24 C240 N138 O102 S6  H150)
    M3 ms50nb50 = mslm 12 + nbIm 12   (696원자: Zn24 C252 N132 O96  S12 H180)
    논거: 최대-δ(saIm) 분율을 실측 안전 구간(<=58.3%) 안에 두고 나머지를
    LCD-확장성 nbIm 으로 채움(R1+R7). 공여-H 밀도는 saIm050/025 와 동일해
    RH90 76/80% 실측 구간(R2). 공여(-SO3H)/수용(-NO2) 인접쌍의 비대칭
    활성화가 실재하는지가 이 계산의 질문(R4).
P2 (이번 주): ZIF-94(sod) 프로토콜 앵커 — GME 계열 Q_st 실측이 문헌에
    없으므로(원논문 grep 확인) 우리 절대값의 유일한 교정점. CIF 확보 필요.
    판정 사전 등록: |우리 Q_st - 30.5| <= 3 이면 절대값 신뢰, 초과면 계통
    보정 후보로 공표.
P3 (중기): 고리 안 N GME (아자벤즈이미다졸) — δ-중립·부피 0·공여-H 0
    (Lee 2025 UZIF-33 Q_st 35.1, N/V 상관). 조각 개발 필요, 합성 의존.
