# 군 B 배치 산포의 하한 — 세 판을 거쳐 정착한 값 (2026-08-28)

`LOWRH_18_ANALYSIS.md` 의 BB(혼합 조성) 비교 셋이 사는지 죽는지는
**군 B `sa50nb50` 의 상대 배치 산포가 BB 가 필요로 하는 19.0% / 23.5% 보다
큰가**에 달려 있습니다. 실현이 아직 다 안 끝났으므로 **"남은 실현이 최악으로
협조해도 여전히 큰가"** 를 물어야 하고, 그것이 하한입니다.

이 문서가 그 하한의 최종판입니다. **대화에만 있던 수를 파일로 내립니다**
(CLAUDE.md §8).

## 1. 관측값 — RH10 물 로딩 (mol/kg)

| 실현 | 물 | 비고 |
|---|---|---|
| e1 | 0.0600 | |
| 생산 | 0.2623 | 08-26, **동시성 8** |
| e3 | 0.3875 | |
| e2 | 0.4985 | |

> **`생산` 을 산포 계산에 넣는 것이 맞습니다.** 동시성 8 은 *소요 시간* 을
> 오염시키지 나 *물 로딩* 을 오염시키지 않습니다(데스크탑 08-28). 같은 이유로
> 소요 순위 시험에서는 `생산` 을 **뺐고**, 물 산포에서는 **넣습니다.** 두
> 판단이 반대 방향이지만 근거는 하나입니다 — 오염된 관측량만 뺍니다.

n=4 실측 상대 산포 = **62.2%**

## 2. 하한 세 판

| 판 | 고정 집합 | 최소화 대상 | n=4 | n=5 | n=6 |
|---|---|---|---|---|---|
| 1차 (데스크탑) | {e1, e2} | `SD` | 64.1% | 55.5% | 49.7% |
| 2차 (데스크탑 자기 정정) | {e1, e2} | `SD/평균` | 56.0% | 47.4% | 41.8% |
| **3차 (확정)** | **{e1, e2, 생산, e3}** | `SD/평균` | **62.2%** | **52.4%** | **46.0%** |

**1차 → 2차**: 데스크탑이 스스로 잡았습니다. `SD` 를 최소로 만드는 값과
`SD/평균` 을 최소로 만드는 값은 다릅니다 — 자유값을 더 높이면 `SD` 는 커져도
평균이 더 빨리 커져 상대값이 내려갑니다. 두 목적함수 이름이 다 "산포" 라
안 보였습니다.

**2차 → 3차**: 고정 집합이 `{e1, e2}` 였습니다. 그러면 **`생산`(0.2623)이
자유값이 되어 최적화가 그것까지 옮겨 버립니다.** `생산` 은 이미 뽑힌 값이라
하한에서 뺄 수 없습니다. 확인:

```
가설 {e1,e2} · SD 최소       -> 64.1%              1차와 일치
가설 {e1,e2} · SD/평균 최소  -> 56.0% at x=0.451   2차와 일치 (x=0.452 까지)
```

두 판 다 재현되므로 **차이는 계산 실수가 아니라 고정 집합**입니다.

## 3. 확정 하한과 BB 판정

```
                    최소 산포     BB 19.0% 의    BB 23.5% 의
  n=4 (지금)         62.2%          3.28배         2.65배
  n=5                52.4%          2.76배         2.23배
  n=6 (완주 시)      46.0%          2.42배         1.96배
```

**남은 두 실현이 최악으로 협조해도 BB 필요값의 2.0배 아래로 못 내려갑니다.**
혼합 조성 비교 셋이 죽는다는 결론은 그대로입니다.

> 앞서 대화에서 오간 **1.8~2.2배** 는 2차 판(= `생산` 자유)에서 나온 수입니다.
> **쓰지 마십시오.** 확정값은 위 표의 **2.42 / 1.96** 입니다.

## 4. e3 가 떨어진 자리

```
n=4 상대 산포를 최소로 만드는 값   x = 0.3909
실측 e3                            = 0.3875     차 0.0034
결과                        실측 62.24%  vs  가능 최소 62.25%
```

**e3 는 산포를 가장 강하게 눌러 주는 자리에 떨어졌습니다.** 관측 범위
0.06~0.50 안에서 우연이고, 두 양을 잇는 기전은 없습니다.

그래서 지금 문장은 이렇게 셀 수 있습니다 — *"새 실현이 산포를 최대로
억누르는 값으로 나왔는데도 BB 필요값의 2.65배."* **최악의 경우로 말해도
결론이 서는 자리**이므로 약점이 아니라 강점입니다.

## 4-1. RH15 가 먼저 완결됐습니다 — **하한이 필요 없어진 첫 관측량** (08-28)

`rh15_e5` 완주로 RH15 가 **6/6** 이 됐습니다. 이제 하한을 논할 필요 없이
실측입니다.

```
생산 0.3459   e1 0.0888   e2 0.5862   e3 0.4750   e4 0.5122   e5 0.1287

평균 0.3561   SD 0.2072   **상대 58.2%**   최대/최소 6.60
```

```
                        BB 19.0% 대비   BB 23.5% 대비
점추정      58.2%          3.06배          **2.48배**
χ² 95%CI 하한 36.3%        1.91배          **1.55배**
```

> **가정 없이 결론이 섭니다.** 앞의 하한들은 *"남은 실현이 최악으로
> 협조해도"* 라는 조건부였는데, RH15 는 **여섯이 다 나왔고 신뢰구간
> 하한에서도 필요값의 1.55배**입니다. **혼합 조성 비교 셋은 죽습니다.**

⚠️ **`n=5` 에서 `n=6` 으로 가며 48.6% → 58.2% 로 올랐습니다.** `e5`
(0.1287)가 낮게 나와서입니다. **추정이 아직 움직인다는 뜻**이므로 이
58.2% 도 확정된 산포가 아니라 `n=6` 에서의 값입니다. 설계상 여기서
멈추므로 이 수가 최종입니다.

⚠️ **RH15 의 58.2% 를 RH10 판정에 쓰지 마십시오.** 2절 표의 하한들은
전부 **RH10** 관측량입니다. RH10 은 아직 `n=4` 입니다.
