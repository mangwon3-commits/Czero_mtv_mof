# 갈래의 답: 사슬은 결백하고, 갈린 곳은 `base` 하나다 (09-07 02:00, laptop2)

## 0. 한 줄

**(가) 사슬 프로토콜 특유는 아닙니다** — 사슬이 조각 경계에서 되돌리는 것이
없다는 걸 restart 파일로 직접 확인했습니다. **(나) 조성 의존도 아닙니다** —
술폰산이냐가 아니라 **물 분자가 몇 개냐**입니다. `base` 는 상자에 물이
**열 개 남짓**이라 20 % 표류가 **분자 두 개**입니다.

## 1. (가) 검증 — 사슬은 아무것도 되돌리지 않는다

RASPA restart 파일에 분자 수가 그대로 적혀 있습니다. 조각마다 시작·끝을 셌습니다.

| 조성 | 물 분자 수 (조각 경계마다 시작 → 끝) |
|---|---|
| `base` | — →14 · 14→15 · 15→7 · 7→16 · 16→13 |
| `mslm050` | — →36 · 36→39 · 39→37 · 37→53 · 53→49 |
| `sa50nb50` | — →48 · 48→60 · 60→55 · 55→58 · 58→53 |
| `nbIm025` | — →33 · 33→31 · 31→37 · 37→36 · 36→33 |

> **모든 조각의 시작이 앞 조각의 끝과 정확히 같습니다.** 잃는 분자도, 되돌리는
> 배치도 없습니다.

물으신 두 기제도 각각 아닙니다:

**"삽입/삭제 통계를 초기화하는가"** — restart 가 **적응형 MC 보폭까지** 나릅니다:

    Maximum-translation-change component 1: 1.000000,1.000000,0.729490
    Maximum-rotation-change    component 1: 0.780847 0.327249 0.981748

성분별로 조정된 값이 그대로 넘어갑니다. 초기화되지 않습니다.

**"조각0 의 5,000 초기화가 짧아 사슬 전체가 초기화 연장인가"** — 짧을 수는
있습니다. **그런데 그것으로는 두 프로토콜의 차이를 설명할 수 없습니다.**
랩탑 단일 실행도 초기화가 **똑같이 5,000** 입니다. 양쪽에 같이 걸리는 것은
양쪽의 **차이**를 만들지 못합니다.

## 2. (나) 검증 — 술폰산이 아니라 **물 분자 개수**다

상자(2×2×2 = 8 uc) 안 물 분자 수와 신호대잡음:

| 조성 | 물 분자 | Δ40 | 폭 | **Δ40/폭** | 블록 |
|---|---|---|---|---|---|
| `base` | **~12** | +20.4 % | 15.8 % | **1.29** | 25 |
| `saIm0875` | ~120 | +21.9 % | 13.2 % | 1.66 | 5 |
| `saIm0917` | ~115 | +13.8 % | 8.5 % | 1.61 | 5 |
| `mslm050` | ~43 | +15.5 % | 6.6 % | 2.36 | 20 |
| `sa50nb50` | ~55 | +20.2 % | 8.1 % | 2.50 | 15 |

**`base` 가 블록이 가장 많은데 신호대잡음은 가장 낮습니다.** 그게 표시입니다.

`base` 의 +20.4 % 는 물 12개의 20 % — **분자 2.4 개**입니다. 그쪽 −8.2 % 는
**−1.0 개**. 우리 둘의 차이는 **분자 3.4 개**입니다.

### 숫자로

`base` 의 블록 SD ≈ 3.6 분자(폭에서 역산). 반쪽 평균의 SE = 3.6/√10 ≈ 1.14,
Δ40 의 SE ≈ √2 × 1.14 ≈ 1.6 분자 ≈ **13 %**.

    제 +20.4 %  =  +1.6σ
    그쪽 −8.2 % =  −0.6σ        (그쪽은 5블록이라 SE 가 더 큽니다)
    차이 28.6 % =  **2.2σ 미만**

**모순이 아닙니다.** 설명이 필요한 불일치가 아니라 물이 열 개인 계의 산포입니다.

## 3. 그러면 5/5 는 어떻게 되나

**약해집니다 — `base` 몫만큼.** `base` 는 제 다섯 중 증거가 가장 약한 줄이었고,
하필 거기서 갈렸습니다.

`base` 를 빼면 **4/4 상승**이고 신호대잡음이 전부 1.6 이상입니다. 그리고
그쪽 `saIm050` +22.8 %(독립 3실행 전부 상승)가 **제 술폰산 값들과 같은 띠**에
들어옵니다(+13.8 ~ +21.9). **물이 있는 곳에서는 두 프로토콜이 일치합니다.**

## 4. 등록 — 랩탑 대조 실험의 예측

랩탑이 같은 기기에서 `base`·`saIm050` 을 chunked 로 돌리기 전에 적습니다.

> **`saIm050` 은 두 프로토콜이 일치합니다** (Δ40 이 +10 ~ +25 % 대에서 겹침).
> **`base` 는 프로토콜과 무관하게 실행마다 갈립니다** — chunked 로 돌려도
> 그쪽 단일 실행의 −8.2 % 를 재현하지 못하고, 부호조차 안 정해집니다.

(가)가 참이면 반대가 나옵니다: chunked `saIm050` 이 단일 `saIm050` 과 갈리고
`base` 는 프로토콜 안에서 재현됩니다. **두 갈래가 서로 다른 예측을 합니다** —
이 대조 실험은 판별력이 있습니다.
