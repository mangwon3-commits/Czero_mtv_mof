## 4. ⚠️ 관문을 러너 **안에** import 로 넣지 마십시오 — 경로가 샙니다

`run_water_v3w` 와 `run_density_water_v3` 는 **둘 다 `import run_water as rw`** 를 하고
**모듈 전역** `rw.HERE`·`rw.RUNS`·`rw.CHARGED` 를 자기 계열로 덮어씁니다. 그래서 밀도
계열 프로세스가 `run_water_v3w` 를 한 번 import 하면 그 순간 밀도 실행이 물 계열
폴더로 샙니다. 실측:

    run_water 기본         .../water_runs
    밀도 러너 설정 후      .../water_runs_density_v3
    물 러너 import 한 뒤   .../water_runs_v3w      <- 밀도 실행이 여기로 샙니다

**오류를 내지 않습니다.** 09-07 에 밀도 러너에 관문을 넣으려다 이것을 보고 멈췄고,
관문을 러너 안이 아니라 **밖의 도구**로 둔 이유가 이것입니다. `check_ff_per_run.py` 는
import 전후로 그 전역을 떠 놓고 되돌리지만, **러너 안에서 부르는 것은 여전히 금지**입니다.
