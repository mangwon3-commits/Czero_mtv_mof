# 정지 규칙을 자료에 대 봤다 — 쓸 만하다, 한 군데만 (09-07 02:00, laptop2)

등록된 규칙: **|Δ40| < 그 실행 통계 폭 이면 정지.**

## 0. 먼저, 제 첫 걱정 둘 다 틀렸다

**(가) "즉시 발동해서 아무것도 안 늘린다"** — 아니다. 지금 자료에 대니
수정 5개 전부 "계속" 이다.

**(나) "폭이 √n 으로 줄어서 영영 안 멈춘다"** — 이것도 아니다. Δ40 은 두
반쪽 평균의 차라 그 잡음도 √n 으로 같이 준다. 평형된 실행에서

    SD(Δ40) ≈ SD/평균 · √(5/n),   폭 = 2.776 · SD/평균/√n
    -> |Δ40| < 폭 은 사실상 **3.4σ 문턱**

이라 평형이면 거의 항상 발동한다. **둘 다 계산해 보고 알았다.**

## 1. 자료에 댄 결과

| 실행 | Δ40 | 통계 폭 | Δ40/폭 | 규칙 |
|---|---|---|---|---|
| 결함 `base` | +5.4 % | 4.4 % | 1.23 | 계속 |
| 결함 `saIm050` | +0.1 % | 3.1 % | 0.04 | **정지** |
| 결함 `nbIm025` | −3.1 % | 4.0 % | 0.79 | **정지** |
| 결함 `nbIm075` | +4.8 % | 3.8 % | 1.27 | 계속 |
| 수정 `base` | +20.4 % | 15.8 % | 1.29 | 계속 |
| 수정 `mslm050` | +15.5 % | 6.6 % | 2.36 | 계속 |
| 수정 `sa50nb50` | +20.2 % | 8.1 % | 2.50 | 계속 |
| 수정 `saIm0875` | +21.9 % | 13.2 % | 1.66 | 계속 |

수정 5/5 계속, 결함 2/4 정지. **방향이 맞다.** 규칙 자체는 쓸 만하다.

## 2. 한 군데: **폭이 조성마다 5배 다르다**

폭이 3.1 % ~ 15.8 % 다. 정지 시점의 **남은 표류가 조성마다 다르다**는 뜻이다.
그리고 물의 절대량으로 환산하면 어긋남이 커진다 — **CO2 를 밀어내는 건 물의
절대량**이지 비율이 아니다.

    정지 시 남는 물 = 폭(%) × 물 평균

| 조성 | 폭 | 물 평균 | **남는 물** | 블록 |
|---|---|---|---|---|
| `base` | 15.8 % | 0.185 | **0.029** | 25 |
| `mslm050` | 6.6 % | 0.537 | **0.035** | 20 |
| `sa50nb50` | 8.1 % | 0.808 | **0.066** | 15 |
| `saIm0875` | 13.2 % | 1.670 | **0.221** | 5 |
| `saIm0917` | 8.5 % | 1.614 | **0.137** | 5 |

**0.029 ~ 0.221, 7.6배.** 물이 많은 조성일수록 느슨하게 멈춘다 — 그런데 물이
많은 조성이 바로 **CO2 유지율이 물에 가장 민감한 조성**이다. **편향이 나쁜
쪽으로 간다.**

### 다만 절반은 블록 수 탓이다

`saIm0875`·`saIm0917` 은 아직 5블록이라 폭이 넓다. 25블록까지 가면 √5 배
좁아진다. 그걸 반영해 어림하면 0.029 / 0.032 / 0.051 / 0.099 / 0.061 로
**3.4배**까지 줄어든다. *(SD 가 그대로라고 본 어림이다 — 표류가 계속되면
SD 에 표류가 섞여 있어 이 어림은 낙관이다.)*

그래도 3.4배는 남는다. **블록 수를 맞춰도 사라지지 않는다.**

## 3. 제안 — 문턱을 더 걸지 말고 **같이 적자**

문턱을 하나 더 얹으면(예: "남는 물 < 0.05 mol/kg 도 만족") 값이 정해지지
않은 상수를 하나 더 등록하는 것이고, 그 값을 지금 고를 근거가 없다.

대신 **정지 시점의 "남는 물" 을 유지율 옆에 같이 적자.** 물 조각 이상치를
판정이 아니라 보고 항목으로 넣었던 것과 같은 처리다. 그러면 읽는 사람이
`base` 100 % 와 `saIm0875` 84 % 가 **같은 엄격함에서 멈춘 값이 아님**을 본다.

한 줄이면 된다:

> `조성  유지율  (정지 시 남는 물 X mol/kg)`

## 4. 제 §2 표에 대한 자기 점검

§2 의 결함-대-수정 Δ40 비교는 **폭을 안 썼다** — Δ40 만 견줬다. 블록 수가
5 대 25 로 달라서 폭이나 유의성을 견줬다면 틀렸을 것이다. Δ40 은 설계와
무관하므로 그 비교는 선다. **이 문서에서 폭을 처음 꺼냈고, 꺼내자마자
블록 수 의존이 문제가 됐다** — 같은 함정이다.

# 부록 A. CO2 를 같은 자로 재면 갈리지 않는다 — 그리고 물은 대부분 **빈 자리를 채운다**

종합의 미결: "물은 오르는데 CO2 가 안 내리면, 물이 CO2 자리를 뺏는 게 아니라
빈 공간을 채우는 중이다." 등록한 자(Δ40 + 실행 사이 부호검정)로 재 봤다.

## A1. 갈린 게 아니라 또 자 문제였다

| 힘장 | 조성 | 물 Δ40 | 폭 | **CO2 Δ40** | 폭 |
|---|---|---|---|---|---|
| 결함 | `base` | +5.4 % | 4.4 % | **−2.2 %** | 2.7 % |
| 결함 | `saIm050` | +0.1 % | 3.1 % | **−0.5 %** | 2.9 % |
| 결함 | `nbIm025` | −3.1 % | 4.0 % | **−0.2 %** | 1.7 % |
| 결함 | `nbIm075` | +4.8 % | 3.8 % | **−2.3 %** | 2.1 % |
| 수정 | `base` | +20.4 % | 15.8 % | **−1.8 %** | 2.0 % |
| 수정 | `mslm050` | +15.5 % | 6.6 % | **−1.6 %** | 2.1 % |
| 수정 | `sa50nb50` | +20.2 % | 8.1 % | **−1.2 %** | 1.8 % |
| 수정 | `saIm0875` | +21.9 % | 13.2 % | **−11.4 %** | 8.4 % |
| 수정 | `saIm0917` | +13.8 % | 8.5 % | **−2.3 %** | 2.3 % |

> **수정 5/5 음수 — 부호검정 p = 0.031.** 물의 5/5 와 같은 세기다.

랩탑 t 가 +1.13/−0.80/+0.17 로 0 과 구별되지 않은 건 **5블록 실행 안 t 의
검정력이 없기 때문**이지 CO2 가 안 내려서가 아니다. 우리가 안 쓰기로 한 그 t 다.

**다만 실행 하나하나는 약하다.** 9개 중 8개가 제 폭 **안**에 있다(밖은
`saIm0875` −11.4 % 뿐). 부호의 일치가 증거지 개별 크기가 아니다.

## A2. 걸리는 것: **결함판도 4/4 음수**다

전체 9/9 음수, p = 0.0020. 그런데 결함판은 물이 평형에 닿은 실행들이다.
물이 다 찼는데 CO2 는 왜 계속 내리나.

그럴듯한 기제: **chunk0 은 빈 상자에서 시작한다.** CO2 는 5사이트 물보다 삽입이
쉬워 먼저 들어차고, 물이 천천히 오면서 밀려난다. 그러면 생산 구간 내내 CO2 는
"과충전에서 내려오는" 모습이 된다 — 물의 평형 여부와 별개로.

**이건 이야기다.** 검증하려면 물을 채운 상태에서 시작한 실행이 필요한데 없다.
**미결로 남긴다** — 다만 이게 맞다면 CO2 하강의 일부는 물 때문이 아니므로
아래 교환비는 **과대**다.

## A3. 핵심 수: **물 5개가 들어와야 CO2 1개가 나간다**

절대량(mol/kg)으로 환산한 교환비 = −ΔCO2 / Δ물:

| 조성 | Δ물 | ΔCO2 | **교환비** |
|---|---|---|---|
| `base` | +0.038 | −0.011 | **0.28** |
| `mslm050` | +0.083 | −0.018 | **0.22** |
| `sa50nb50` | +0.163 | −0.011 | **0.07** |
| `saIm0875` | +0.366 | −0.124 | **0.34** |
| `saIm0917` | +0.223 | −0.024 | **0.11** |

**0.07 ~ 0.34, 평균 ≈ 0.20.** 1:1 이 아니다.

> **종합의 읽기가 맞다 — 물은 대부분 빈 자리를 채우고 있다.**
> 들어온 물 다섯 중 넷은 CO2 를 안 건드린다.

## A4. 그래서 상한은 생각보다 **덜 느슨하다**

물이 더 Δw 들어와도 CO2 는 0.2·Δw 만 준다. 감을 잡자면 — **예측이 아니라
민감도**다:

- `base` (물 0.185): 물이 **2배**가 돼도 CO2 −0.037 → 유지율 100 % → **≈94 %**
- `saIm0875` (물 1.67): 물이 **+20 %** 더 오면 CO2 −0.11 → 83.8 % → **≈75 %**

**이 두 줄을 인용하지 말 것.** 교환비는 과도상태에서 쟀고 5배로 흩어져 있으며
(A2 가 맞다면 과대이고), 물의 점근값을 모르니 "2배" · "+20 %" 는 **임의로 고른
수**다. 상한이 조성마다 다르게 느슨하다는 **방향**만 쓸 수 있다 — 그리고 그
방향은 §2 의 정지 규칙 결론과 같다: **물이 많은 조성일수록 더 느슨하다.**
