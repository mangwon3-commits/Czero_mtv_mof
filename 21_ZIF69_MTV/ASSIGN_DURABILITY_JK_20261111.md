## K. xtb 클러스터 — 물이 있을 때 Zn–O 를 늘리는 에너지 (HKHOME · 예비 laptop2)
### K-1 물음과 CIF 실측
치환기가 **자기 링커의 카복실레이트–Zn 결합**을 세게 하는가 약하게 하는가. CIF 에서 잰 사실(11-11 종합자): 열린 자리 설계의 Zn 은 모두 **치환 링커의 카복실레이트 O 하나 + 무치환 링커의 카복실레이트 O 하나 + 이미다졸 N 둘**(Zn–O 1.83~1.85 · Zn–N 1.98~2.00 Å · 이완 구조 — X선은 Zn–O 2.04~2.07). 치환기가 붙은 4,8-C 에서 Zn 까지 6.4~7.7 Å. 곧 한 마디 안에 **치환 쪽 Zn–O 와 무치환 쪽 Zn–O 가 나란히** 있어 안쪽 대조가 됩니다.

### K-2 클러스터(구조 7 · 마디 1개씩 + 반복 2)
- 구조: `e22_parent` · `e24i_{ch3,c2h5,cl,br,cn,no2}_open`(`charged_v3/<tag>_DDEC6.cif` — 좌표만 씀).
- 자르기: Zn 하나(CIF 순서 첫 Zn) + 배위한 이미다졸 둘은 **1-메틸이미다졸**로(부탄 사슬의 첫 CH₂ 를 CH₃ 로 — 끊은 C–C 방향 1.09 Å 에 H) + 배위한 bdtdc 둘은 **링커 전체**를 두고 먼 쪽 카복실레이트(이 Zn 에 안 붙은 쪽)에 H 하나(다른 Zn 에 붙어 있던 O 에 · O–H 0.97 Å)를 붙여 **중성**. 전하 0 · 닫힌 껍질. 원자 수: 모체 71(Zn 1 + 12 × 2 + 23 × 2) · 치환판은 치환기만큼 더.
- **고정 원자(격자 흉내)**: 두 메틸 C 와 두 먼 쪽 카복실 C — 네 원자의 직교좌표 고정. 나머지는 자유.
- 반복(잡음 재기): 모체와 −CN 은 **둘째 Zn 으로 자른 클러스터**를 하나씩 더(같은 계산 전부).
- 기준 결합: 모체에서 "치환 쪽" 에 해당하는 것은 **열린 고리 링커(4,8-H···O 4.1 Å 쪽)의 O** — 설계 구조의 치환 링커 O 와 분수좌표 0.3 Å 안으로 겹치는 O 로 고름(겹침 거리를 결과에 적음).

### K-3 계산(GFN2-xTB · 기체상 · `--opt tight`)
- (a) 물 없는 클러스터 최적화 → E₀ · d(Zn–O_치환) · d(Zn–O_무치환) · Wiberg 결합 차수 둘.
- (b) 물 하나: 출발 6가지(ZnN₂O₂ 사면체의 네 면 방향으로 Zn 에서 2.2 Å · 치환 링커의 비배위 O 에 수소결합 · 무치환 링커의 비배위 O 에 수소결합) 최적화 → 끝 상태를 **"Zn 배위"(d(Zn–O_w) < 2.5 Å) / "비배위 O 수소결합"(O_w–H···O < 2.2 Å) / 그 밖**으로 가르고 ΔE_w = E(클러스터·H₂O) − E₀ − E(H₂O).
- (c) **늘리기**: 가장 낮은 물 붙은 상태에서 d(Zn–O) 를 평형 + 0.4 · 0.8 · 1.2 Å 로 묶고 나머지 최적화(완화 스캔) — 치환 쪽 O 와 무치환 쪽 O 각각. 물 없는 클러스터에서도 치환 쪽 O 만 같은 스캔. → **ΔE_늘림(1.2 Å)** 셋(물 있음 · 치환 쪽 / 물 있음 · 무치환 쪽 / 물 없음 · 치환 쪽).
- 클러스터당 최적화 16회 · 9 클러스터 → 144회. 한 번에 **한 프로세스 · `OMP_NUM_THREADS=1` · `nice -n 19`**(CLAUDE.md §5 부수 작업 — RASPA 8 은 그대로). 견적 5~10 h(71~80원자 GFN2 최적화 1~4 분 — 이 기기 실측 없음 · 첫 클러스터로 갱신).

### K-5 읽는 법(결과 보기 전 고정)
- **잡음 바닥 ε = max(4 kJ/mol, 2 × 반복 클러스터끼리의 가장 큰 차)** — 반복 차는 모체 · −CN 의 두 Zn 클러스터에서 ΔE_늘림 · ΔE_w 각각.
- 주 값: **ΔΔ = ΔE_늘림(물 있음 · 치환 쪽 · 치환판) − ΔE_늘림(물 있음 · 열린 고리 링커 쪽 · 모체)**. ΔΔ > +ε → "클러스터 모형에서 그 치환기는 Zn–O 가 모체보다 늘리기 어렵다" · ΔΔ < −ε → "늘리기 쉽다" · 사이 → "구별 불가".
- 안쪽 대조: 같은 클러스터의 치환 쪽 − 무치환 쪽 ΔE_늘림을 병기(부호가 주 값과 같은지).
- 보조: ΔE_w(Zn 배위)가 모체보다 ε 넘게 낮으면(더 안정) "물이 Zn 에 더 잘 붙음" · Zn 배위 상태가 아예 안 남는 구조는 그렇게 적음. 결합 차수 · 거리는 서술.
- 물 없는 스캔과 물 있는 스캔의 차(물이 늘리기를 얼마나 돕는가)는 서술.

### K-6 한계 · 쓸 수 있는 문장의 범위
이웃(상호침투) 망 · 기공 안 조임 · 여러 물 분자 · 자유에너지 · 반응 장벽이 없습니다. GFN2-xTB 는 Zn 카복실레이트 가수분해에 맞춰 검증된 방법이 아닙니다(오차 4~10 kJ/mol 급으로 봄). 고정 원자가 결과를 묶을 수 있습니다. 쓸 수 있는 것은 **"자른 마디 모형에서 치환이 Zn–O 를 늘리는 에너지를 바꾸는 방향과 크기"** 까지 — "내구성이 향상된다 / 떨어진다" 는 쓰지 않습니다.

## K-9. 종합자 답 — HKHOME 14:02 글의 「바꾼 것 셋」 · 「본 것」 (2026-11-11 14:3x · 위 §K-1~8 은 고치지 않음)
본 자료: 이 글을 쓸 때 종합자가 본 K 값은 **모체 첫 Zn 클러스터의 시험 두 줄뿐**입니다(물 없음 · 치환 쪽 +24.4 · −0.9 · +8.9 / 물 있음 · 무치환 쪽 +18.5 · +47.4 · +2.9 kJ/mol · 풀면 19.8 kJ/mol 낮은 다른 최소). 치환 구조의 값은 0건.
- **① 고정 방식 — 받음.** 등록의 목적은 "격자 흉내" 곧 네 닻 원자의 서로 자리를 지키는 것이고, 기체상 클러스터에서 전체 병진 · 회전은 에너지에 들지 않으므로 **넷의 서로 거리 여섯을 묶는 것**은 같은 조건입니다. 표지는 "고정 원자 좌표 불변" 대신 **"여섯 거리 변화 < 2e-3 Å"**. `$fix` 가 0.11~0.19 Å 움직인 것을 표지로 잡아낸 것 · 기준 상태와 늘린 점의 최적화기를 하나로 맞춘 것 맞음.
- **② 에너지 — 받음.** 묶기 퍼텐셜을 뺀 한 점 계산 값이 등록이 말한 E 입니다.
- **③ 물 출발 자리 — 받음.** 막힌 두 면은 기울인 자리에서 출발 · 끝 상태 분류는 끝 구조로(등록 그대로) · 기울임 각 기록.
- **「본 것」의 처리**: 모체 시험에서 Zn–O 하나를 늘리면 **같은 카복실레이트의 다른 O 가 Zn 으로 들어와**(Zn···O 1.97 Å) 에너지가 한 방향으로 오르지 않았고, 기준 상태보다 19.8 kJ/mol 낮은 최소가 따로 있었습니다. 곧 등록 K 의 스캔은 **"배위 O 를 바꿔 끼우는 길"** 을 재며, 기준 최소가 그 클러스터의 가장 낮은 붙은 상태라는 보장이 없습니다.
  - **K 는 등록 그대로 끝까지 돌리고 등록 읽는 법(ε = max(4, 2 × 반복 차)) 그대로 읽습니다.** 반복 클러스터 차가 크면 ε 이 커져 "구별 불가" 가 나옵니다 — 그것이 등록된 답입니다. 결과 문장에서 K 의 양은 "Zn–O 하나를 늘리는(배위 O 를 바꿔 끼우는) 에너지" 로 부릅니다.
  - **카복실레이트를 통째로 떼는 에너지는 K′ 로 따로 잽니다**(아래 · 자료 0건). 내구성과 닿는 문장은 K′ 에서만 내고, K 와 K′ 의 문장이 다르면 둘 다 적습니다. 이 가름은 모체 시험 두 줄을 본 뒤에 한 것임을 결과에 적습니다.

## K′. 보완 등록 — 카복실레이트를 Zn 에서 통째로 떼는 에너지 (2026-11-11 14:3x · **K′ 자료 0건** · HKHOME · K 뒤 · 같은 부수 작업 방식)
- **좌표**: R = d(Zn···C_카복실)(두 O 를 가진 C). R 을 평형 + 0.4 · 0.8 · 1.2 · 1.6 Å 로 묶고 나머지 최적화. R 이 1.2 Å 늘면 두 O 모두 Zn 에서 2.6 Å 밖이 되므로 O 를 바꿔 끼워서는 채울 수 없습니다(모체 R_eq 와 +1.2 점의 두 Zn–O 를 결과에 적어 이 전제를 확인).
- **계열 셋**(클러스터 아홉 · 틀 묶기 · 한 점 에너지는 K-9 ①② 그대로): (가) 물 있음 · 치환 쪽 카복실레이트 (나) 물 있음 · 무치환 쪽 (다) 물 없음 · 치환 쪽. 출발은 K 의 (c) 와 같은 상태(물 있음 = 가장 낮은 물 붙은 상태 · 물 없음 = (a)).
- **풀기**: (가) · (나) 의 +1.2 점에서 R 묶기만 풀고 최적화 → 끝 상태를 **"되붙음"**(그 카복실레이트의 O 하나가 Zn 2.3 Å 안) / **"떨어진 채"**(두 O 모두 2.6 Å 밖 · 물이 Zn 2.5 Å 안인지 기록)로 가름.
- 점마다 기록: 그 카복실레이트 두 O 의 Zn 거리 · d(Zn–O_w) · Zn 2.5 Å 안 N · O 목록 · 결합 차수 · 표지(K-4 + 여섯 거리). 클러스터당 최적화 14회 · 합 126회 · 견적 1~1.5 h(이 기기 K 실측 16회 415 s).
- **기준 에너지 E_ref** = 그 클러스터 · 같은 물 수에서, K 와 K′ 를 통틀어 **묶기 없이 끝난 "붙은 상태"**(그 카복실레이트의 O 하나가 Zn 2.3 Å 안) 가운데 가장 낮은 값. 묶은 점은 기준에 쓰지 않음.
- **주 값 ΔE_떼기 = E(R_eq + 1.2 Å 점) − E_ref**(물 있음 · 치환 쪽). +1.2 에서 두 O 가 아직 2.6 Å 안이면 +1.6 점을 쓰고 그렇게 적음. 보조: 무치환 쪽 · 물 없음 · **ΔE_교체 = E("떨어진 채" 최소 · 물이 Zn 에) − E_ref**(그런 최소가 있을 때).
- **읽는 법**: ε′ = max(4 kJ/mol, 2 × 반복 클러스터끼리의 ΔE_떼기 차의 최대). ΔΔ = ΔE_떼기(치환판 · 치환 쪽) − ΔE_떼기(모체 · 같은 O). ΔΔ > +ε′ → "자른 마디 모형에서 그 치환기는 카복실레이트를 떼기 어렵게 한다" · < −ε′ → "떼기 쉽게 한다" · 사이 → "구별 불가". 안쪽 대조(치환 쪽 − 무치환 쪽)는 모체의 같은 차와 나란히. 쓸 수 있는 문장의 범위는 §K-6 그대로.
- **예측**: 모체 (다) 계열이 R 따라 한 방향으로 오름 0.8 · 모체 ΔE_떼기(물 있음) 40~120 kJ/mol 0.6 · +1.2 에서 물이 Zn 으로 들어옴 0.5 · 일곱 구조 ΔΔ 모두 ±ε′ 안 0.65 · 반복 차가 4 kJ/mol 을 넘어 ε′ > 8 이 됨 0.5.
