### J-2 읽는 법(결과 보기 전 고정 · `WATER_SITE_E22_20261108.md` §2 그대로 + 종류 하나 가름)
- **종류 정의 보완(자료 0건)**: 비배위 카복실레이트 O(`O_f`) = Zn 에 2.4 Å 안이 아니고 **O 둘을 가진 C 에 붙은 O** · 니트로 O(`O_n`) = **N 에 붙은 O**. 11-08 정의는 둘을 한 종류로 세어 −NO₂ 를 못 읽었음. 이 정의로 **기존 −NO₂ 323 K 격자도 다시 읽음**(격자는 이미 있으나 O_f 만의 값은 본 적 없음).
- 측정: 물 밀도 가운데 Zn · O_f · O_n · bib 원자 · 니트릴 N · 할로젠에서 3.5 Å 안의 몫과 기공 기준선 대비 배수(측정 2). 측정 1 은 병기.
- **물 접근 값** = (그 온도의 RH 90 % 흡착 물 mol/kg · 6씨앗 회수량 계산의 ads 값) × (물 밀도 중 O_f 3.5 Å 안 몫). 여섯 구조 × 두 온도 표.
- 판독 문장: 모체 대비 물 접근 값이 **두 온도 모두 0.67배 이하 → "물 접근이 모체보다 줄어듦"** · **두 온도 모두 1.5배 이상 → "늘어남"** · 그 밖 → "비슷하거나 온도에 따라 다름". Zn 3.5 Å 몫 ≥ 0.10 인 구조가 나오면 따로 적음.

## K. xtb 클러스터 — 물이 있을 때 Zn–O 를 늘리는 에너지 (HKHOME · 예비 laptop2)
### K-1 물음과 CIF 실측
치환기가 **자기 링커의 카복실레이트–Zn 결합**을 세게 하는가 약하게 하는가. CIF 에서 잰 사실(11-11 종합자): 열린 자리 설계의 Zn 은 모두 **치환 링커의 카복실레이트 O 하나 + 무치환 링커의 카복실레이트 O 하나 + 이미다졸 N 둘**(Zn–O 1.83~1.85 · Zn–N 1.98~2.00 Å · 이완 구조 — X선은 Zn–O 2.04~2.07). 치환기가 붙은 4,8-C 에서 Zn 까지 6.4~7.7 Å. 곧 한 마디 안에 **치환 쪽 Zn–O 와 무치환 쪽 Zn–O 가 나란히** 있어 안쪽 대조가 됩니다.

### K-2 클러스터(구조 7 · 마디 1개씩 + 반복 2)
- 구조: `e22_parent` · `e24i_{ch3,c2h5,cl,br,cn,no2}_open`(`charged_v3/<tag>_DDEC6.cif` — 좌표만 씀).
- 자르기: Zn 하나(CIF 순서 첫 Zn) + 배위한 이미다졸 둘은 **1-메틸이미다졸**로(부탄 사슬의 첫 CH₂ 를 CH₃ 로 — 끊은 C–C 방향 1.09 Å 에 H) + 배위한 bdtdc 둘은 **링커 전체**를 두고 먼 쪽 카복실레이트(이 Zn 에 안 붙은 쪽)에 H 하나(다른 Zn 에 붙어 있던 O 에 · O–H 0.97 Å)를 붙여 **중성**. 전하 0 · 닫힌 껍질. 원자 수: 모체 71(Zn 1 + 12 × 2 + 23 × 2) · 치환판은 치환기만큼 더.
- **고정 원자(격자 흉내)**: 두 메틸 C 와 두 먼 쪽 카복실 C — 네 원자의 직교좌표 고정. 나머지는 자유.
- 반복(잡음 재기): 모체와 −CN 은 **둘째 Zn 으로 자른 클러스터**를 하나씩 더(같은 계산 전부).
- 기준 결합: 모체에서 "치환 쪽" 에 해당하는 것은 **열린 고리 링커(4,8-H···O 4.1 Å 쪽)의 O** — 설계 구조의 치환 링커 O 와 분수좌표 0.3 Å 안으로 겹치는 O 로 고름(겹침 거리를 결과에 적음).

### K-3 계산(GFN2-xTB · 기체상 · `--opt tight`)
- (a) 물 없는 클러스터 최적화 → E₀ · d(Zn–O_치환) · d(Zn–O_무치환) · Wiberg 결합 차수 둘.
- (b) 물 하나: 출발 6가지(ZnN₂O₂ 사면체의 네 면 방향으로 Zn 에서 2.2 Å · 치환 링커의 비배위 O 에 수소결합 · 무치환 링커의 비배위 O 에 수소결합) 최적화 → 끝 상태를 **"Zn 배위"(d(Zn–O_w) < 2.5 Å) / "비배위 O 수소결합"(O_w–H···O < 2.2 Å) / 그 밖**으로 가르고 ΔE_w = E(클러스터·H₂O) − E₀ − E(H₂O).
- (c) **늘리기**: 가장 낮은 물 붙은 상태에서 d(Zn–O) 를 평형 + 0.4 · 0.8 · 1.2 Å 로 묶고 나머지 최적화(완화 스캔) — 치환 쪽 O 와 무치환 쪽 O 각각. 물 없는 클러스터에서도 치환 쪽 O 만 같은 스캔. → **ΔE_늘림(1.2 Å)** 셋(물 있음 · 치환 쪽 / 물 있음 · 무치환 쪽 / 물 없음 · 치환 쪽).
- 클러스터당 최적화 16회 · 9 클러스터 → 144회. 한 번에 **한 프로세스 · `OMP_NUM_THREADS=1` · `nice -n 19`**(CLAUDE.md §5 부수 작업 — RASPA 8 은 그대로). 견적 5~10 h(71~80원자 GFN2 최적화 1~4 분 — 이 기기 실측 없음 · 첫 클러스터로 갱신).

### K-4 표지 · 산출
- 표지: xtb 정상 종료 문구 · 최적화 수렴 문구 · 고정 원자 좌표 불변 · 전하 0 · 원자 수 · xtb 판 · 묶은 거리 달성(|d − 목표| < 0.02 Å). 하나라도 빠지면 그 값은 None(0 과 다름).
- 산출: `znbdt_k_xtb_cluster.py`(자르기 + 실행) · `results_znbdt_k_xtb_<기기>.json`(클러스터 · 상태별 E · 거리 · 결합 차수 · 표지) · `k_xtb_runs/<클러스터>/<상태>.xyz`(출발 · 끝 좌표 — 작으니 커밋). 값의 차 · 순위는 적지 않음.

### K-5 읽는 법(결과 보기 전 고정)
- **잡음 바닥 ε = max(4 kJ/mol, 2 × 반복 클러스터끼리의 가장 큰 차)** — 반복 차는 모체 · −CN 의 두 Zn 클러스터에서 ΔE_늘림 · ΔE_w 각각.
- 주 값: **ΔΔ = ΔE_늘림(물 있음 · 치환 쪽 · 치환판) − ΔE_늘림(물 있음 · 열린 고리 링커 쪽 · 모체)**. ΔΔ > +ε → "클러스터 모형에서 그 치환기는 Zn–O 가 모체보다 늘리기 어렵다" · ΔΔ < −ε → "늘리기 쉽다" · 사이 → "구별 불가".
- 안쪽 대조: 같은 클러스터의 치환 쪽 − 무치환 쪽 ΔE_늘림을 병기(부호가 주 값과 같은지).
- 보조: ΔE_w(Zn 배위)가 모체보다 ε 넘게 낮으면(더 안정) "물이 Zn 에 더 잘 붙음" · Zn 배위 상태가 아예 안 남는 구조는 그렇게 적음. 결합 차수 · 거리는 서술.
- 물 없는 스캔과 물 있는 스캔의 차(물이 늘리기를 얼마나 돕는가)는 서술.

### K-6 한계 · 쓸 수 있는 문장의 범위
이웃(상호침투) 망 · 기공 안 조임 · 여러 물 분자 · 자유에너지 · 반응 장벽이 없습니다. GFN2-xTB 는 Zn 카복실레이트 가수분해에 맞춰 검증된 방법이 아닙니다(오차 4~10 kJ/mol 급으로 봄). 고정 원자가 결과를 묶을 수 있습니다. 쓸 수 있는 것은 **"자른 마디 모형에서 치환이 Zn–O 를 늘리는 에너지를 바꾸는 방향과 크기"** 까지 — "내구성이 향상된다 / 떨어진다" 는 쓰지 않습니다.

### K-7 예측
- 일곱 구조 모두 ΔΔ 가 ±ε 안("구별 불가") 0.6 — 치환기가 Zn 에서 6~8 Å 떨어져 있음.
- −CN · −NO₂ 가 "늘리기 쉽다" 0.3 · −CH₃ · −C₂H₅ 가 "늘리기 어렵다" 0.1.
- 부호만 보면 −CH₃ · −C₂H₅ ≥ 모체 > −Cl ≈ −Br > −CN ≈ −NO₂ 순서(전자 주기/끌기) 0.5.
- 모체에서 물이 Zn 에 배위한 상태(5배위)가 최적화 뒤에도 남음 0.5.
