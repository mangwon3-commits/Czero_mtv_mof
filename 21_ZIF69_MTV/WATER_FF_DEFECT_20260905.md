# 물 힘장 결함 — `Hw`·`Lw` 가 `force_field_mixing_rules.def` 에 없어 UFF 수소 LJ 를 물려받았습니다

전부 그럴듯한 숫자를 냈습니다
**영향** **물이 들어간 모든 계산.** CO₂ 단독 계산은 무관합니다

## 1. 무엇이 잘못됐나

`forcefield/UFF_MOF/force_field_mixing_rules.def` 는 물 원자 중 **`Ow` 만**
정의합니다. `Hw` 와 `Lw` 항이 없습니다.

같은 파일 5행이 이렇게 적혀 있습니다:

    # IMPORTANT: define shortest matches first, so that more specific ones overwrites these

RASPA 는 **앞자리 일치**로 형을 찾습니다. `Hw` 는 자기 항이 없으므로
**17행의 `H_` (UFF 수소)** 를 물려받습니다.

    H_             lennard-jones   22.1417   2.57113      // UFF Rappe 1992

실행 출력 머리말이 그대로 찍습니다 — **값이 한 자리도 다르지 않습니다**:

    Ow -  Ow  [LENNARD_JONES] p_0/k_B:  89.63300 [K], p_1: 3.09700 [A]
    Ow -  Hw  [LENNARD_JONES] p_0/k_B:  44.54915 [K], p_1: 2.83406 [A]   <- 있어서는 안 됨
    Hw -  Hw  [LENNARD_JONES] p_0/k_B:  22.14170 [K], p_1: 2.57113 [A]   <- H_ 그대로
    WARNING: ... NO VDW INTERACTION Ow-Lw Hw-Lw Lw-Ow Lw-Hw              <- Lw 만 0

**TIP5P·TIP5P-Ew 에서 수소는 LJ 가 없습니다.** 전하만 있습니다.

## 2. 배포본이 정답을 갖고 있습니다

같은 RASPA 배포본의 `Dubbeldam2007FlexibleIRMOF-16/force_field_mixing_rules.def`:

    33: Ow             LENNARD_JONES    89.633    3.097
    42: Lw             none
    43: Hw             none

**`Ow` 89.633 / 3.097 은 우리 것과 같습니다.** 우리 파일은 이 줄을 가져오면서
**`Lw none` 과 `Hw none` 두 줄을 빠뜨렸습니다.** `CrystalGenerator` 는
`Hw lennard-jones 0.0 0.0` 으로 같은 일을 합니다.

## 3. 크기 — 수소 결합이 성립하지 않습니다

**이합체.** 선형 수소결합 배치에서 O–O 거리를 훑었습니다(전하 ±0.241, 우리 water.def 기하):

    설정                    우물 깊이        우물 위치
    Hw LJ 없음 (TIP5P 원본)   −22.9 kJ/mol     O–O **2.70 Å**   <- TIP5P 문헌 2.71 Å
    Hw LJ 있음 (우리 것)      −10.0 kJ/mol     O–O **3.60 Å**

**우물이 0.9 Å 밀려나고 2.3배 얕아집니다.** 원인은 `Ow–Hw` 의 σ = 2.834 Å 입니다 —
O–O 2.8 Å 인 수소결합에서 주개 H 는 받개 O 로부터 **1.85 Å** 인데, 그 자리가
LJ 반발벽 한가운데입니다.

**액체 구조 (지금 도는 T-B1 의 실제 배치, 1000분자, 0.997 g/cm³):**

    O–O 첫 봉우리      **3.32 Å**   (액체물 2.80 Å)
    g(2.82 Å)          **0.18**     (액체물 ≈ 2.9)  <- 첫 껍질이 **없습니다**
    3.5 Å 이내 배위수  **6.19**     (액체물 ≈ 4.5)  <- 사면체가 아니라 **조밀 충전**
    최소 O–O           2.735 Å

**사면체 수소결합망이 아니라 LJ 구 더미입니다.**
