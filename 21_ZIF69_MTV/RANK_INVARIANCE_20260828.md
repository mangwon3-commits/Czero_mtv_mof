# 실현 순위가 RH 를 가로질러 보존됩니다 — 자리 산포의 독립 증거 (2026-08-28)

**`R` 을 몰라도 성립합니다.** 08-28 에 세 세션이 재실행으로 실행 잡음 `R` 을
재고 있었는데, 군 B 저압 자료 안에 **`R` 을 전혀 쓰지 않는 증거**가 이미
들어 있었습니다.

## 1. 관측

`sa50nb50` 실현 5개(생산·e1~e4)를 RH 5/10/15 에서 각각 **별개의 RASPA
작업**으로 돌렸습니다(시드도 각각 다름 — `RASPA_SEED_20260828.md`).

```
물 로딩                                              순위
rh05   0.1497  0.0339  0.3376  0.2776  0.3038      2 1 5 3 4
rh10   0.2623  0.0600  0.4985  0.3875  0.4437      2 1 5 3 4
rh15   0.3459  0.0888  0.5862  0.4750  0.5122      2 1 5 3 4

CO2 로딩                                             순위
rh05   1.0634  0.8291  1.0329  1.1029  1.1081      3 1 2 4 5
rh10   1.0390  0.8215  0.9983  1.0515  1.0629      3 1 2 4 5
rh15   1.0122  0.8163  0.9817  1.0123  1.0218      3 1 2 4 5
```

**두 관측량 모두 세 RH 에서 순위가 완전히 같습니다.** Spearman ρ = +1.000
(세 쌍 전부).

## 2. 왜 이것이 자리 산포의 증거인가

세 RH 는 **독립 실행**입니다. 흩어짐이 실행 잡음이라면 순위가 RH 마다
섞여야 합니다. 안 섞입니다.

    귀무(다섯 실현의 참값이 같고 차이는 전부 잡음):
      각 RH 의 순위가 독립 균등 순열  ->  셋이 일치할 확률 = 1/120² = **6.9e-05**

**관측량마다 따로 성립하므로 두 번입니다.**

## 3. ★ 그리고 두 순위가 **서로 다릅니다**

```
물   2 1 5 3 4
CO2  3 1 2 4 5
```

**이것이 "그 실현이 그날 운이 좋았다" 류의 실행 인공물을 배제합니다.**
실현 단위의 실행 편향이라면 물과 CO₂ 순위가 **같이** 움직여야 합니다.
다르다는 것은 **자리 배치가 관측량별로 다른 방식으로 작용한다**는 뜻이고,
그것은 구조의 성질입니다.

> `batch-dispersion-is-per-observable` 와 같은 이야기가 순위 층위에서
> 다시 나옵니다 — 산포의 **크기**만 관측량별인 것이 아니라 **순서**도
> 관측량별입니다.

## 4. 🔴 [정정] 이 시험은 `R_true` 를 못 가릅니다

**처음에 여기에 *"순위 시험이 `R_true = 0` 을 직접 깬다"* 고 적었습니다.
틀렸습니다.** 데스크탑이 잡았고 재현했습니다.

**2절의 귀무(다섯 실현이 같다)는 이미 죽어 있던 귀무입니다.** `e1`(0.06)과
`e2`(0.50)이 오차막대 수십 개 떨어져 있으므로, 그 귀무는 순위를 보기 전에
끝나 있었습니다. **`6.9e-05` 는 아무도 세우지 않은 허수아비를 겨눕니다.**

`R_true` 를 가르려면 두 후보에서 순위가 다르게 행동해야 하는데, 안 합니다:

```
인접 간격 24쌍 전수, 기대 뒤집힘 횟수
  R_true = 0   (통계만 0.006)    **1.06회**   관측 0 의 Poisson p = 0.35
  R_true = R̂  (0.0089)          **1.45회**   관측 0 의 Poisson p = 0.23
  관측                            **0회**     ->  **양쪽과 정합**
```

**두 후보가 실현 간 간격보다 한참 작아 순위를 거의 못 건드립니다.**
`R_true` 가 순위를 흔들려면 `~0.02` 이상이어야 하는데 **그런 후보를 아무도
제안한 적이 없습니다.**

> **기기 차이 봉투 `p ∈ [0.0006, 0.073]` 는 그대로 열려 있습니다.**
> 좁히는 것은 Junseok `n=8` 과 데스크탑 `r2·r3` 뿐입니다.

### 4-1. ⚠️ `ρ=+1.000` 안에 동전 던지기가 하나 있습니다

```
CO2 rh15   생산 1.0122  대  e3 1.0123    간격 **0.0001**
```

**이 쌍의 순서는 어느 잡음 수준에서도 50/50 입니다.** 세 RH 에서 일치한
것은 동전이 맞은 것이고, **"완전 보존 세 번" 의 정보량은 `6.9e-05` 보다
실제로 적습니다.**

그리고 이 한 쌍이 기대 뒤집힘의 대부분을 만듭니다:

```
24쌍 전부        R_true=0 기대 1.06   ·  R̂ 기대 1.45
동전 쌍 제외 23쌍  R_true=0 기대 **0.56**  ·  R̂ 기대 **0.95**
```

**인용할 때 이 쌍을 빼거나 각주로 다십시오.**

## 4-2. 그러면 순위가 실제로 보태는 것

| 명제 | 주 근거 | 왜 |
|---|---|---|
| 자리 산포 **실재** | `e1` 대 `e2`, **z ≈ 40** | 가장 단순. 순위 필요 없음 |
| **구조 특유** (런 특유가 아님) | **순위 보존** | 차이가 **조건(RH)을 넘어 따라옴** |
| **관측량별로 다르게 작용** | **물/CO₂ 순위 불일치** | 순위가 아니면 못 봄 |
| 산포의 **크기** | 배치 SD ± `R̂` | `n=8`·`r2·r3` 대기 |
| **기기 차이** | 봉투 `[0.0006, 0.073]` | **미결** |

**"실재" 의 주 근거는 순위가 아닙니다** — `z≈40` 한 줄이 더 짧고 가정도
없습니다. **순위의 제 용도는 "지속성"** 입니다: 차이가 세 조건을 가로질러
따라오므로 런 특유가 아니라 구조 특유입니다. `F` 검정(크기)과 겹치지
않습니다.
