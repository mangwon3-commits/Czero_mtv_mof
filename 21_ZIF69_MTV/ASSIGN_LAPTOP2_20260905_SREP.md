# laptop2 배정 — 포스터 대표 수치의 **실행 간 산포** (2026-09-05 16:1x, 데스크탑)

**측정 전 등록문입니다.** laptop2 가 유휴(실행 중 계산 0)이고, 이 일은
**물 힘장 판단과 무관**합니다 — 건조 Widom 뿐입니다.

## 1. 왜 이것인가

포스터가 걸린 수는 **CO₂/N₂ 헨리 선택도 `base` 20.10 → `saIm100` 150.91 = 7.51배**
입니다. 그런데 그 `±` 는 **한 실행의 블록 다섯**이고 **실행 간 산포가 없습니다.**

    base      20.10 ± 0.45  (2.2%)
    saIm100  150.91 ± 13.72 (**9.1%**)   <- 불확실성이 여기 있습니다
    배율 **7.51 ± 0.70**,  차이 **9.5 단위**

**배치 산포는 구조적으로 0 입니다** — 0% 와 100% 치환은 실현이 **하나뿐**이라
빌더 씨앗이 고를 자리가 없습니다. **그래서 빠진 것은 실행 간 산포 하나뿐이고,
이 둘만 재면 대표 수치의 오차가 완결됩니다.**

## 2. 무엇을 재나

    대상   **`base`** 와 **`saIm100`**  (대표 수치의 양 끝)
    양     Widom **K_H(CO₂)** 와 **K_H(N₂)**  ->  선택도 = K_H(CO₂)/K_H(N₂)
    반복   각 구조 **5 실현**  (씨앗만 다름. 구조·덱 동일)
    덱     `run_aryl_gcmc.py` 그대로 — NumberOfCycles **15000** /
           NumberOfInitializationCycles **3000**, UFF_MOF, 컷오프 12, Ewald 1e-6, 1e-5 Pa
    작업수 2구조 × 2기체 × 5실현 = **20건**

## 3. 확인 조건 — **씨앗이 실제로 다른가** (측정 전 등록)

RASPA 는 **작업 폴더 생성 시각 +3초**로 씨앗을 만듭니다
(`RASPA_SEED_20260828.md`). **워커 여럿이 같은 초에 폴더를 만들면 씨앗이 겹칩니다.**

    각 실행의 `.data` 에서 씨앗을 읽어 **20개가 서로 다른지** 확인한다.
    겹치면 **그 쌍은 독립 실현이 아니므로 제외**하고, 남은 수로 다시 센다.
    씨앗 20개를 **판정문 본문에 숫자로** 적는다.

> 오늘 여러 번 확인한 자리입니다 — **의도한 것이 실제로 일어났는지 값과 별개로 봅니다.**
> 이 조건이 없으면 **겹친 씨앗이 산포를 작게 만들고, 작은 산포는 좋은 소식으로 읽힙니다.**

### 3-1. ⚠ **[16:5x 추가, laptop2 발견] 이어받기가 반복을 무효로 만듭니다**

**이 배정문의 구멍이었습니다.** `run_aryl_gcmc.run_one` 은 실행 폴더를
`{mode}_{gas}_{cif이름}` 으로 짓고 **끝난 실행을 캐시로 돌려줍니다**
(`if done: return ... 'cached'`). **같은 구조를 5번 돌리면 다섯 번 다 같은 폴더로
가고 캐시가 첫 결과를 다섯 번 줍니다.**

    -> **`s_rep` 이 정확히 0 으로 나옵니다.**

**씨앗 겹침보다 나쁩니다** — 겹침은 산포를 **줄이고**, 이건 **0 으로 만듭니다.**
그리고 **`s_rep = 0` 은 이 시험에서 가장 좋은 소식**입니다(대표 수치가 완벽히 재현).
**검사 9-1 그대로** — **실패가 "아무 일 없음" 으로 떨어집니다.**

    **고침** (laptop2): CIF 를 실현마다 다른 이름으로 복사해 **폴더를 가른다**
             (`base_r1_DDEC6.cif` …). 구조·덱은 동일.
    **사전** 워커 기동을 **2초씩 어긋냄**(씨앗 해상도 1초보다 크게).
             실측 16:52:45/:47/:50/:52/:54/:56 — 전부 갈림
    **사후** `/proc/PID/cwd` 로 여섯이 서로 다른 폴더인지 확인 (기동 직후 완료)

### 3-2. 등록 추가 — **`s_rep = 0` 은 결과가 아니라 실패 신호**

    구조별 `s_rep` 이 **정확히 0** 이면 -> **판정하지 않고 실패로 적는다.**
    산출물 경로 20개가 **서로 다른지** 먼저 확인한다.

> **CLAUDE.md §3 의 새 얼굴입니다.** §3 은 *"이어받기가 설정을 검사하지 않는다"* 를
> 경고하는데, 여기서는 **설정이 같아도** 이어받기가 **시험의 목적(독립 반복)을
> 무효로 만듭니다.** 설정이 아니라 **의도**가 어긋나는 경우입니다.

## 4. 판정 — 측정 전 등록

    낸다   구조별 s_rep(선택도), 비 **r = s_rep / ±**,
           그리고 결합 `±' = √(±² + s_rep²)` 로 다시 센 **base ↔ saIm100 단위**

    **≥ 1.5 단위**   대표 수치 **유지**. "실행 간 산포 포함" 으로 병기하고 인용 가능
    **< 1.5 단위**   대표 수치 **못 씀**. 포스터에서 내린다
    **r > 3**        **별건 경보** — 저장소 실측(0.66 × ±)의 4.5배. 이 시험을 넘어
                     모든 단일 실현 판정에 걸립니다. 그 경우 판정보다 **먼저 보고**

### 예상 (등록해 둡니다)

`RASPA_SEED_20260828.md` 배너의 실측 **s_rep ≈ 0.66 × ±** 를 넣으면 **약 8.0 단위**,

> **그래서 이 시험의 값어치는 "통과 여부" 가 아니라 "물려받은 추정을 실측으로
> 바꾸는 것" 입니다.** 지금 대표 수치의 오차는 **다른 조성에서 잰 비율**을 빌려
> 온 것이고, 이 둘에서 직접 잰 적이 없습니다.

## 5. 이 시험이 **하지 않는** 것

- **물 힘장 결함과 무관**합니다. 건조 Widom 이고 `Ow`/`Hw`/`Lw` 가 안 들어갑니다
  (`ff_type_audit.py`: `C_co2`·`O_co2`·`N_n2`·`N_com` 전부 정확 일치).
- **배치 산포를 안 잽니다** — 이 두 구조에서는 구조적으로 0 입니다.
  **사다리 중간(saIm025/050/075)에는 배치 산포가 있고 이 시험이 안 다룹니다.**
- **n=5** 입니다. `s_rep` 의 상대 불확실성이 `1/√(2·4) = 35%` 입니다
  (`ERROR_BARS.md` 상단 — **비를 볼 때는 2.776 환산이 필요 없습니다**).
