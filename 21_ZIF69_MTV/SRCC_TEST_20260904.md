# T-SRCC — 건조 평형 지표의 습윤 성능 **순위 보존** 검정 등록문 (2026-09-04, 데스크탑)

> **용어 등록**: 이 문서가 `T-SRCC` 를 정의합니다(CLAUDE.md §8). SRCC =
> Spearman's rank correlation coefficient. 출처: Zhao et al., *Matter* 8, 102140
> (2025), "CoRE MOF DB" Fig. 9 — 35개 후보 MOF 에서 평형 지표(선택도·작업 용량)와
> 공정 지표(TSA 순도, 회수율 90% 제약)의 순위 일치도를 SRCC 로 잰 분석.

## 0. 논문 방법을 그대로 옮기지 않는 이유 — 셋

| | 논문 | 우리 | 이 등록문의 처리 |
|---|---|---|---|
| 종속변수 | 공정 모사 CO₂ 순도·회수율 | **공정 모사 없음** | 종속변수를 **습윤 성능**(습윤 TSA WC · RH90 유지율)으로 둔다. 논문의 결론("평형 지표는 공정 성능을 못 맞힌다")은 **이식하지 않는다** — 우리는 그 질문을 묻지 않는다 |
| n | 35 | 11 (습윤 WC) · 7 (유지율) | n 과 p<0.05 임계 ρ 를 판정문에 병기. n=11 임계 ≈ 0.62, n=7 ≈ 0.79 |
| 불확실성 | 점값으로 순위 | `±` 는 95% CI 이고 1.5 단위 미만은 순위를 안 매김(CLAUDE.md §2) | 점 ρ 가 아니라 **`±` 에서 재추출한 부트스트랩 ρ 구간**으로 판정 |

## 2. 방법 — 수를 보기 전에 고정

    통계량   Spearman ρ (scipy.stats.spearmanr, 동순위 평균 순위)
    부트스트랩  각 점을 정규분포 N(값, σ) 에서 재추출.
             σ = ±/t(0.975, dof) — **점마다 자유도가 다르다**: RASPA 단일 실현은
             5블록이라 dof 4(2.776), 실현체 n개의 앙상블 평균은 dof n−1(n=6 이면
             2.5706). `ERROR_BARS.md` 211행. [09-04 정정, 랩탑 지적]
             N = 10,000회, seed 20260904, (X, Y) 쌍마다 새 난수 흐름
             → ρ 의 2.5 / 97.5 백분위 = **부트스트랩 95% 구간**
    감도     [판정 아님] σ_Y 에 saIm0583 배치 SD(0.0580, T-1)를 합성해 같은 구간을 한 번 더.
             단일 실현의 ± 에 배치 산포가 없다는 사실의 크기만 보인다
    보고     n · 점 ρ · p · 부트스트랩 구간 · 감도 구간 · p<0.05 임계 ρ — 전부 병기

## 3. 판정 — 수를 보기 전에 고정

각 (X, Y) 쌍에 대해:

| 결과 | 판정 |
|---|---|
| 부트스트랩 95% **하한 ≥ 0.6** | **순위 보존 지표로 채택** — X 로 Y 의 후보 순서를 정해도 된다 (T-B2 의 등록값 0.6 과 정합) |
| 하한 < 0.6 이고 점 ρ ≥ 0.6 | **미확정** — 점값은 넘지만 `±` 안에서 흔들린다. 채택하지 않고 n 을 늘린다 |
| 점 ρ < 0.6 | **기각** — X 는 Y 의 순위를 보존하지 않는다 |

감도 구간이 판정을 뒤집으면(채택인데 감도 하한 < 0.6) **"배치 산포 미측정 조건부"** 를 판정에 붙인다.
