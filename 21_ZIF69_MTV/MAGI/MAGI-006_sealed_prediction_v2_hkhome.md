## 규약 선언
- DoF: **결함 인지 공통 DoF**(수율 손실이 결함으로 나므로). CD 기준 공통 DoF 는 상한 참고.
- 결합: 주 = **Mack(무작위 RSS + 계통 선형)**, 선형 합·전 RSS 는 감도 상·하한.
- 스캐너 항: **팹 모니터 ±8(3σ, 반폭) → 전폭 16**(같은 장비군 실측 · 필드 내 포함). 제조사 10 은 폭 규약 불명이라 감도로만.
- 폭 규약: 전부 **전폭**으로 통일해 DoF(창 폭)와 비교.
- **패턴 간 최적 초점 편차는 공통 DoF 정의 안에 이미 들어 있으므로 예산에 다시 넣지 않는다**(넣으면 이중 계상 — 오차 항목 표의 함정).
- 토포: 평균과 최대를 둘 다 계산, 판정은 평균 기준 + 최대 기준 병기.

## Q1 (레버 없음) — 무작위 RSS: LP 스택 √(16²+12²+14²+1.5²)=24.5 · MC/M1 스택 √(16²+12²+8²+1.5²)=21.6. 계통 고정 = 렌즈 5 + 레지스트 3 = 8.
- LP: 예산 24.5+8+22 = **54.5**(최대 토포 66.5) vs 58(45~70) → 마진 **+3.5 / −8.5**. 선형 합 −15.5 · 전 RSS +24.6. 창의 95 % 구간(±13)보다 마진이 작다 → 산술로는 **판정 불가**; 그러나 현 세대 LP 가 더 큰 마진(+17.5)에서도 0.3 %(목표 초과)였고 N+1 은 모든 항이 더 나쁘다 → 목표 0.2 % 기준 **부족** (확신 중).
- MC: 예산 21.6+8+80 = **109.6**(최대 139.6) vs 48(35~60) → **−62**(전 RSS 로도 −35) → **부족** (확신 상, 어느 규칙이든). 파일럿 4~8 % 와 정합.
- M1: 예산 21.6+8+65 = **94.6**(최대 124.6) vs 72(60~84) → **−23** → **부족** (확신 중상). 현 세대 정합(Q3)이 이 모델이 M1 에서 보수적임을 시사하나 부호를 뒤집을 만큼은 아님.

## Q2 레버
- **MC·M1 은 평탄화가 유일한 닫는 레버** — 토포가 예산의 70 % 이상. P1 은 CD 기준 +9~15 nm(결함 인지 이득 미측정), P2 는 +2~3 nm(재현성 성분 30 % 감소 → RSS 21.6→18.9) 뿐.
  - C1 만: MC 토포 42 → 예산 71.6 vs 48 → **−24, 불충분.** M1 토포 37.5 → 67 vs 72 → +5(얇음).
  - **C2**: MC 토포 20 → 49.6 vs 48 → **≈ 0(−1.6)**; M1 토포 17 → 46.6 vs 72 → **+25 확보.**
  - **권고 MC = C2 + P1(+ P2 팹 공통)** → 예상 마진 MC **+4~+11**(P1 결함 인지 이득을 CD 이득의 0.66 배로 가정한 값 — 미측정), M1 +25~+28.
  - 비용: C2 3.5만원/장 = **252억/년** + 마스크 1억 + 공정 +1.2일 + CMP 결함 −0.05~0.15 % = 54~162억/년 → 합 306~414억/년. P1 MC 마스크 5억 + 30인·주(일회). P2 120억(일회, 7개 레이어 공통).
  - 대안 **X1**(MC ArF 유지): 432억/년 + 오버레이 여유 ≤ 2 nm 위험 + N+2 High-NA 경로 지연. **C2 제품 레이아웃 검증이 실패하면 X1 로 회귀**하는 조건부 예비안.
  - C3 는 1,400억 일회 + 실적 0 → 이번 세대 채택 안 함(N+2 후보로 평가 착수만).
- **LP**: 평탄화 레버가 없다(커패시터 전). **P1 + P2**(+ 레벨 센서 스택 오프셋 보정, 목록 밖 · LP 스택 14 → 6~8 로 RSS −3 nm 정도) → 마진 **+10~+19**. 그러나 현 세대 +17.5 가 0.3 % 였으므로 **0.2 % 를 장담 못 함.** **D1**(순다이 −0.4 % = 확정 −432억/년 상당) 은 LP 손실이 0.6 % 를 넘어야 남는 장사 → 기대값 중앙에서는 **넣지 않되**, 설계 동결이 데이터보다 먼저 오면 그 시점에 P1 결함 인지 파일럿 결과로 재판단(**결정 시한이 자료보다 앞서는 자리** — Balthasar 형 계획 변경).
- 남는 위험: P1 결함 인지 이득 미측정(모의만) · C2 의 M1 수치는 추정 · CMP 결함 · MC FEM 웨이퍼 1장(창 35~60) · 가장자리 다이 토포 최대치.

## Q3 정합 — **같은 규칙이 두 레이어에서 반대 방향으로 어긋난다.**
- 현 세대 LP: Mack 24.5+8+20 = 52.5 vs 70 → **+17.5** 인데 손실 **0.3 %**(모델보다 나쁨).
- 현 세대 M1: 21.6+8+70 = 99.6 vs 95 → **−4.6** 인데 손실 **0.2 %**(모델보다 좋음). 선형 합이면 −20.5.
- 원인 후보(우선순위): ① **토포의 길이 척도 대 레벨 센서 분해능(1 mm)** — LP 토포는 100 µm 셀 블록 가장자리라 어디에나 있고 레벨링이 못 따라감(전부 유효) · MC/M1 토포는 셀–페리 경계(전이 5~10 µm) 근처 ~1 mm 띠에만 유효 → 같은 nm 가 다른 면적 비율의 다이를 때림. ② **수율 손실은 꼬리 현상** — 평균 토포가 아니라 가장자리 다이의 최대 토포와 3σ 초과 확률이 정하므로 "마진 한 수" 는 손실과 1:1 이 아님(마진→손실 곡선이 필요). ③ LP 스택 레벨 센서 오차 14 는 금속 하지 패턴 밀도에 묶인 **계통 성분**일 가능성(무작위로 RSS 하면 과소). ④ 결함 인지 DoF 의 CI(64~76 · 88~102)와 12개월 드리프트.
- Q1·Q2 에의 영향: LP 판정은 **더 나빠짐**(③이면 예산 +7 → 마진 −4) → 부족 확정 쪽. MC/M1 은 **평균 기준으로는 덜 절망적**이나 꼬리(최대 토포 110/95)는 그대로 → 레버는 평균이 아니라 **최대치를 15~25 로 내리는 C2** 여야 하고 C1(최대 미확인)로는 부족 — 방향 불변, 크기 조정.
