## 2. Q1 판별

**공통 가정**: ① 자 = 결함 인지 공통 DoF. ② 현 세대와 N+1 의 "초점 관련 수율 손실" 귀속 방법이 같고, 같은 층 유형 안에서 마진이 줄면 손실이
줄지 않는다(단조). ③ MC 는 같은 MC/M1 스택·셀+페리 양쪽 패턴이므로 M1 의 "마진 ↔ 손실" 사상을 빌린다(가장 약한 가정, §8).
판정은 **절대 마진 표 + 앵커 차 + 파일럿 손실 추정** 세 갈래가 같은 쪽을 가리키는지로 냅니다.

### (c) 평탄화 1회의 수혜 EUV 레이어 수 n

- ILD CMP 는 MC·M1 둘에 단차를 물려줌 → **X1 없이 n = 2, X1 이면 EUV 기준 n = 1**(MC-ArF 도 혜택은 받지만 ArF DoF 가 커서 nm 당 가치가 낮음).
- 평탄화 비용은 **공정 단계당**(웨이퍼당), 이득은 **레이어당** → 레이어당 연간 비용 = 비용 / n. C2(306~414) → n=2 레이어당 153~207 · C1(57.6) → 28.8.
- 평탄화를 정당화하는 부족분 문턱(목표 근처 nm 당 가치 ≈ 0.057 × 0.2 %p × 1,080 억 ≈ **연 12 억원/nm/층**, [가설] 사상):
  C2 중앙 360 억 → n=1 **약 29 nm** · n=2 **약 15 nm**/층. C1 → 4.7 / 2.3 nm. C3 연 운영비 144 억만으로 n=1 12 nm · n=2 6 nm(일회성 1,400 억은 따로 — 회수 기간 = 1,400 / (가치 − 144)).

- 즉 X1 은 MC 의 노광 비용만이 아니라 **평탄화의 경제성을 반으로 깎는 결정**이기도 합니다. N+2 에서 MC 가 High-NA 가 되면 n 은 그대로 2 인데
  그중 한 층의 nm 당 가치가 커져 평탄화(특히 C3 급)의 정당화 문턱이 더 내려감.
- 확신도: (a) 중 (nm 천장은 모의 % × 빌린 비율) · (b) **하** (0.55NA 오차 항 실측 없음, 결함 인지 비율 미측정, LP급 DoF 를 MC 에 씀) · (c) 산술 상 · 가치 환산 하.

    근거: MC 파일럿 손실의 화폐 가치 연 4,320~8,640 억 ≫ 어느 안의 비용(57.6~489.6).
    틀렸다면: MC 파일럿 손실 추정(표본 작음)이 한 자릿수 과대였을 것 — 그래도 C1 급 비용은 정당화됨.

**B-10. 실적 있는 레버와 없는 레버의 가치 차는 "기대 이득" 보다 "분산" 에 있다.** `[가설]`
    근거: C1(테스트 패턴)은 중앙 이득이 C2 의 70 % 인데 비용은 1/5 — 기대값으로는 박빙. 차이를 만드는 것은 C1 의 이득 범위(30~45)와
          미확인 스크래치라는 **꼬리**이고, C2 는 CMP 결함 −0.05~0.15 % 라는 **정량된 꼬리**.
    틀렸다면: 단락 흐름(Q5 ②)에서 C1 이 좁은 범위로 좋은 끝에 떨어질 것 — 그러면 B 로 갈아탐.

**B-11. X1 은 가장 비싸고, 정량 안 된 오버레이 위험을 지며, N+2 경로를 잘라낸다.** `[산술]` `[모의]`
    틀렸다면: MC 오버레이 여유 실측이 ≥ 4 nm 이고 N+2 가 MC 를 High-NA 로 안 옮기기로 할 것 — 그러면 X1 은 "비싼 안전안" 으로 남음.

**B-12. 결정 순서는 되돌릴 수 없음과 리드타임이 정한다 — D1 이 가장 먼저 닫히고, X1 은 가장 늦게까지 열어 둘 수 있다.** `[가설 — 일정 논리]`
    틀렸다면: 설계 동결이 이미 지났거나(그러면 D1 은 판단 대상이 아님), ArF 이중 패터닝 공정 자격 유지 비용이 문제 밖에서 클 것.

**B-13. 0.55NA 에서 Photo 레버의 nm 천장은 거의 그대로이고 평탄화 문턱은 약 9~20 nm 내려간다.** `[산술]` + `[가정: 결함 인지 비율·오차 항 빌림]`
    틀렸다면: 0.55NA 결함 인지 비율이 0.33NA 보다 훨씬 높거나(> 0.9) 0.55NA 초점 오차 항이 nm 로 크게 줄 것.

**B-14. 평탄화의 경제성 문턱은 수혜 레이어 수에 반비례한다.** `[산술]`
    틀렸다면: 평탄화 한 번이 두 층에 **같은 크기**의 단차 감소를 주지 않을 것(문제는 M1 효과를 `[추정]` 으로만 줌).

## 8. 자기 반박 — 이 답의 급소

**MC 필요량 57 nm 는 "MC 가 M1 처럼 사상된다" 에 서 있고, 바로 이 R1 의 Q3 가 층마다 사상이 다르다는 것(LP 가 약 25 nm 옮겨짐)을 보였습니다.**
MC(콘택 누락·브리지)는 M1(라인)과 불량 방식도 다이당 기회 수도 다릅니다. MC 가 LP 쪽으로 옮겨져 있다면 필요량이 70~80 을 넘어 권고안 A 의 이득(62~83)으로
부족하고 **X1 이나 C3 가 필요**해집니다. 반대로 M1 보다 관대하면 B(C1)로 충분해 연 248~356 억을 아낍니다.
**드러날 관측**: Q5 ② 의 단락 흐름 웨이퍼에서 잰 MC 토포·결함 인지 DoF 와 같은 웨이퍼의 파일럿 수율. 그리고 두 번째 급소 — 파일럿 DoF 는 공정 성숙 전 값이라
양산까지 오를 수 있는데(학습 곡선), 이 R1 은 그 몫을 0 으로 뒀습니다. 오르는 쪽이면 LP 판정이 "부족 → 판정 불가" 로 움직일 수 있습니다.

## 9. 용어표 (이 문서 안 정의)

| 용어 | 이 문서 안 정의 |
|---|---|
| DoF | 초점 심도 — 규격을 만족하는 초점 범위의 **전폭**(nm) |
| 패턴별 / 공통 / 결함 인지 공통 DoF | 한 패턴의 창 / 모든 패턴이 동시에 CD 규격을 지키는 겹침 창 / 초점 관련 결함 밀도가 팹 기준 이하인 겹침 창(문제 §2-1 정의) |
| EL | 노광 관용도 — FEM 에서 CD 규격을 지키는 선량 범위(여기선 10 %로 고정된 조건) |
| FEM | 초점–노광 매트릭스 — 샷마다 초점·선량을 바꿔 찍어 창을 재는 웨이퍼 |
| SMO / SRAF / OPC | 광원–마스크 동시 최적화 / 해상 안 되는 보조 패턴 / 광학 근접 보정(마스크 모양 보정) |
| ILD / CMP | 층간 절연막 / 화학 기계 연마 |
| p-v | 최고–최저 차(전폭) |
| 3σ | 표준편차의 3배. "±3σ" 는 반폭, 전폭은 6σ |
| 레벨링 | 노광 전 웨이퍼 높이를 레벨 센서로 재 초점면을 맞추는 동작. 센서 공간 분해능 약 1 mm 보다 짧은 높이 변화는 못 따라감 |
| 레벨 센서 공정 의존 오차 | 하부막 구조·금속 반사 때문에 센서가 읽는 높이가 실제 표면과 다른 몫 |
| 마스크 3D | 마스크 흡수체 두께 때문에 패턴마다 최적 초점이 달라지는 효과 |
| High-NA | 개구수 0.55 EUV. 해상도는 높고 DoF 는 좁음 |
| 무작위 / 계통 | 서로 독립으로 흔들려 제곱합하는 항 / 한 자리에서 같은 부호로 겹쳐 선형합하는 항(이 문서의 Mack 규칙) |
| 앵커 차 | **이 R1 이 만든 말.** 같은 규칙·스캐너·토포 통계 칸에서 "N+1 마진 − 앵커(손실을 아는 현 세대 층) 마진". 0.2 % 에 닿기 위해 더 필요한 nm |
| 앵커 여유 | 레버 이득 − 앵커 차. 양수면 앵커 손실 이하로 예상 |
| δ | **이 R1 이 만든 말.** LP 를 0.3 % 에서 0.2 % 로 내리는 데 더 필요한 nm. B-7 의 가설 사상에서 6~8 |
| T* | **이 R1 이 만든 말.** Photo 레버만으로 앵커 여유를 채울 수 있는 최대 잔여 토포(평균) — 이보다 크면 평탄화 필요 |
| G0~G3 | **이 R1 이 만든 말.** §3-5 의 결정 관문(지금 / 설계 동결 전 / 단락 흐름 뒤 / P1 마스크 뒤) |
| 인·주 | 한 사람이 한 주 일한 양 |
| 설계 동결 | 레이아웃 변경을 더 받지 않는 시점 — D1 의 마감 |
| 단락 흐름 | 전체 공정이 아니라 해당 구간만 돌리는 시험 웨이퍼 흐름 |
| 재공 | 공정 중에 있는 웨이퍼(WIP). 공정 기간이 늘면 늘어남 |
