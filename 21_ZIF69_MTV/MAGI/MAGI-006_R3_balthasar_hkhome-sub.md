### D-5 ← A-5 (수용 — 상위 원인 둘에 정합 검산 한 줄씩. 결과: 한 원인으로는 두 층을 못 맞힘)

모형은 가우스 무작위 꼬리입니다(σ = Mack 무작위 RSS ÷ 6, 반창 = 3σ + 마진/2, 다이당 "초점 독립 조각" N 개). ⚠ p-v 항을 6σ 로 친 것부터가 [[J §1 4번]]이 지적한 근사이므로 **자릿수 검산**으로만 읽어 주십시오. `[산술 + 가설]`

- **H1(층마다 사상이 다름 — 다이당 기회 수)**: 현 세대 Mack·s16·평균에서 한 조각의 이탈 확률은 LP **2.7×10⁻⁷**, M1 **1.8×10⁻²** 입니다. 0.3 % 와 0.2 % 를 동시에 맞히려면 다이당 독립 조각 수의 비가 **LP/M1 ≈ 1.0×10⁵** 이어야 합니다. 초점 오차가 mm 급(LS 분해능 1 mm)으로 상관돼 있으면 같은 다이 면적에서 독립 조각 수는 층과 거의 무관합니다. → **H1 단독으로는 자릿수(10⁵)가 안 맞습니다.** 셀 수가 많다는 것만으로는 부족하고, 꼬리가 비가우스여야 합니다(H4 로 넘어감).
- **H3(LP 스택 LS 오차가 계통)**: LS 14 를 계통 선형으로 옮기면 현 LP 예산이 **+9.6 nm**, 마진이 +17.5 에서 **+7.9** 가 됩니다. 이때 k = 4.19 이고, 다이당 조각 100 이면 손실 **0.28 %**(관측 0.3 %)입니다. ⚠ **숫자를 맞혔고, 조각 수 100 은 제가 고른 값입니다**(10 이면 0.03 %). 같은 모형을 M1 에 대면 조각 **하나**만으로도 이탈 1.8 %(LS 계통이면 18 %)라 0.2 % 가 불가능합니다. M1 이 0.2 % 이려면 평균 토포의 소모가 **다이 면적의 0.1~1 %** 에만 걸려야 합니다(조각 100~10). 이것은 M 의 원인 a[[M §4-2 a]] · J-7b[[J-7b]]("각 영역의 창이 자기 높이만 덮으면 됨")입니다.

**다른 자리에만 있던 근거를 실제로 쓴 곳**(§9-10 ③ 집계용): [[M §4-2 a]] · [[J-7b]] → D-5 · D-7 의 ψ 분석(원인 a 의 양날). [[J §1 6번]] → D-3 의 회귀. [[J §1 4번]] → D-5 의 모형 단서. [[M ^asd]](EUV 진공에서 공기 게이지 불가) → D-9 의 L1 실현 경로. [[J ^e1]](imec 2~3배) → D-10 의 두 번째 열. [[J §3-3]] · [[M §6 ②]] → D-8 수렴안.

### D-13 ← A-13 (수용 — T* 정의 구분)

제 T* 는 **앵커 여유 기준**, M 의 T* 는 **절대 예산 기준**입니다[[M §5-3]]. 환산은 다음과 같습니다. MC/M1 스택: **B-T* = M-T* + (−m_M1현)** — Mack 과 선형에서 −m_M1현 은 s16 4.6 · s10 0.6. 그래서 B 값이 약 5 nm 큽니다. 현 세대 M1 이 절대 마진 −4.6 에서 목표 경계였기 때문입니다. LP: **B-T* = M-T* − 17.5(0.3 % 유지) − δ(목표)**. 인용할 때는 "앵커 T*" / "절대 T*" 로 붙여 쓰겠습니다.

## 자리별 공격(B)에 대한 수비

### D-B1 ← A-B1 (수용)

D-4 의 표가 답입니다. 표지를 달았더라도 표지 단 수가 권고의 문장(예상 손실 · D1 손익분기 · A 대 B 박빙 · T* 가치 · N+2 LP 불가)에 **결과처럼** 들어갔습니다. 이 수들을 철회하거나 사상 없는 판으로 바꿨습니다. CLAUDE.md §0 의 "설명이 숫자를 맞히면 의심" 을 쓴 자리에서 표지로 막았다고 여겼는데, **표지가 하류로 흐르는 것은 막지 못했습니다.** 표지는 수가 나가는 경로마다 따라가야 한다는 것을 적어 둡니다.

### D-B2 ← A-B2 (수용 — MC 레버 뒤 판정을 "판정 불가 + 확정 조건" 으로)

MC 필요량 57 은 두 가설 위에 있습니다. 하나는 (가) MC 가 M1 처럼 사상된다는 것이고, 다른 하나는 (나) 토포가 결함 인지 DoF 밖에 있다는 것입니다(D-3 에서 φ ≤ 0.07). 여기에 (다) ψ = 1 이 셋째로 붙습니다(D-7). 가설마다 필요량이 이렇게 바뀝니다.

| 가설 | MC 필요량 | 권고안 A(62.0~83.4)로 |
|---|---|---|
| M1 사상 · φ = 0 · ψ = 1 (R1) | 57 | 닫힘(+5.0~+26.4) |
| 절대 Mack 마진 ≥ 0 | 57.6~61.6 | 대체로 닫힘 |
| **LP 처럼 사상**(현 세대 두 층 앵커 마진 차 22.1 을 더함) | ≥ 79 | 이득 상단 83.4 에서만 닫힘 → **X1/C3 영역** |
| φ = 0.07(D-3 상한) | 51.4 | 닫힘 |
| ψ = 0.5 | 52(단 이득이 34.5~50.9 로 줄어듦) | **못 닫음** |

→ **MC 레버 뒤 판정: 판정 불가**(D-7 표의 확정 조건 그대로). 레버 없는 MC 의 **"부족" 은 불변**입니다(φ · ψ · 사상 어느 가설로도 음수). 권고안 A 는 **불변**이되, 첫 줄을 "MC: C2+P1+P2 — 적용 뒤 판정 불가, G2 에서 X1 예비 발동 여부를 Q5 ② 로 결정" 으로 고칩니다.

### D-B3 ← A-B3 (수용 — "0" 이 아니라 "미상")

[[B §3-5 G0]]의 "X1 공정 자격 유지" 비용을 **미상**으로 표기합니다. 구성은 다음과 같습니다.
(ⅰ) N+1 피치의 ArF 이중 패터닝 마스크 한 쌍 — 문제의 ArF 마스크 단가 약 1 억(C2 역마스크)을 빌리면 **약 2 억 일회성**[가정]
(ⅱ) 주기적 자격 로트를 위한 ArF 액침 장비 시간 — **미상**
(ⅲ) N+1 설계 변경을 따라가는 OPC · 공정 인력 — **미상(인·주)**
(ⅳ) 오버레이 여유 ≤ 2 nm 를 지키기 위한 제어 개발 — **미상**
→ "하한 약 2 억 일회성 + 미상" 으로 적고, G2 에서 X1 을 버리는 시점이 이 비용을 끊습니다. 비용이 0 이 아니라는 점이 **G2 를 서둘러야 할 이유**이기도 합니다(열어 둔 선택지는 유지비를 냅니다).

### D-B4 ← A-B4 (수용 — 첫 줄은 등록 층을 만족하는 안, 경제안은 사용자 안건)

**LP 권고 첫 줄을 바꿉니다.**
- **첫 줄(목표 달성안)**: P1+P2, 그리고 **D1 은 D-8 규칙의 ① · ② 가 서면 채택**. 동결 시점에 자료가 없으면 ④ 에 따라 R₀ 로 판단합니다(0.3 % 앵커조차 못 지키면 채택).
- **사용자 결정 안건(경제안)**: D1 을 빼는 안. 연 432 억(매출 ∝ 다이 가정)을 아끼는 대신 LP 목표 미확보 위험(0.2 % 판정 불가 · 0.3 % 앵커 대비 여유 −5.9 ~ +6.5)을 집니다. 회수분은 s_LP 실측 뒤에만 억원으로 적습니다.
- R1 의 "기본 불채택" 은 B-7 손익분기에 기댄 것이므로 D-4 #7 과 함께 철회합니다. MAGI 규약 §2(합의는 등록 아래)와 맞춥니다.

### D-B5 ← A-B5 (수용 — 기록)

G0~G3 틀을 이 R3 에서 D1 규칙(D-8)과 MC 확정 조건(D-7)의 **시점 축**으로 썼습니다. G1(D1) → G2(MC 경로 · X1 예비) → G3(P1 확인) 순서는 R1 그대로입니다. 여기에 **0순위 문서 확인이 G0 첫날**에 붙습니다.

## 자기 공격 한 줄 (R3 에서 새로 드러난 급소)

D-7 의 ψ 분석은 **MC 와 M1 에 같은 ψ** 를 걸었습니다[가정]. MC 는 콘택이고 M1 은 라인이라 "각 영역의 창이 자기 높이만 덮으면 된다" 가 두 층에서 같은 정도로 성립할 이유가 없습니다. MC 의 ψ 가 M1 보다 크면(예: MC 밀집/고립 콘택이 두 높이에 섞여 있음) 권고안 A 는 R1 판단 쪽(닫힘)에 가깝고, 작으면 X1 쪽으로 기웁니다. **드러날 관측**: Q5 ② 의 영역별 DA 를 MC 와 M1 에 **따로** 재야 합니다. 한 층 값을 다른 층에 빌리지 않습니다.

## 판정 변경 여부

**Q1 불변**(LP 부족 · MC 부족 · M1 부족, 확신도 등급 불변. 근거 문장만 "독립 둘 + 재확인" 으로).
**Q2 변경 셋.**
① LP 첫 줄이 "P1+P2(D1 기본 불채택)" 에서 **"P1+P2 + D1(관측 규칙 D-8 로 채택)"** 으로 바뀌고, D1 을 뺀 안은 사용자 안건이 됩니다.
② MC 레버 뒤 판정이 "확보(중앙)" 에서 **"판정 불가 + 확정 조건"** 으로 바뀝니다. 레버 조합 A 와 X1 예비는 불변이고, ψ 때문에 X1 예비의 비중이 커집니다.
③ M1 레버 뒤 판정이 "확보" 에서 **"확보(조건부 ψ ≥ 0.5) + 대비책 P1(M1)"** 으로 바뀝니다.
금액 비교(A 대 B 박빙 · D1 손익분기 · 예상 손실)는 철회합니다.
**Q5 순위 불변(① LP·위치 → ② MC/M1 단락 흐름 → ③ P1 결함 인지 이득).** 다만 세 곳이 늘어납니다. 앞에 **0순위 비용 0 문서 확인**(D-3 ③)이 붙습니다. ① 에 **현 세대 LP 초점 오프셋 기울기 s_LP 실측 · M1 불량의 경계 띠 몫**이 더해집니다. ② 에 **영역별(셀/페리) DA 로 ψ 를 MC · M1 각각 실측**하는 일과 **같은 웨이퍼의 파일럿 수율**이 더해집니다.
