## 1. 내 후보 상위 3

### 1-0. 먼저 — **셋 다 §0 의 자로 잰 수가 없습니다. 저도, 남들도.**

§0 이 정한 자는 **RH90 습윤 TSA 작업용량 + 유지율 + 0.15 bar 절대량 병기**입니다.
**제 후보 셋 중 그 자로 잰 수를 가진 것은 하나도 없습니다.** 문헌 습윤 자료는 대부분
**RH 40 %**(Kwon 의 GCMC)이거나 **RH·조건 미상**(원논문 미확보)입니다. RH40 과 RH90 은
**같은 이름의 다른 양**입니다(§3). 그러므로 **이 라운드에서 후보 순위를 자로 매기는 것은
불가능하고, 저는 매기지 않습니다.** 제가 세우는 것은 *"우리 자로 재 볼 값이 있는 셋"* 입니다.
**남의 §1 에 §0 의 자로 매긴 순위가 있으면 그것이 제 R2 첫 공격 대상입니다.**

### 1-1. 후보 A — **MUF-16(Ni) / MUF-16(Co) / MUF-16(Mn)**  ⭐ 제 1순위

    골격 코드    CSD/CoRE [미확인] — 조성식 [M(Haip)₂], 공간군 **I2/a**, 세 금속 동형(isostructural)
    위상         [미확인] (논문은 위상 기호를 안 씀) · **1D 채널**
    금속         Co(II) / Ni(II) / Mn(II) — **OMS 없음**(금속이 카복실레이트 4 + 아미노 2 로 팔면체 포화)
    링커         **5-아미노아이소프탈산 H₂aip** — 저가·상용. SMILES `Nc1cc(cc(c1)C(=O)O)C(=O)O`
    PLD / LCD    **[미확인]** — 논문에 값 없음. **우리가 Zeo++ 로 재면 30분**
    CO₂ 0.15 bar **[미확인]** — 등온선은 있으나 제가 수를 못 뽑았습니다(2차본)
    습윤 근거    **없음.** 논문이 말하는 것은 *"산소와 수증기에 견딘다"* — **안정성이지 흡착량이 아닙니다.**
                 **이 점을 제가 먼저 적습니다.** 남이 공격하기 전에.
    합성 상태    **그램 규모 고수율**, 메탄올 용매, 링커 상용. 셋 중 합성 위험이 가장 낮음
    출처         `10.1038/s41467-020-20489-2` **[전문]** (Qazvini 2021 Nat. Commun.)

**왜 1순위인가 — 우리 자산을 유일하게 재사용합니다.** 이 프로젝트가 2주 안에 실제로 잘하는 것은
**"골격 하나를 잡고 링커 치환기를 바꿔 가며 재는 것"** 입니다(MTV 기계). CALF-20 의
트라이아졸레이트·옥살레이트에는 치환 여지가 거의 없고, 음이온 기둥 계열은 기둥이 성능을 정합니다.
**H₂aip 는 아미노기 하나와 고리 자리가 비어 있어 우리 빌더의 치환 축이 그대로 살아납니다.**
게다가 **아미노기가 이미 달린 채로 물리흡착**이라(아민 그래프팅이 아님) 우리 강체 GCMC 로 잽니다.

**우리 파이프라인으로 재는 법과 2주 비용(전부 실측 단가):**

    ① CIF 확보(CSD/CoRE) → 원소수·고아 감사                      0.5 h
    ② PACMAN DDEC6 전하 (모델 md5 대조)                          ~수 분
    ③ Zeo++ PLD/LCD — **RASPA 와 동시 금지**(9.5 GB/건, §5)      0.5 h · 창 필요
    ④ GCMC RH0 + RH90, 3 금속(Co/Ni/Mn) = 6 작업                 RH0 **1.8 h** · RH90 **17.5 h** (등록 단가)
                                                                  워커 5 로 **약 20 h**
    ⑤ 배치 단위가 없으므로 **실현 반복 불가**(단결정 구조 1개)     -> n=1. **§0 의 자로 순위 못 냄**(1-0)
    합계  **약 하루**. 2주 안에 여유. 남는 시간은 치환체(-NO₂·-SO₃H 등) 확장에 씀

**반증 조건(무엇이 나오면 버리는가) — 미리 적습니다:**

    ㉠ Zeo++ PLD < 3.3 Å (CO₂ 운동직경)  -> 강체 GCMC 가 0 을 냄. **버림**(또는 유연성 필요 = 모델 불가로 강등)
    ㉡ RH90 유지율이 우리 `saIm050`(83.5 %, n=5 평균) **미만**   -> ZIF-69 노선을 대체할 이유 없음. **버림**
    ㉢ 0.15 bar 건조 CO₂ 가 우리 `base`(0.5839 mol/kg) 미만       -> 출발점이 모체보다 낮음. **버림**
    ㉣ 아미노기가 CO₂ 와 **화학결합**(카바메이트) 징후            -> 모델 불가로 강등, 계산 배정 반납

### 1-2. 후보 B — **IISERP-MOF2**

    골격 코드    [미확인] (Kwon ref 31)      위상/금속/링커  **[미확인]**
    PLD / LCD    2.6~3.7 Å **구간**(넷을 묶어 제시) · 개별값 [미확인]
    CO₂ 0.15 bar [미확인]
    습윤 근거    **실험 보고됨**(Kwon 본문 인용) — **RH·평형/breakthrough·수 전부 [미확인]**
    합성 상태    [미확인]
    출처         `10.1021/acscentsci.5c00777` **[전문]** — 다만 이 골격에 대한 서술은 **인용(2차)**

**왜 후보인가 — 기제가 우리 것과 같습니다.** Kwon 연구 전체에서 **공정 에너지 최저**이고, 그 이유가
*"N₂ 흡착량이 유난히 낮다"* 입니다. **우리 `sa50nb50` 의 건조 선택도 이득도 N₂ 배제였습니다**
(`MAGI-002 §0-1 ㄷ`). 같은 기제라면 **우리 해석의 외부 검증**이고, 다르면 **우리 해석을 시험하는 대조군**입니다.
어느 쪽이든 값이 있습니다.

**비용**: 위와 같은 경로. 다만 **①에서 막힐 수 있습니다** — CSD 코드를 제가 모릅니다.
코드 확보가 선결(웹 몫). 확보 뒤에는 **약 하루**.

**반증 조건:**

    ㉠ 습윤 자료가 **breakthrough** 로 밝혀짐 -> 우리 평형 자와 다른 양. **후보에서 내림**(참고로만)
    ㉡ OMS 가 있음 / 유연 골격         -> 모델 불가. **버림**
    ㉢ 우리 GCMC 의 N₂ 가 낮지 않음    -> "낮은 N₂" 가 이 골격의 성질이 아니었던 것. **버림**
    ㉣ CSD 코드를 R2 까지 못 찾음      -> **2주 안에 못 재므로 후보 자격 없음**

### 1-3. 후보 C — **CALF-20**

    골격/링커    Zn · **트라이아졸레이트 + 옥살레이트** · 1D 채널 (정확한 조성식·SMILES [미확인])
    PLD          **2.75 Å** — Kwon 이 스크리닝 하한을 이 값 때문에 2.0 Å 로 낮췄다고 **본문에 명시** [전문]
    LCD / CO₂ 0.15 bar   [미확인]
    습윤 근거    **실험 보고됨**(Kwon 인용) · RH·수 [미확인]
    합성 상태    ⭐ **상용화 진행** — 시멘트 배가스 증기 스윙 공정으로 스케일업 중. 셋 중 유일
    출처         `10.1021/acscentsci.5c00777` **[전문]**(PLD·상용화) · 원논문 ref 19 **[미확인]**

**왜 3순위인가 — 제가 먼저 약점을 적습니다.** **PLD 2.75 Å 는 CO₂ 운동직경 3.3 Å 보다 작습니다.**
그런데도 실제로 CO₂ 를 잡는다는 것은 **골격이 강체가 아니라는 뜻**일 가능성이 큽니다(게이트 개폐·유연성).
**그러면 우리 강체 GCMC 는 0 에 가까운 수를 냅니다** — 계산이 틀린 것이 아니라 **모델이 안 맞는 것**입니다.
§3 이 "유연 게이팅은 파이프라인 밖" 이라 했으므로 **저는 이 후보를 "모델 불가 가능성 높음" 으로 표시하고 냅니다.**
그럼에도 3순위에 두는 이유는 **음성 대조로서의 값** 입니다 — 상용화된 물질에서 우리 파이프라인이 0 을 내면,
그것은 **우리 파이프라인의 한계를 보여 주는 수**이지 물질의 평가가 아닙니다. 그 사실을 아는 것이 포스터에 중요합니다.

**반증 조건:** ㉠ 우리 GCMC 가 CO₂ ≈ 0 -> 예상대로. **후보에서 내리고 "파이프라인 한계 사례" 로만 인용**
㉡ 유연성 문헌 근거가 확인됨 -> 즉시 모델 불가. ㉢ 강체로도 잘 나옴 -> **1순위로 올림**(그때 근거를 다시 적음)

## 1-4. 제 입장의 약한 곳 (남이 치기 전에)

    · **후보 B·C 의 습윤 근거가 전부 2차 인용**입니다. 원논문(ref 19·31·83·84)이 제 라이브러리에 없습니다.
      R2 에서 남이 원문을 가져오면 제 수는 그쪽 것으로 갈아타야 합니다.
    · **후보 A 는 습윤 자료가 아예 없습니다.** "물에 견딘다" 를 "습윤에서 잘한다" 로 읽으면 안 되고,
      제가 그렇게 읽지 않았다는 것을 1-1 에 적어 뒀습니다.
    · **PLD 를 두 자로 견주는 문제가 여기서도 있습니다.** Kwon 의 PLD 와 우리 Zeo++ before PLD 가
      같은 양인지 미확인입니다. 우리 창(4.3~4.8 Å)과 Kwon 습윤 상위군(2.6~3.7 Å)을 나란히 놓으면 안 됩니다.
    · **셋 다 단결정 구조 하나뿐**이라 실현 반복이 없습니다. 우리가 09-08 에 배운 것
      (**배치 단위 8.7 p > 후보 간 최대 차이 7.9 p**)이 여기에도 걸립니다 — 신규 골격 셋을 n=1 로 견주면
      **ZIF-69 후보에서 못 가른 것과 같은 이유로 못 가릅니다.** 이것은 제 후보만의 약점이 아니라
      **이 판 전체의 약점**이고, R2 에서 남의 후보에도 같은 공격을 하겠습니다.
