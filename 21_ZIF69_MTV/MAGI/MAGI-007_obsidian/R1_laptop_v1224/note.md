# MAGI-007 R1 — Melchior(이론 · 랩탑) 그래프용 판

원문: `~/.mof_magi/MAGI-007_laptop.md`(같은 봉인 해시 줄). 주장 단위만 옮깁니다.

**M-1** 열린 자리 치환 넷은 통로 수를 바꾸지 않고(4 → 4) 바닥 S_OFF 를 39 → 53~63 으로 올린다 `[전문]`.

**M-2** 치환기는 통로 벽(카복실–Zn 줄 위)에, CO₂ 는 c 축 1차원 통로에 있다 `[전문]`.

**M-3** 정전기 몫을 올린 치환기는 −CN 하나다(25.9 % 대 모체 22.6 %) `[전문]`.

**M-4** −CN 만 작동점 선택도가 헨리보다 오른다(비 1.21) — 값 `[전문]` · 기제 `[가설]`.

**M-5** RH90 CO₂–H₂O 이원에서 다섯 설계의 CO₂ 습윤/건조 비는 0.96~1.00 이다 `[전문]`.

**M-6** 그러므로 E 에서 S_humid ≈ S_mix(건조), 유지비 0.93~1.03 — 판별 관측은 −CN 의 유지비 `[가설]`.

**M-7** UFF4MOF 상한 300 이완 뒤 −CN · −Cl 은 CO₂ 통로 0 · AV 0.0, −Br 은 열림 `[전문]`.

**M-8** 닫힘 기제는 Zn–O 신장 → 셀 a 확장 → 링커 16° 회전 → 창 조임이며 모체도 같은 회전을 보인다 `[전문]`.

**M-9** 모체 S_mix 323/298 비는 0.669 다 `[산술]`.

**M-10** 헨리 근사로 열린 자리 −CN · −Br 의 323/298 비는 0.60~0.66 이다 `[산술]`·`[가설]`.

**M-11** A 에서 −CN 은 막음 뒤 두 적재가 ≈ 0 이 되어 S_mix 가 정의되지 않을 가능성이 크고, A 판정 표에는 그 칸이 없다(등록 빈칸) `[가설]`.

**M-12** "−C₂H₅ 323 K 단독 선두(E-27b)" 의 수는 전 치환 구조 `e24c_c2h5_100` 의 값이며 §25 로 보류다 — 열린 자리 −C₂H₅ 의 323 K 값은 없다 `[전문]`.

**M-C1** 후보: 열린 자리 −C≡CH — CN 이득의 모양 대 극성을 가름, CN 을 넘을 확률 0.15 `[가설]`.

**M-C2** 후보: 열린 자리 −CN/−Br 이종 한 쌍 — 가산성 시험, 넘을 확률 0.05 `[가설]`.

**M-C3** 후보: 열린 자리 −NO₂ — 정전기 상한 시험, 넘을 확률 0.15 `[가설]`.

**M-V** 판정: 다섯을 넘는 개질은 2주 안에 확인될 가능성이 낮고, 조건 전부에서 서는 후보는 −Br 이 될 것 — 확신 중 `[가설]`.
