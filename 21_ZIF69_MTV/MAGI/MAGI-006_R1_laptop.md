## 2. Q1 판별

### 2-1. 판별 방법 — 절대 마진에서 차분으로 옮긴 이유

M-1. 절대 마진은 **규칙에 따라 부호가 바뀝니다**(LP: 선형 −15.5 · Mack +3.5 · RSS +24.6). 그래서 "마진이 양수인가" 만으로는 LP·M1 을 판정할 수 없습니다. [산술 — 표 1-3]
　이 단계가 틀렸다면: 한 규칙이 현 세대 실측 손실을 맞혀야 합니다. §4 에서 보이듯 셋 다 못 맞힙니다.

M-2. 같은 레이어 · 같은 장비군에서 **N+1 마진 − N 마진**을 취하면 공통 항(스캐너 · 웨이퍼 · LS · 렌즈 · 레지스트)이 지워집니다. 남는 것은 ΔDoF 와 ΔT 뿐이라 **선형과 Mack 에서는 값이 정확히 같고, RSS 에서도 거의 같습니다.** [산술]
　LP: 선형 −14.0 · Mack −14.0 · RSS −13.3 (평균토포) / 최대토포 −16.0 · −16.0 · −15.2
　M1: 선형 −18.0 · Mack −18.0 · RSS −18.2 (평균토포)
　이 단계가 틀렸다면: N+1 에서 무작위항이 바뀌었을 것입니다(예: 새 LP 스택의 LS 오차). 그러면 N+1 파일럿 손실이 차분이 예측하는 순서와 어긋나야 합니다. 실제로는 어긋나지 않습니다(M-6).

M-3. 차분은 "**현 세대의 손실이 그 마진에서 나온 것**" 을 기준점으로 삼습니다. 현 세대 LP 는 이미 **0.3 % > 목표 0.2 %** 입니다. 그러므로 LP 는 **차분이 0 이어도 부족**합니다. [양산 12개월]

### 2-2. 레이어별 판정

**LP — 부족 (확신도 중)**
- 계산: ΔDA = 58 − 70 = −12. 95 % 구간을 제곱합으로 합하면 약 [−26, +2] 입니다(N+1 45~70 은 2장 · N 64~76 은 6장). ΔT = +2(평균) / +4(최대). → **Δ마진 −14(평균) · −16(최대), 구간 약 [−28, 0]**. [FEM 2장 vs 6장] [산술]
- 기준점 N 이 이미 목표를 넘기므로, 구간의 상단(0)에서도 판정은 부족입니다.
- 교차 확인: 파일럿 손실 추정 0.4~0.9 % > 0.2 %. [추정 · 표본 작음]
- 절대 표(Mack, S 16): +3.5 / −8.5, 구간 [−9, +16]. 이 표만 보면 판정 불가입니다. §4 의 뒤집힘 때문에 이 표를 판정에 쓰지 않습니다.
- 기댄 자료: 웨이퍼 2장의 DA, 12개월 양산 손실.

**MC — 부족 (부호 확신도 상 · 크기 확신도 중)**
- 절대 마진: 모든 규칙 × 스캐너 값 × 토포에서 **−23 ~ −112 nm**. 가장 너그러운 칸(전 RSS · S 10 · 평균토포 · DA 구간 상단 60)도 −22 nm 입니다. **CD 기준 공통 DoF 를 써도 −7 ~ −55 nm** 입니다. [FEM 1장] [AFM 40×4]

- 기댄 자료: DA 는 웨이퍼 1장뿐입니다(구간 35~60). 그러나 구간 상단을 써도 결론은 같습니다.

**M1 — 부족 (확신도 중)**

### 2-3. 판정 불가로 가지 않은 이유
LP 의 절대 표만 보면 판정 불가가 맞습니다. 그러나 **서로 독립인 세 갈래 — 규칙에 무관한 차분 · 현 세대 기준점이 이미 목표 위 · 파일럿 손실 추정 — 가 같은 쪽을 가리킵니다.** 규율 4 는 판정 불가를 낼 때 "무엇이 오면 판정이 되는지" 를 요구합니다. 여기서는 그것이 이미 와 있다고 봅니다. 단 **세 갈래 모두 LP 파일럿 웨이퍼 2장에 기대므로** 확신도는 중입니다.

### 2-4. 마진 한 수가 손실 한 수로 이어지는가 — 3σ 와 수율의 물리

M-4. 무작위항만 있고 그것이 정규분포이면, 창 밖으로 나갈 확률(양쪽)은 반창을 σ 단위로 쟀을 때 2Φ(−k) 입니다. **목표 0.2 % 는 k = 3.09(양쪽) 또는 2.88(한쪽)** 입니다. 흔히 쓰는 "±3σ" 는 0.27 % 로, 목표보다 조금 느슨합니다. [산술 — scipy.stats.norm]
M-5. 민감도: LP 의 무작위 σ ≈ 24.5/6 = 4.1 nm(Mack, S 16). 반창 1 nm 는 k 를 0.25 옮깁니다. k 가 3 근처에서 0.5 줄면(반창 2 nm) 꼬리 확률은 **약 4.6배**가 됩니다(Φ(−3) = 0.13 % → Φ(−2.5) = 0.62 %). → **마진 수 nm 가 손실 수 배**입니다. 절대 예산이 몇 nm 틀리면 손실 예측이 자릿수로 틀리는 이유입니다. [산술]
M-6. 계통항(토포)은 확률이 아니라 **면적**으로 손실을 만듭니다. 다이 손실 ≈ Σ_자리 (그 높이를 가진 면적 비율) × (그 자리의 무작위 꼬리 확률)입니다. 예(LP, Mack, S 16): 평균 토포 자리는 마진 +3.5 → k ≈ 3.43 → 꼬리 0.03 %. 최대 토포 자리는 마진 −8.5 → k ≈ 1.96 → 꼬리 2.5 %. 최대 토포 면적이 전체의 수 % 만 되어도 다이 손실은 0.1~0.3 % 대가 됩니다. [산술 · 가설: 결함은 창 경계에서 계단처럼 켜진다]
　→ **손실은 "최대 토포가 얼마인가" 보다 "그 높이가 다이의 어디에, 얼마만큼의 면적에 있나" 에 달려 있습니다.** Q3 와 Q5-② 의 뿌리입니다.

## 4. Q3 현 세대 정합

### 4-1. 계산

표 1-3 의 N 행(Mack, S 16): **LP +17.5 / +7.5 · M1 −4.6 / −34.6**. 실측 손실은 **LP 0.3 % · M1 0.2 %**.

M-8. **어긋남은 규칙과 무관합니다.** 세 규칙 모두 M1 의 계산 마진이 LP 보다 작습니다(선형 −20.5 < −1.5 · Mack −4.6 < +17.5 · RSS +21.5 < +37.9). 그런데 손실은 LP 가 더 큽니다. 세 스캐너 해석(10 · 16 · 20)에서도 같습니다. **"마진이 클수록 손실이 작다" 는 단조 대응이 두 레이어 사이에서 성립하지 않습니다.** [산술 · 양산 12개월]
　이 단계가 틀렸다면: 두 레이어의 결함 인지 DoF(6장씩, 구간 비겹침: 64~76 · 88~102)가 크게 틀렸어야 합니다. 구간을 다 써도 부호는 유지됩니다(LP Mack [+12, +24] · M1 [−12, +2]).

→ 한 규칙을 골라 한 레이어를 맞추면 다른 레이어가 틀립니다. 예: 선형으로 LP −1.5 ≈ 0.3 % 를 "맞히면" M1 −20.5 에서 0.2 % 가 설명되지 않습니다. **이 설명들은 각자 숫자 하나를 맞힐 수 있습니다 — 규율 1 이 경고하는 자리입니다.**

### 4-3. Q1·Q2 에의 영향
- Q1 은 **차분으로 판정해 이 어긋남을 우회**했습니다. 차분이 유효하려면 "N 에서 N+1 로 가도 레이어 안에서 마진→손실 대응이 같다" 는 가정이 필요합니다. 원인 e 나 f 가 맞으면 이 가정이 흔들립니다(§8).
- Q2 의 LP 레버 선택은 원인 b · c · d 가운데 어느 것이냐에 **직접** 걸려 있습니다 → D1 을 조건부로 둔 이유이고, Q5-② 가 1순위급인 이유입니다.
- MC 는 어떤 원인이든 결론이 같습니다(창보다 큰 토포).

## 5. Q4 레이어 증가 · High-NA

### 5-1. NA 스케일링의 물리

M-9. Rayleigh 초점 심도는 해상 한계에서 DOF = k₂ λ / NA² 이고, 같은 피치의 3-빔 결상에서는 DOF < p² / λ 입니다. 둘 다 Mack 강의록 [전문 — 2쪽 전부 읽음] 의 식입니다. Mack 은 이것이 "오늘의 리소그래피에는 맞지 않는다" 는 단서도 같이 적었습니다. → **피치를 고정하면 DoF 는 NA 와 거의 무관하고, NA² 배율은 해상 한계로 피치를 줄일 때의 값**입니다. 0.33 → 0.55 의 순수 NA² 비는 (0.33/0.55)² = **0.36** 입니다. [산술]
M-10. 문제 §6 의 0.55NA LP급 CD 공통 DoF 40~55 [모의] 를 N+1 LP 88 로 나누면 **0.45~0.63** 입니다 → 두 극단 사이. 공개 요지들도 "DoF 가 1/NA² 로 줄어 약 1/3" 이라고 적습니다 [요지 — 블로그 · SPIE 초록 검색 요약]. **토포(nm)는 NA 와 무관합니다**(문제 §6 가정). 따라서 창 대비 토포의 비중은 **1/0.45~1/0.63 = 1.6~2.2배**로 커집니다. [산술]

### 5-2. Photo 레버의 폐쇄 한계(nm)

| | 결함 인지 DoF | Photo 이득 | 폐쇄 한계(nm) |
|---|---|---|---|
| 0.33NA (N+1) | LP 58 · MC 48 · M1 72 [FEM] | +12~20 % (P1) [모의] | **LP 7~12 · MC 6~10 · M1 9~14** |
| 0.55NA (N+2) | 40~55 × DA/CD 비. 비는 미측정이므로 N+1 실측 0.64~0.74 를 **빌리면** 26~41 [가정] | +18 % (SMO+SRAF) / +32 % (비대칭 SRAF) [모의] | **5~7 / 8~13** |

→ 비율 이득은 커지지만(18~32 %) **절대 nm 는 제자리이거나 줄어듭니다**. 창 자체가 줄기 때문입니다. [산술 · 가정]

### 5-3. 평탄화 문턱 — 남길 수 있는 토포 T*

T* = DA(최선 Photo 적용) − (무작위 RSS + 렌즈 5 + 레지스트 3). Mack, S 16 기준입니다.

| | LP | MC | M1 |
|---|---|---|---|
| 0.33NA | 70 − 32.5 = **37** | 57.6 − 29.6 = **28** | 86.4 − 29.6 = **57** |
| 0.55NA | (26~41) × 1.32 − 32.5 = **2~22** | (26~41) × 1.32 − 29.6 = **5~24** | (M1 은 N+2 전환 대상 아님) |

- 0.33NA 에서 LP 토포(22 · 최대 34)는 T* 37 안에 있어 평탄화 레버가 필요 없습니다(LP 의 부족분은 DoF 쪽). **0.55NA 에서는 LP 토포 22 가 T* 를 넘습니다** → D1 이나 LP 아래층 평탄화가 필요해집니다.
- MC 는 0.33NA 에서 C2(15~25)로 경계, 0.55NA 에서는 **C3 급(≤ 5)** 이 필요합니다.
- ⚠ **0.55NA 의 초점 오차 항목은 실측이 없습니다**(문제 §6). High-NA 장비의 무작위항이 작다면 T* 는 올라갑니다. 이 절의 확신도는 **하**입니다.

### 5-4. 평탄화 1회의 수혜 레이어 수

M-11. 커패시터 뒤 ILD 단차는 MC 로 가고 그 위의 M1 까지 **물려받습니다**(문제 §1 공정 순서 · 두 레이어 토포가 80 · 65 로 같은 원천). **ILD 평탄화 1회는 EUV 레이어 두 개에 동시에 듣습니다.** [산술 · 문제 §1]
- 레이어별 비용으로 보면 C2 252 억/년은 EUV 레이어당 126 억입니다. X1 을 택하면(MC ArF) 같은 C2 가 EUV M1 하나만 돕습니다.
- N+2 에서 MC 가 High-NA 로 가면 T* 5~24 이므로 **평탄화는 선택이 아니라 필수**가 되고, 그때도 M1 을 함께 돕습니다. → **지금 X1 을 택하는 것은 평탄화 결정을 미루는 것이지 피하는 것이 아닙니다**(경로 의존). [가설]
- 레이어 수 5 → 7: 다이 손실은 레이어별 초점 손실의 합에 가깝습니다(작은 확률의 합). 레이어마다 0.2 % 면 **7 × 0.2 = 1.4 %** 입니다. 모든 레이어에 듣는 플랫폼 레버(P2, 레이어당 2~5 nm)의 가치는 레이어 수에 비례해 커집니다. [산술]

## 6. Q5 다음 측정 (우선순위)

**0순위(비용 0, 먼저)**: 제조사 스캐너 "10(3σ)" 의 폭 규약과 재현성 60/40 % 의 기준(분산인지 진폭인지)을 **문서로 확인**합니다. 바꾸는 것: 절대 마진 ±3~6 nm(S 10 ↔ 20) · P2 이득(분산 기준 2~3 대 진폭 기준 4~5 nm). 판정은 차분이라 바뀌지 않습니다.

1. **MC 제품 레이아웃 결함 인지 FEM — 웨이퍼 ≥ 5장, 기준 · C2 · C2+P1 가름.**
　바꿀 결론: MC 의 C2+P1 대 X1(또는 C3). C2 의 M1 단차 값([추정] → 실측).
　사전 등록 문턱: C2+P1 가름의 **DA 95 % 하한 ≥ Mack W(실측 평균 토포)** 이면 C2+P1 확정. 하한 < W 이고 점추정 ≥ W 이면 웨이퍼를 더 잽니다. 점추정 < W 이면 X1(또는 C3 평가 착수).
2. **현 세대 LP·M1 초점 결함의 공간 분해** — 웨이퍼 반경 · 다이 안 위치(블록 가장자리 · 셀–페리 경계 띠 · 페리 내부) · 아래층 금속 밀도. 12개월 결함 자료의 재분류이므로 새 노광이 필요 없습니다.
　바꿀 결론: Q3 원인 a~d 의 판별 → **LP 레버(D1 대 LS 보정 대 P2)**, M1 에 C1 으로 충분한지. **D1 의 설계 동결 시한 전에** 필요합니다.
　사전 등록 문턱(예): LP 초점 결함의 ≥ 50 % 가 블록 가장자리 10 µm 안이면 → 원인 c · D1 권고. 금속 밀도와의 순위 상관의 95 % 하한 > 0.3 이면 → 원인 b · LS 보정 · D1 보류. 바깥 고리(r > 0.9R)에 ≥ 50 % 이면 → 원인 d · 가장자리 오프셋.
3. **LP 에 P1 마스크(SMO+SRAF)를 올린 결함 인지 FEM — ≥ 3장.**
　바꿀 결론: P1 의 DA 이득(미측정 → 실측)에 따라 LP 가 P1+P2 로 되는가, D1 이 필요한가.
　사전 등록 문턱: DA 이득 ≥ 12 nm 이면 P1+P2 로 D1 불필요. < 7 nm 이면 D1(원인 c 가 ② 에서 확인된 경우).

## 8. 자기 반박 — 급소 하나

**급소: Q1 의 LP·M1 판정은 차분에 기대고, 차분은 "레이어 안에서 마진→손실 대응이 세대를 건너 같다" 는 가정에 기댑니다.** 그런데 §4 에서 **레이어 사이**에서는 그 대응이 이미 깨졌음을 보였습니다. 레이어 사이에서 깨지는 무언가(원인 a~f)가 세대 사이에서도 깨질 수 있습니다. 특히:
- N+1 LP 는 스택이 바뀌어 LS 오차 성질이 달라질 수 있습니다(원인 b).
- 현 세대 손실의 일부가 초점이 아닐 수 있습니다(원인 e).
- 파일럿 DA 는 2~3장이라 구간이 넓습니다(LP Δ 구간 상단 0).

**드러날 관측**: Q5-② 에서 현 세대 LP 손실이 초점 오프셋 변화에 반응하지 않거나(원인 e), N+1 파일럿의 결함 위치 분포가 현 세대와 다른 유형이면(예: N 은 블록 가장자리인데 N+1 은 금속 밀도 상관), 차분의 전제가 무너지고 LP 는 **판정 불가**로 물러나야 합니다. M1 은 파일럿 손실 추정(0.6~1.2 %)이 독립적으로 부족을 가리키므로 덜 흔들립니다.

부수 반박(작음): 렌즈 · 레지스트 · 레티클 값을 반폭으로 읽으면 선형 예산이 +9.5 nm, Mack 예산이 +8.0~8.3 nm 커집니다. 차분에서는 지워지므로 판정은 불변입니다. 레버 적용 뒤의 절대 마진(§3)은 그만큼 나빠집니다.
