## 파일 이름

    MAGI-NNN_<짧은-제목>.md        NNN 은 3자리 일련번호, 도입 순

## 절차 (한 결정)

    1. 종합(Fable)이 **질문을 한 문장**으로 적고 **질문 종류**(규약 4절 표)와 **가중치**를 먼저 등록
    2. 세 기기가 **각자 자기 정보로** 독립 평가 — verdict / confidence(+근거) / basis / dissent
       · 랩탑·laptop2 는 자기 세션(Opus)에서, 데스크탑 Caspar 는 Opus 서브에이전트에서
       · **다른 기기의 평가를 보기 전에** 씁니다. 순서가 뒤바뀌면 그 사실을 적습니다
    3. 종합(Fable)이 취합 — **합의 문장 · 소수 의견 전문 · 가중치를 어떻게 썼는지 한 줄 ·
       등록 층(사전 등록 문턱)에 저촉되는지**
    4. 결정 → 배정/행동. **등록 층에 걸리면 MAGI 로 못 넘습니다** — 새 시험 등록으로

## 지켜야 할 것 (규약에서)

- **dissent 필수.** 없으면 "없음" 명시. 빈칸 금지
- **가중치는 곱해 합산하지 않습니다.** "누구 말을 먼저 듣는가" 입니다
- **Caspar 반대**(수가 틀렸다·병기 빠짐)는 가중치와 무관하게 막고 **원자료로만** 풀립니다
- **Balthasar 반대**(기간 안에 안 됨)는 판정을 안 막고 **계획을 바꿉니다**
- 셋이 만장일치여도 **사전 등록 문턱은 못 옮깁니다**
