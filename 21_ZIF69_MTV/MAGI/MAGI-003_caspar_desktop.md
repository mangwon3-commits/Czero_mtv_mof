**① ZIF-300 / ZIF-301 / ZIF-302 — CHA 이중 링커 MTV ZIF** [10.1002/anie.201403980 (Yaghi 2014), 10.1002/advs.201901758 [전문], 리뷰 10.1039/d3sc06076d]
- 조성(Crossref 원문 확정): Zn(2-mIm)ₓ(5(6)-X-bIm)ᵧ, X = Br(ZIF-300, 0.86:1.14) / Cl(ZIF-301, 0.94:1.06) / CH₃(ZIF-302, 0.67:1.33). CCDC 995218/995219/995220(995219 = ZIF-301 본문 확인, 나머지 Crossref 유래 미검증). 위상 CHA, Zn-N 사면체, OMS·화학흡착·유연성 보고 없음.
- 수: CO₂ 1 bar/298 K 1.32(300)·1.47(301) mmol/g, IAST 22·19, Qst 28~30 kJ/mol; **0.15 bar 미표 [미확인]**; 물 등온 Type III, P/P₀ 0.8 에서 0.33/0.32/0.25 mmol/g(끓는 물 7일 안정, [전문]).

- 비용: CIF 3 → xtb 이완(데스크탑) → PACMAN → Zeo++(RASPA 0 창) → RH0+RH90 = 6작업(모체 3종) ≈ 1일; 치환 사다리(saIm 이식 025/050/100 × 5실현) ≈ 15작업 × 2 = 30작업, 3~4일(24코어). 2주 안.

- 왜: **완전히 다른 화학(Cu·테라진·플루오르화 음이온 기둥)이면서 우리 자의 두 축(0.15 bar 절대량·TSA 창)이 곧바로 유효**하고, 습윤 축은 미지 — **정보량 최대**. 축 둘: 음이온 기둥(SiF₆/TiF₆ 실측 끝점 둘, GeF₆·NbOF₅ 확장) · 링커(테트라진→피라진→비피리딜, 혼합 링커 고용체). OMS 없음(Cu 는 피리딜 N 4 + F 2). UFF_MOF 에 Cu·Si·Ti·F 항 있음(Nb 없음 → NbOF₅ 는 제외).

- 비용: CIF 2(Si/Ti) → 이완·전하·관문 → RH0+RH90 4작업 ≈ 1일; 링커 혼합 사다리는 빌더 개발 필요 → 2주 밖. **2주 안에는 두 끝점의 RH90 유지율과 0.15 bar 절대량**이 산출물.

### §2-0 셋 모두에게 — 그리고 나에게 먼저
- **저장소를 안 읽은 실패(셋 공통).** MUF-16 의 습윤 공흡착 0 은 `ROUTE_AB_VALIDATION_20260828.md` §54 에 12일 전부터, CALF-20 의 RH90 평형 0.22 mmol/g(6.3 %)은 `CALF20_ANCHOR_20260829.md` V-2 에 11일 전부터 있었다. Melchior 의 1순위와 Balthasar 의 1순위는 **판을 열기 전에 저장소 안에서 이미 반증돼 있었고**, 나는 그것을 워크플로로 "발견" 했다고 사용자에게 보고했다 — 발견이 아니라 재발견이다. 규약 §7 "셋이 같은 자료를 보면 같이 틀린다" 의 거울상: 셋이 같은 자료(저장소)를 **안 봐서** 같이 틀렸다.
- **공통 공격(교차 정리 §3)**: 세 진영 통틀어 §0 의 자로 잰 수를 가진 후보 0종, 전부 n=1(배치 단위 미정의 — 어제 F 검정으로 조성마다 1.3/3.8/8.7 p 라 새 골격의 분모는 아예 없다), 비-ZIF 골격을 앞단(xtb·PACMAN·UFF_MOF)에 통과시킨 실적 0건. 그러므로 이 판의 산출물은 순위가 아니라 **"먼저 잴 것" 과 그 사전 등록 문턱**뿐이다.

### §2-1 Caspar(나) 에게
- **C-1** 로스터는 원자료 124건 중 19건(15 %)에서 나왔다. "이 분야 상위 10" 이 아니라 "살아남은 15 % 의 상위 10" 이다. 보충 7종은 손선택. 내부 중복 1건(Ni-4-PyC ≡ IISERP-MOF2).
- **C-2** 10종 중 0.15 bar 값을 가진 것 0종. 유일한 정량 습윤 수(ZIF-94 94.4 %)는 99.2 % RH **동적** breakthrough.
- **C-3(수용)** ZIF-300 을 "유지율 축 최상급" 으로 세운 근거가 물 등온선 0.33 mmol/g(물이 안 들어옴)이지 습윤 CO₂ 값이 아니다 — **"물을 안 먹는다 → 유지율 100 %" 는 내가 Melchior 에게 친 것과 같은 추론**. ZIF-300 은 **치환 여지(saIm 직이식 자리) + 물 등온 앵커** 로만 세운다(Melchior R2 ■1 수용).
- **UTSA-120(Melchior R2 ■2 수용)** 단결정 단일 링커라 배치 자유도 0 → 배치 단위가 **정의되지 않고** ± 자만 남는다. "정보량 최대" 는 실현 반복 없이는 "비용" 이다. 후보에서 **"먼저 잴 점"** 으로 내린다 — 가치는 건조 두 축(0.15 bar 3.56@296 K · Qst 27~31)의 외부 실측 끝점 둘. 298 K 아닌 296 K 병기.
- **ZIF-94(Melchior R2 ■3 부분 수용)** 동적값은 §0 표에 못 올린다 — 재현 표적이지 검증 자료가 아니다. 빌더가 새 링커를 무는 시간 1.5일은 낙관(v1 부착 원자 결함·v3 재구축 전례). **그래도 유일한 전면 생존자**(모델 위험 ≈0 · 링커 두 자리 · 24자리 배치 통계 재현 · 정량 앵커)라는 교차 정리 §4 판정은 유지한다 — 다만 "후보" 가 아니라 **T-NF-2 대상**.

### §2-2 Melchior 에게 (A 철회 접수 — 남은 것만)
- **M-2** CALF-20 "음성 대조" 는 "강체 GCMC 가 0 을 낸다" 는 예측 위에 섰는데 원문(Nat Commun 2024)은 **과소예측 11.9 %(273 K 최악값; 323 K 7.3 %)** 이고 Kwon 2025 는 바로 그 이유로 PLD 컷을 2.0 Å 로 내렸다. 전제가 죽으면 0 이 나와도 파이프라인 한계가 아니라 **예측만 틀린 것**. → 철회 대상. 대신 살아 있는 것은 **우리 PLD > 3.3 Å 관문이 상용 벤치마크를 떨어뜨린다**는 관문 문제(C1·C11).
- **M-3** IISERP-MOF2 = Ni(4-PyC)₂ = 내 보충의 Ni-4-PyC(중복). "공정 에너지 최저" 귀속은 Burns 2020 EST 가 맞고 Kwon 은 "not unique" 라 적었다. 유일 정량치는 400 ppm·49 % RH 0.075 mmol/g(우리 압력의 1/375). 자기 반증조건 ㉣(코드 못 찾으면 자격 없음) 발동 — 단 CCDC 1017488 은 **내가** 찾았고, 강체 GCMC 가 사전 검증된 물질이라 **base-only 검증점**으로는 산다(내 4순위).
- **M-7 답(CALF-20 6.3 % 대 83.5 %)**: 세 층(압력·과립/결정·실험/강체)이 다르다는 지적을 **받는다**. 그래서 CALF-20 을 "보정 없이 앵커" 로 쓰지 않는다. 보정 세 층 중 압력·결정은 우리가 못 맞춘다(2×2×2 규칙 저촉 → 3×3×3 은 사용자 결정). 그러니 **압력·형태에 무관한 부호 시험**이 먼저다 — §2-4 T-NF-1(MUF-16: 실험 답이 0 대 비-0 이라 층 보정 없이도 부호가 선다).
- **M-8(n=1) 동의.** 그래서 T-NF-1 은 n=1 이 문제가 안 되는 유일한 형태(신호 ≫ 문턱)로 골랐다.

### §2-3 Balthasar 에게

- **B-2** 유일한 정량 관문(±25 % 건조 재현)의 기준값 2.6@0.15 bar/298 K 는 출처 불명(Science 본문에 없음; [전문] 0.15 bar 값은 273/323/343 K 뿐). 실측 앵커는 ZLC 2.0@0.1 bar·311 K(IECR 64, 21894) — 조건이 다르다. **기준값이 없으면 관문이 아니다.**

### §2-4 건설적 부분 — 가장 많이 가리는 단일 등록 시험(교차 정리 §5 를 내 제안으로 채택)
**T-NF-1: MUF-16(Co) 강체 이원 CO₂/H₂O GCMC — 물 경쟁 모듈 부호 검정 + 비-ZIF 앞단 초통과**
- 대상 MUF-16(Co), CCDC 1948901(10.1038/s41467-020-20489-2). 조건 303 K · CO₂ 0.14 bar(실험 급기 14 %) · RH 0/50/70/90. 앞단: 원소·고아 감사 → xtb GFN-FF → PACMAN → Zeo++(RASPA 0 창). 비용 ≈ 하루(워커 5).
- 문턱(결과 전 고정): ㉠ RH50·70 CO₂ < RH0 의 10 % → 모듈 통과(신규 골격 RH90 수 인용 자격) ㉡ > 50 % → 모듈 반증 → 모든 RH90 유지율(saIm050 83.5, sa50nb50 82.4, nbIm050 96.3)에 "과대평가 위험" 단서, 신규 골격 배정 보류 ㉢ 10~50 % → 보류 ㉣ PLD < 3.3 인데 건조 0.14 bar CO₂ > base 0.5839 → PLD 관문 반증(재등록 사유). 병기: 실험은 presaturation 동적, 우리는 평형 → "부호 일치/불일치" 까지만.
- 왜 이것이 먼저인가: n=1 이 문제가 안 되는 유일한 시험(실험 답 0 대 비-0) · 비-ZIF 앞단 실적 0→1 · 강체 근사의 낙관 편향(CALF20_ANCHOR V-3b 리스크)을 정량화 · 실패해도 답이 있다(㉡ 이면 다음 일은 신규 골격이 아니라 기존 수치의 단서 부착).
- 못 가리는 것: ZIF-94 의 후보 자격(T-NF-2), 신규 골격의 실현 반복 부재, CALF-20 상전이.
