### §1-1 내 후보 상위 3 (생존자 안에서; 순위 아님 — 셋의 역할이 다름)

**① ZIF-300 / ZIF-301 / ZIF-302 — CHA 이중 링커 MTV ZIF** [10.1002/anie.201403980 (Yaghi 2014), 10.1002/advs.201901758 [전문], 리뷰 10.1039/d3sc06076d]
- 조성(Crossref 원문 확정): Zn(2-mIm)ₓ(5(6)-X-bIm)ᵧ, X = Br(ZIF-300, 0.86:1.14) / Cl(ZIF-301, 0.94:1.06) / CH₃(ZIF-302, 0.67:1.33). CCDC 995218/995219/995220(995219 = ZIF-301 본문 확인, 나머지 Crossref 유래 미검증). 위상 CHA, Zn-N 사면체, OMS·화학흡착·유연성 보고 없음.
- 수: CO₂ 1 bar/298 K 1.32(300)·1.47(301) mmol/g, IAST 22·19, Qst 28~30 kJ/mol; **0.15 bar 미표 [미확인]**; 물 등온 Type III, P/P₀ 0.8 에서 0.33/0.32/0.25 mmol/g(끓는 물 7일 안정, [전문]).
- 습윤 근거: "건조·습윤 모두 3사이클 손실 없이 CO₂/N₂ 동적 분리" — **breakthrough, RH 미표, 재생은 상온 N₂ purge(TSA 아님)**. 리뷰의 "80 % RH" 는 안정성 라벨. 우리 자의 수는 **없다**.
- 왜: **우리 방법(고정 위상 + 링커 치환 사다리 + 배치 통계)의 직계 이식처**. 축 둘이 이미 실현돼 있다(2-mIm:bIm 비 · bIm 5(6) 치환기 Br/Cl/CH₃). **NO₂·CN·NH₂·SO₃H 는 미탐 — saIm 직이식 자리**. 물 등온이 Type III 라 유지율 축의 상한 앵커가 된다.
- 반증 조건(등록): ㉠ 0.15 bar 건조 절대량 < base 0.5839 → **절대량 축 탈락, 유지율 앵커로만 인용**(Qst 28~30 이면 그럴 공산이 큼: 외삽 0.2~0.4 mol/kg, [미확인]) ㉡ 관문(PLD>3.3, LCD 감소<20 %) 탈락 → 버림 ㉢ 치환 사다리에서 배치 단위 > 조성 차 → "배열 > 조성" 결론 재현으로 적음(실패 아님) ㉣ 습윤 breakthrough 를 평형처럼 인용하지 않는다.
- 비용: CIF 3 → xtb 이완(데스크탑) → PACMAN → Zeo++(RASPA 0 창) → RH0+RH90 = 6작업(모체 3종) ≈ 1일; 치환 사다리(saIm 이식 025/050/100 × 5실현) ≈ 15작업 × 2 = 30작업, 3~4일(24코어). 2주 안.

**② UTSA-120 (+ dptz-CuTiF₆) — 다이피리딜-테트라진·MF₆ 기둥 정사각 격자, SIFSIX-2-Cu-i 그물** [10.1039/c8ta11596f [전문], 리뷰 Table 2]
- [Cu(dpt)₂(SiF₆)]ₙ, 2중 상호침투 pcu 형, 세공 4.6 Å. **0.15 bar/296 K 3.56 mmol/g**(로스터 최고), 1 bar 5.0, IAST ~600, **Qst 27~31 kJ/mol(벤치마크 대역 안 — TSA 298→373 K 가 실제로 비울 수 있는 값)**. TiF₆ 끝점 2.93/0.15 bar, Qst 38.2(리뷰 표). CCDC 1881280(활성화·무게스트), 1882294(CO₂ 적재).
- 습윤 근거: **없다.** "80 % RH" 는 1일 노출 PXRD 결정성 라벨(1차 전문 확인). 물 등온 존재 시사(ESI) 수치 미열람.
- 왜: **완전히 다른 화학(Cu·테라진·플루오르화 음이온 기둥)이면서 우리 자의 두 축(0.15 bar 절대량·TSA 창)이 곧바로 유효**하고, 습윤 축은 미지 — **정보량 최대**. 축 둘: 음이온 기둥(SiF₆/TiF₆ 실측 끝점 둘, GeF₆·NbOF₅ 확장) · 링커(테트라진→피라진→비피리딜, 혼합 링커 고용체). OMS 없음(Cu 는 피리딜 N 4 + F 2). UFF_MOF 에 Cu·Si·Ti·F 항 있음(Nb 없음 → NbOF₅ 는 제외).
- 반증 조건(등록): ㉠ 강체 RH90 유지율 예측을 "문헌 습윤 성능 재현" 이라 적지 않는다(앵커 없음) ㉡ 0.15 bar 건조 절대량이 3.56 의 50 % 미만이면 우리 파이프라인이 이 계열을 못 다루는 것 → 계열 종료 ㉢ SIFSIX 계열의 실제 습윤 실패는 가수분해·기둥 이탈일 수 있고 강체는 그것을 못 봄 → 결과에 "구조 붕괴 미반영" 병기 의무 ㉣ ZIF-69 와 직접 순위 비교 금지(다른 계열) — 자기 base(UTSA-120) 대비 사다리로만.
- 비용: CIF 2(Si/Ti) → 이완·전하·관문 → RH0+RH90 4작업 ≈ 1일; 링커 혼합 사다리는 빌더 개발 필요 → 2주 밖. **2주 안에는 두 끝점의 RH90 유지율과 0.15 bar 절대량**이 산출물.

**③ ZIF-94 / SIM-1 — SOD, 4-methyl-5-imidazolecarbaldehyde** [10.3390/molecules27175608 [전문, PMC9458099]]
- 1 bar/298 K CO₂ 2.38 mmol/g, N₂ 0.285, IAST(15:85) 54.1, Qst 28.2, BET 588, SOD 공동 8.0 Å. **습윤 breakthrough 99.2 % RH 에서 건조 동적 용량의 94.4 % 유지(30.94/32.76 cm³/g), PXRD 불변** — 목록 전체에서 가장 높은 RH 의 정량 습윤 수. 물 등온 측정됨(수치는 SI 그림, [미확인]). CCDC 없음 → ZIF-8 SOD 모체에서 링커 치환으로 구축(빌더 경로 있음).
- 왜: 파이프라인 네이티브(우리와 같은 화학) + 정량 습윤 앵커. 치환 축: 고리 두 자리(알데히드 → SO₃H/CN/COOH; 4-메틸), 2-mIm/ZIF-94 고용체.
- 반증 조건(등록): ㉠ 94.4 % 는 동적값 — 강체 평형 RH90 유지율과 정성 방향으로만 대조 ㉡ Qst 28 → 0.15 bar 절대량이 base 아래면 절대량 축 탈락 ㉢ 관문 탈락 → 버림.
- 비용: 구축 1 → 이완·전하·관문 → RH0+RH90 5실현(SOD 24자리 배치 자유도) = 10작업 ≈ 1.5일.

### §1-2 후보가 아니라 **자(自) 보정·대조군**으로 값이 있는 것 (등록 제안, 후보 순위와 무관)

- **CALF-20 — 유지율 축의 유일한 외부 교정 앵커.** RH 0→90 이성분 평형 실측(IECR 2025, 64, 1712 표 2, 30 °C·0.95 bar 순수 CO₂·무바인더 과립): 3.51 → 2.10(RH50) → 0.42(RH75) → **0.22(RH90), 유지율 6.3 %**, 물 RH90 11.86 mol/kg. 우리 saIm050 83.5~92 % 와 대조할 자리. **막는 것 셋**: PLD 2.75~2.8 Å(Zeo++)이 우리 관문 3.3 아래 · 셀(8.06/9.69/8.57 Å)이 12 Å 컷오프에서 3×3×3 필요(§1 고정값 "2×2×2" 저촉 → 사용자 결정) · 물 유발 상전이(α→γ, 셀 −9 %)를 강체가 못 봄. 그래서 "예측" 이 아니라 **"강체 근사가 어느 방향으로 얼마나 틀리는가"** 를 재는 시험(T-NF-1 후보).
- **MUF-16 — 음성 대조군.** RH 50·70 % 물 포화 층에서 CO₂ 공흡착 0(ACS AMI 2025, He 추적자 동시 파과). 우리 물 모델이 이 배제를 재현하는지가 통과/실패 이분 시험.
- **SIFSIX-3-Ni 순수 물 등온(95 % RH 8.80 mmol/g, Sci Adv 2019 표 1)** — CO₂ 없는 물 모듈 단일 수 관문.
- **Qc-5-Cu-sql-β(CCDC 1470738, 세공 3.3 Å)** — 우리 PLD 관문이 40,000 선택도 체를 탈락시키는지 보는 관문 시험(Zeo++ 만, 계산 0).
