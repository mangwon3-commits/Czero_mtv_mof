- 차분: 현 LP 보다 **14 nm 작음**(구간 −28 ~ 0). 그런데 기준인 현 LP 는 이미 **0.3 % 로 목표 0.2 % 를 못 맞추고 있음**[양산 12개월]. 구간 상한(Δ ≈ 0)에서도 기껏 "현 LP 수준" 이라 0.2 % 가 안 됨.
- 파일럿 0.4 ~ 0.9 %[표본 작음]가 같은 방향.
- 판정: **부족**. 확신도 **중**.
- 이 단계가 틀렸다면: N+1 LP 가 현 LP 보다 나쁘지 않아야 함 — 파일럿 LP 손실을 여러 장으로 재어 ≤ 0.3 % 가 나오면 차분의 전제(J-5)가 깨진 것.

**J-4. 어느 절대 예산도 "마진 ≥ 0 ⇒ 손실 ≤ 0.2 %" 를 현 세대에서 지키지 못한다.**  [산술]

- 현 M1: 선형 · Mack 에서 마진 − 인데 손실 0.2 %(목표 충족).
- 그래서 N+1 에서 절대 마진이 + 인 칸(LP 의 Mack 평균 · RSS, M1 의 RSS 평균)을 "확보" 근거로 쓸 수 없음. → Q3.

**J-5. 판정은 차분으로.**  [산술 · 가설]
- 같은 레이어 · 같은 장비군이면 무작위항(스캐너 · 평탄도 · 레벨 센서 · 레티클)과 렌즈 · 레지스트가 상쇄됨 → Δ마진 = ΔDoF − Δ토포. 결합 규칙 · 스캐너 값 · 폭 규약 선택에 무관(RSS 에서도 0.8 nm 안).

## 4. Q3 현 세대 정합

  - SMO+SRAF +18 % → 결함 인지 +4.6 ~ +7.3
  - 비대칭 SRAF +32 % → +8.2 ~ +13.0
- imec 은 0.55NA 의 DoF 를 NA² 로 줄어드는 것으로 적고, 모의로 0.33NA 대비 **2 ~ 3배 감소**를 적음[전문][^e1].
  이 문제의 LP 급 40 ~ 55 는 N+1 LP CD 공통 88 대비 1.6 ~ 2.2배 감소 → imec 범위의 **낙관 끝 · 그 밖**.
  imec 범위(88/3 ~ 88/2 = 29 ~ 44)로 다시 하면 Photo 이득은 결함 인지 척도 +3.4 ~ +10.4 nm[산술].
- 초점 오차원(웨이퍼 휨 · 토포 · 레지스트 두께)은 DoF 에 비례해 줄지 않는다는 것이 Mack 의 초점 효과 연작의 요지[요지][^e2].
  0.55NA 오차 항목은 실측값 없음(문제 §6) → 여기서는 0.33NA 값을 그대로 둠[가정].
- → **Photo 레버 한계(nm)**: 0.33NA 의 약 6 ~ 14 → 0.55NA 의 약 3 ~ 13 nm(결함 인지 척도). 부족분은 그대로인데 메우는 폭은 줄어듦.

**J-11. 평탄화가 필요해지는 잔여 단차 문턱이 내려간다.**  [산술]
- 문턱 = 결함 인지 DoF(+ Photo 이득) − 무작위 RSS(21.6, 스캐너 16) − 렌즈 · 레지스트 8.
- 0.33NA: MC 18.4(P1 이면 24.2 ~ 28.0) · M1 42.4(51.0 ~ 56.8) · LP 25.5(32.5 ~ 37.1) nm.
- 0.55NA(문제 모의 DoF · 비 0.64 ~ 0.74):
  - 레버 없음 −4.0 ~ +11.1
  - SMO+SRAF +0.6 ~ +18.4
  - 비대칭 SRAF +4.2 ~ +24.1
  - imec 범위면 −10.8 ~ +13.4
- → 문턱이 **약 18 ~ 57 nm 에서 약 −11 ~ +24 nm 로** 이동.
  C2 급(MC 잔여 15 ~ 25)이 새 문턱 근처 · 위 → 0.55NA MC 는 C3 급(≤ 5, 제조사 발표) 또는 무작위항 자체의 감소가 필요.
  0.55NA LP 는 자기 가장자리 단차(22 → D1 뒤 10 ~ 14)도 문턱을 넘을 공산 — LP 에 평탄화 레버가 없으므로 설계 레버(D1 급) · 무작위항 감소가 유일한 길.
- 확신도 **하**: 0.55NA 오차 항목 · 결함 인지 비 · 레버 이득이 모두 미측정 · 모의.

**J-12. 평탄화 1회의 수혜 레이어 수 n 이 레버 순서를 바꾼다.**  [산술]
- N+1: ILD 평탄화(C1 · C2 · C3) 1회는 MC · M1 두 EUV 레이어를 도움(n = 2). X1 이면 EUV 는 M1 하나(n = 1).
- C2 레이어당 연간: n = 1 → 306 ~ 414 · n = 2 → 153 ~ 207 · n = 3 → 102 ~ 138억.
- C3 레이어당: 일회 1,400 / n + 연간 144 / n.
- n = 2 에서 C2(153 ~ 207/레이어) < X1(432, MC 한 레이어).
- X1 을 택해 n = 1 이 되면 M1 한 레이어에 C2(306 ~ 414) 대 C1(57.6) → **C1 이 이김.** 즉 X1 이 M1 의 최적 레버를 뒤집음(경로 의존).
- 5 → 7 레이어의 뜻:
  - P1 은 레이어당 5억 + 30인·주라 레이어 수에 비례(7개면 35억 · 210인·주).
  - P2 는 장비군 1회 120억이라 레이어당 17억(6개면 20억).
  - 커패시터 위 EUV 레이어가 늘수록 n 이 커져 평탄화 급 레버의 레이어당 값이 좋아짐.
  - LP(커패시터 아래)는 어떤 n 에서도 ILD 평탄화 수혜 밖.
- 확신도 **중**(산술은 문제 상수만, n 의 미래 값은 가정).

## 6. Q5 다음 측정(우선순위)

    ① MC 결함 인지 공통 DoF — C2 평탄화 제품 레이아웃 웨이퍼 ≥ 5장(지금 1장, 구간 35 ~ 60) + 같은 웨이퍼의 MC · M1 잔여 단차(AFM, 셀–페리).
       바꿀 결론: MC 적용 뒤 판정(불가 → 확보 / 부족) · C2 대 X1 · C3 선택 · M1 의 C2 값(지금 추정) 확정.
       사전 등록: C2 제품판에서 Mack(스캐너 16 · 최대 토포) 마진이 DoF 95 % 하한에서 ≥ 0(P1 은 ③ 실측값) → C2 경로 확정.
                 중앙에서 < −10 → C3 · X1 재평가(X1 은 자기 손실 보정 뒤).
    ② 현 세대 LP · M1 의 "초점 → 손실" 보정.
       의도적 초점 오프셋 로트, 또는 기존 결함 지도 회귀: 초점 결함 밀도 대 국소 초점 · 토포 · 영역(셀 블록 가장자리 / 중앙 · 셀 / 페리 · 웨이퍼 가장자리).
       바꿀 결론: Q3 원인(J-7a ~ d) 가르기 · LP 에 필요한 nm(지금 16 ~ 28 가설) · D1 채택 규칙의 입력 · 차분 전제(J-5) 검증.
       사전 등록: LP 초점 결함의 ≥ 50 % 가 셀 블록 가장자리 → D1 우선.
                 M1 결함이 한 높이 영역에 ≥ 80 % → 단차의 실효 소모를 영역별로 다시 셈(M1 레버 필요량 축소).
                 초점 오프셋당 손실 증가율 LP / M1 ≥ 2 → J-7a 채택.
    ③ P1 의 결함 인지 DoF 이득 실측(지금 CD 기준 모의뿐) — P1 마스크 또는 시험 레티클 FEM + 결함 검사, LP · MC.
       바꿀 결론: LP 레버 조합(P1 + P2 로 되는지, D1 필요한지) · MC 의 C2 + P1 뒤 마진 · Q4 Photo 레버 한계.
       사전 등록: 결함 인지 이득 ≥ CD 이득 % 의 60 % → §3 가정 유지. < 30 % → LP 는 D1 필수 · MC 는 C3 / X1 재평가.
    시간 제약: D1 은 설계 동결 전만 → ② · ③ 이 동결 전에 끝나지 않으면 D1 은 "판정 불가 상태에서의 결정" 이 됨(그 사실을 결정문에 적을 것).

## 8. 자기 반박 — 급소 하나

내 판정(특히 LP · M1 "부족" 과 레버 크기)은 **J-5 의 전제 — "같은 레이어의 마진 → 손실 대응이 N → N+1 에서 유지된다"** 에 기대고 있다.
N+1 에서 레이아웃 · 패턴 혼합이 바뀌면 전제가 깨진다 — 예: M1 최소 피치 라인이 페리까지 늘어나거나(J-7b 의 반대 방향), LP 셀 블록 크기가 바뀌는 경우.
그러면 차분 −14 · −18 은 손실로 옮겨지지 않고, 판정은 절대 예산(보정 안 됨)으로 되돌아가 LP 는 규칙 선택에 달린다.

**드러날 관측**: 파일럿 손실을 웨이퍼 여러 장으로 다시 재어
- LP ≤ 0.3 % 또는 M1 ≤ 0.2 % 가 나오면 → 차분이 예측한 악화가 없는 것이므로 J-5 가 틀림.
- 반대로 LP 0.4 ~ 0.9 · M1 0.6 ~ 1.2 가 굳으면 → 전제가 버팀.

(둘째 급소, 짧게: 패턴 편차를 예산에서 뺀 것(J-8)은 MC 에서 겹침 80.5 대 표 75 로 5.5 nm 어긋남 — MC 공통 DoF 에 제3의 패턴이나 더 큰 편차가 숨어 있을 수 있음. 판정 방향은 불변.)

## 9. 용어표(이 문서 안 정의)

    DoF(초점 심도)       정해진 규격(여기서는 CD ±10 % · EL 10 %)을 만족하는 초점 범위의 폭. 이 문서는 전부 전폭(nm).
    공통 DoF            한 레이어의 모든 패턴이 동시에 규격을 만족하는 초점 범위 = 패턴별 창의 겹침.
    결함 인지 공통 DoF   결함 검사를 포함한 FEM 에서 초점 관련 결함 밀도가 팹 기준 이하인 공통 범위. 이 문서의 마진 자.
    마진                DoF − 초점 오차 예산(전폭). 차분 마진 = 같은 레이어의 N+1 마진 − N 마진.
    EL(노광 관용도)      규격을 만족하는 노광량 범위(%).
    FEM                 초점 × 노광량 행렬 노광 — 창을 재는 실험.
    3σ                  정규분포 가정의 표준편차 3배. ±3σ 는 반폭, 전폭은 6σ.
    p-v                 최고점 − 최저점(전폭). 3σ 와 같은 통계량이 아님.
    전폭 / 반폭          창 전체 폭 / 중심에서 한쪽 폭.
    선형 합 · RSS · Mack  각각 전 항 선형 합 · 전 항 제곱합 제곱근 · 무작위 RSS + 계통 선형(문제 §3).
    무작위 / 계통        샷 · 웨이퍼마다 독립으로 흔들리는 항 / 매번 같은 부호 · 크기로 들어가는 항(팹 표준 분류를 따름).
    레벨링              노광 전 웨이퍼 높이를 재 초점면을 맞추는 동작. 공간 분해능 약 1 mm.
    잔여 토포            레벨링 · 레이어별 초점 오프셋 보정 뒤에도 샷 안에 남는 단거리 높이 차(전폭).
    마스크 3D            흡수체 두께 때문에 패턴마다 최적 초점이 달라지는 효과(문제에서는 모의값).
    SMO · SRAF · OPC     광원-마스크 동시 최적화 · 해상 안 되는 보조 패턴 · 광근접 보정.
    ILD · CMP           층간 절연막 · 화학기계 연마.
    High-NA             0.55NA EUV. 0.33NA 는 현 NXE.
    차분                같은 레이어 · 같은 장비군에서 세대 간 차 — 무작위항 · 렌즈 · 레지스트가 상쇄됨.
    수혜 레이어 수 n     평탄화 1회가 잔여 단차를 줄여 주는 EUV 레이어의 수.
