# MAGI-005 종합자 봉인 예측 (규약 §9-10 ①) — HKHOME Fable 5.1, 2026-09-24 22:02, HEAD 0be33d5c

"평가가 안 왔다면 내가 정했을 결정":

1. 선택도를 지금보다 올리는 가장 확실한 축은 **정전기 세기(치환기)** 가 아니라 **세공 기하(LCD 6~7 Å 급 초미세공 + PLD 3.4~3.8 Å 의 N₂ 부분 체질)** 이다.
   근거: v3 31조성에서 선택도 상위는 전부 LCD 8.9~10.2 Å 의 강극성기(saIm/mslm/nbIm)이고, 극성기 축은 물 흡착과 맞교환(saIm050 물 1.6 mol/kg)이라 습윤 축에서 상한이 보인다.
   CoRE 524종 위에서 선택도 축 상위 13 %(saIm050 87.0 %)인데, 그 위의 13 % 는 대부분 초미세공(SIFSIX/CALF-20/MUF-16 류)이다.
2. 그러므로 권고안은 (a) gme 밖의 **소공동 아졸레이트 위상**(cag/mer/dia/lcs 등, LCD 5~7 Å) 스크리닝을 우리 자로 먼저 돌리고,
   (b) 극성기는 −SO₃H 가 아니라 **작고 약한 다중 약극성 접촉**(F/CN/N-헤테로 고리, azbIm 류)으로 물 페널티를 줄이는 것,
   (c) 금속 치환(Zn→Co/Cd)은 선택도 이득이 작아 후순위.
3. 세 토론자가 낼 것으로 예상: Melchior = 기하(초미세공/체질) · Balthasar = 파이프라인 안에서 되는 치환기 조합(azbIm·혼합) · Junseok = 데이터 기준 검증(우리 자로 재본 CoRE 상위군 역설계).
4. 판정 예상: 후보 0종 확정은 아니지만 **"우리 자로 잰 신규 후보는 없다"** 가 다시 나올 공산이 크고, 산출물은 등록 시험안 2~3개.
