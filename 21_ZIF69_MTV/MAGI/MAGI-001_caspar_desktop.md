## 3. 자(ruler) — **§8-2 는 등록된 두 자 중 어느 것도 아닙니다**

`ERROR_BARS.md` 맨 끝 절이 이 저장소에 자가 **둘** 등록돼 있음을 적고,
*"판정 단위를 적을 때 분모의 자를 같이 적으십시오"*, *"두 값을 다 병기한다"*
를 당장의 규칙으로 못 박았습니다. §8-2 의 식

    평균 ± sqrt( 블록±²  +  s_batch² / n )

은 **블록 항은 `±`(95%CI = 2.776×SEM), 배치 항은 `1σ`(표본 SD/√n)** 로,
두 자를 한 분모에 섞습니다. 같은 비교를 세 방식으로 내면:

    (A) 전부 σ 자   블록 ±/2.776,  배치 s/√n          ->  **1.746 단위**   검출
    (B) 전부 ± 자   블록 ±,        배치 2.776·s/√n     ->  **0.629 단위**   미검출
    (H) §8-2 혼합자                                    ->  **1.524 단위**   칼날

**등록된 두 자가 정반대 판정을 냅니다.** 문턱 1.5 는 CLAUDE.md §2 에서
`±` 자로 정의된 수이므로 문언대로면 (B) 이고, 그러면 1.5 를 넘기려면
차가 **25.3** 필요합니다(실제 10.62). 관문 통과 집합 안에서 그만한 차를
가진 쌍은 없습니다 — **판별력 0 에 가깝습니다**(검사 1).

    블록 항을 n 으로 안 나눈 것은 보수적입니다(17% 분모 증가).
    그러나 배치 항을 σ 자로 둔 것은 **반대 방향으로 2.42배 관대**합니다.
    둘이 상쇄되지 않고, **알짜는 관대**합니다.

### 3-1. 이중 계산은 있지만 **작습니다** — 여기가 문제가 아닙니다

    laptop2 실측 s_rep/± = 0.514 로 보정해도 9.217   (−1.9%)

**2% 입니다. 이중 계산은 병기만 하고 넘어가도 됩니다.** 문제는 3절의 자입니다.
