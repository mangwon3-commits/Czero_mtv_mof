## 주의

- 격자는 **2×2×2 슈퍼셀** 위에 정의돼 있습니다(52.168 / 52.168 / 38.816 Å).
  단위셀로 접을 때는 **셀 행렬**을 쓰십시오 — ZIF-69 는 γ=120° 육방이라
  길이만으로 접으면 최대 24 Å 틀립니다(09-05 `092788e` 에서 고친 결함).

- 값은 최대 1 로 정규화된 분수입니다. 최소단위의 역수가 최대 복셀 원계수입니다.
