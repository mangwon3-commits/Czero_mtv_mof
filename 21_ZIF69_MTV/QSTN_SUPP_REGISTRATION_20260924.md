## 2. 식 — **§AS 와 동일**(새 식을 만들지 않습니다)

온도별 등온을 `ln p` 대 `n` 으로 **구간 선형 보간**(외삽 금지) → 세 온도 최소제곱 기울기로
`Q_st(n) = −R · d ln p / d(1/T)`. 괄호 값은 등온을 `+±`/`−±` 로 옮겨 다시 낸 것.

## 4. 예측 (자료 0건 시점 고정)

    P1 ★ 주 판정 — **시험 다섯**(mslm050·sa50nb50·saIm025·saIm050·saIm0583)의
         Δ_low = Q_st(0.3) − Widom(보정) 의 **평균**
           평균 ≥ **−2.5**            → **물리**   (저피복에서 보정 Widom 으로 올라옴)
           평균 ≤ **−4.0**            → **도구 의심** (보정 전 Widom 쪽에 머묾)
           −4.0 < 평균 < −2.5         → **판정 불가**
         문턱의 근거: 2RT = 4.96 의 **절반이 2.48**. 상수 오프셋(도구)이면 −4.96 근처에 머물고,
         피복 효과(물리)면 0 쪽으로 줄어듭니다. **−2.5 는 "0 에 더 가까움", −4.0 은 "2RT 대 안"** 입니다.
         등록 예측: **물리 쪽(평균 ≥ −2.5)**.
    P2   다섯 전부 `Q_st(0.3) > Q_st(n_w)` — 저피복이 더 높다.  등록 예측: **맞음**.
    P3   대조 `base` 의 |Δ_low| ≤ 2.5 (센 자리가 없어 안 움직임).  등록 예측: **맞음**.
    P4   `n_lo < 0.3` 인 조성 수 **6/6** — 0.01 bar 가 충분히 낮은가.  등록 예측: **6/6**.
         (6/6 이 아니면 그 조성은 P1 에서 빠지고, 빠진 수를 판정문에 적습니다.)
    P6   기기 항(§1-2) — `base` 여섯 짝 적재 비의 **중앙값이 1 ± 0.03 안**.  등록 예측: **안**.
         밖이면 **P1 판정 불가**(§1-2 의 관문).
    P5   서술 — 다섯의 Δ_low 가 MUF-16 의 **0.2**(T-NF-1q §10, n=0.3 CC 34.4 대 보정 34.1)에
         얼마나 가까운가. **판정에 안 씁니다.**
