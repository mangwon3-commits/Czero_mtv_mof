# T-6 겹침 적분 — 예측은 **기각되지 않았으나 기제로는 부족하다** (2026-09-05, laptop2)

**판정: 겹침 지표는 유지율과 방향이 맞으나, 표본량 보정 후 여유가 1.7σ 이고
설명하려던 물당 손실 16배에 대해 겹침 차이는 1.02배다.**

등록: `ASSIGN_20260905.md` §2 — (가) 단성분 CO₂ × 물 격자로 판정, (나) 이원 런
겹침 병기. 예측: `WATER_DISPLACEMENT_20260905.md` §3 (결과 전 등록).

---

## 1. 겹침 적분

`O = Σ min(p_CO₂, p_H₂O)`, 두 분포를 접근가능 복셀 위에서 각각 합 1 로 정규화.

| 구조 | **(가) 단성분 CO₂** | (나) 이원 런 | 차 |
|---|---:|---:|---:|
| `base` | **0.2688** | 0.2813 | −0.0125 |
| `nbIm025` | **0.3356** | 0.3110 | +0.0246 |
| `saIm050` | **0.3205** | 0.3143 | +0.0062 |

**(나)가 (가)와 방향이 같다** (둘 다 base < saIm050). **T-6′ 는 필요 없다.**

## 2. 예측 검정 — 등록문이 허용하는 최대치는 "기각되지 않음"

    예측 (결과 전 등록):  O(base) < O(치환체).  대조쌍 base 대 saIm050
    등록된 처분:          거짓이면 **겹침 가설을 버린다**

    실측:  O(base) 0.2688  <  O(saIm050) 0.3205      -> **기각되지 않음**

**"확인됨" 은 등록되지 않은 진술이다** (데스크탑 지적). 이 예측은 **반증 시험**으로
등록됐으므로 참일 때 말할 수 있는 것은 **기각되지 않았다**까지다.

## 3. ⚠ 그런데 표본량 교란이 있다 — 여유가 7.7배 줄어든다

**O 가 표본량에 따라 아직 오르는 중이다.** base 재실행 스냅 13개(1개는 쓰기 도중
복사로 잘려 제외)로:

    N_max 1,728 -> 3,041 동안  O  0.2547 -> 0.2688  **단조 증가**
    회귀  O = 0.0675 + **0.02498** × log(N_max)     **r = +0.958 (n=12)**

**수렴하지 않았다.** 그런데 비교 대상의 표본량이 크게 다르다:

    base 3,041    nbIm025 5,118    saIm050 **19,150**  (base 의 6.3배)

표본량을 맞추면:

    base 를 saIm050 수준(19,150)까지 외삽  ->  O ≈ **0.3138**
    saIm050 실측                              **0.3205**
    차이  +0.0518  ->  **+0.0067**  (**7.7배 감소**), 표본 잡음 SD 0.0040 대비 **1.7σ**

**씨앗 잡음은 그 위에 얹히는데 측정된 바 없다.**

⚠ **외삽이다.** base 는 N_max 3,041 까지만 관측됐고 그 위는 자료가 없다. O 가
어디선가 평평해지면 과대평가다. **확정이 아니라 경보다.**

## 4. 교란의 정체 — 추정량이 비교하려는 성질과 얽혀 있다

`N_max` 는 로딩 × 사이클에 비례한다. **`saIm050` 은 물을 더 많이 잡으므로**
(RH90 0.94 대 base 0.49 mol/kg) **자동으로 계수가 많아지고, 계수가 많으면 O 가
크다.** 즉 **"물을 많이 잡는다" 는 성질 자체가 추정량을 밀어 올린다.**

**우연한 불균형이 아니라 구조적 결합이다. 사이클을 맞춰도(셋 다 15,000) 계수는
안 맞는다.** 설계가 "사이클 맞추기" 가 아니라 **"계수 맞추기"** 였어야 한다.

## 5. **더 센 진술 — 크기가 부족하다** (표본량과 별개)

이 예측이 설명하려던 것은 **물당 손실 16배**(base 0.0197 대 saIm050 0.3130)다.

    겹침 차이   보정 전 **1.19배**    보정 후 **1.02배**
    설명 대상   물당 손실 **16배**

**세 자릿수가 안 맞는다.** §3 이 *"차이가 있는지 모른다"* 라면 이것은
**"있어도 부족하다"** 이고, **후자가 더 세다.** 표본량 문제가 완전히 해결돼 차이가
실재로 확인돼도 16배를 못 만든다.

> **겹침 가설은 기각되지 않았으나, 물당 손실 16배의 기제로는 탈락이다.**

## 6. 병기

**(가) 물 힘장 결함 — T-4 와 동일.** `Hw` 가 `H_`(UFF 수소) LJ 를 물려받아
수소결합이 억제돼 있다(내 출력 `Hw-Hw` 22.14170/2.57113 = `UFF_MOF:17` 와 일치).
**겹침 적분의 물 격자 전체가 그 물이다.** 물이 CO₂ 자리로 못 들어가는 정도가
힘장 때문일 수 있고, 그러면 겹침이 **과소평가**된다.

**(나) 세 격자 전부 실현 1개, 씨앗 상이 → 실행 간 산포 미측정.**
씨앗: base 1788559403 · nbIm025 1788537975 · saIm050 1788537979.

**(다) `nbIm025` 는 예측 대조에서 제외** (RH0 가 물 러너가 아니라 건조 GCMC
선별값이라 물당 손실을 같은 자로 못 낸다). **T-6 판정에는 포함.**

**(라) `nbIm025` 가 보정 후에도 가장 높다** — base 를 nbIm025 수준(5,118)까지
외삽하면 0.2809, 실측 0.3356 으로 **+0.0547**. 표본량으로 설명 안 된다.
**예측 대조에서 빠진 구조가 가장 큰 겹침을 냈다.** 탐색 기록으로만 남긴다.

**(마) `nbIm025` 는 14,500/15,000 사이클 판.**
