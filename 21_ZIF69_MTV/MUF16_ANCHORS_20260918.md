# MUF-16 실측 앵커 — Qazvini·Telfer, ACS Appl. Mater. Interfaces 2021, 13, 12141 (10.1021/acsami.1c01156) (2026-09-18 02:02, 종합자 독해; 사용자 업로드 PDF)

**T-NF-1 이 자료 0건이므로 등록 조건을 결과 전에 보완할 수 있다**(MAGI §9-6 "첫 결과를 읽기 전"). 이 문서는 수치만 적고, 등록 변경은 §4 의 사용자 안건.
이 논문에는 CIF 가 없다 — 구조 기탁(CCDC 1948901~05)은 ref 34(Nat. Commun. 2021, 12, 197)이며 **거기에 CO₂ 적재 단결정 구조가 있다**(본문 Figure 1b: "CO₂-loaded sample 의 SCXRD 로 흡착 자리 확정"). 다섯 기탁 중 하나는 CO₂ 적재판일 것 → **우리 GCMC 밀도맵의 자리 대조 앵커**로 쓸 수 있다.

## 1. 구조·활성화
    [Co(Haip)₂], I2/a, 1D 채널 **3.6 × 7.6 Å²**, BET 214 m²/g, 세공 부피 0.11 cm³/g. 활성화 **130 °C 진공** → 무게스트. 탈용매·CO₂ 적재에서 회절 패턴 불변(강체 골격 — 우리 강체 GCMC 가정과 맞음).
    선택 기전은 분자체가 아니다: 77 K 에서 N₂·H₂ 세공 접근 가능, 195 K 에 C₂H₆ 도 들어감. **정전기(아민·비배위 COOH 와 CO₂ 사중극자)** 가 선택도의 핵심 → ㉣ "PLD < 3.3 인데 CO₂ 흡착" 이 이 재료에서 예상되는 모양.
    MW = 419.2 g/mol (Co + 2 C₈H₆NO₄).

## 3. 등록(`TNF_REGISTRATION §1`)과의 대조
    등록 조건 **303 K · 0.14 bar · RH 0/50/70/90** — 이 논문의 실측은 **293 K(등온·파과·습윤 파과 전부) 와 298 K(물 등온)** 이다. 303 K 는 어느 실측과도 안 맞는다(같은 이름의 다른 양 — T-NF-0 에서 ZIF-71 을 308 K 로 옮긴 것과 같은 사유).
    "전제: RH0 건조 CO₂ ≥ base 0.5839 의 1/2" 는 실측 1.08 mol/kg @0.165 bar 로 보아 넉넉히 넘을 것 — 우리 힘장이 그렇게 내는지가 시험이지 전제가 아니게 됨.
    문턱 ㉠ "RH50·RH70 CO₂ < RH0 의 10 % → 물 모듈 통과" 는 실측(82 % RH 파과에서 단기 무손상)과 **부호가 반대인 예측을 검정하는 문턱**이었다 — 등록 취지(물 경쟁 모듈의 부호 검정)는 유지되나, 실측이 "물이 있어도 CO₂ 를 잡는다" 쪽이므로 문턱 문장을 이 실측 기준으로 다시 세워야 한다(§4).

## 4. 사용자 안건 — 등록 보완(자료 0건 시점, 결과 전)
