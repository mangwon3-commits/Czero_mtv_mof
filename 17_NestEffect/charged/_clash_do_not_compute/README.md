# 계산 금지 — 구조 감사 불합격

`mIm075_saIm025_DDEC6.cif` 의 전하는 현재 구조와 정확히 일치하지만(좌표 차 0.0000 Å),
**그 구조 자체가 구조 감사에 불합격**이라 계산에 쓰면 안 됩니다.

## 무엇이 문제인가

술폰산의 **−O–H 수소가 이웃 링커의 Zn 배위 이미다졸레이트 N 을 1.569 Å 에서 찌릅니다.**
네 자리 전부 정확히 같은 거리입니다 — 무작위 배치 사고가 아니라 빌더가
**S−O−H 이면각을 고정**해 둔 결과입니다.

- 정상 N···H 수소결합: 1.8~2.0 Å
- 이 거리는 양성자 이동(−SO₃⁻ / N−H⁺)이 일어날 만한 영역

주기경계(고리 언랩) 버그와는 **무관**합니다. `build_nest.py` 를 다시 돌려도 그대로입니다.

## 풀려면

빌더에 S−O−H 이면각 탐색을 넣거나, 술폰산염 형태로 모델링할지 결정해야 합니다.
−SO₃H 가 현재 최고 작용기이므로 그냥 넘길 문제가 아닙니다.

해결한 뒤에는 `python audit_orphans.py` 로 `고아 0 / 충돌 0 / 분리 0` 을 확인하고
이 파일을 상위 `charged/` 로 되돌리면 `run_raspa_nest.py` 가 다시 집어 갑니다.

> `18_PoreNarrowing` 의 −SO₃H 구조들은 이 문제가 없습니다. 주력 결과는 영향받지 않습니다.
